# 更新日志
## [0.4.3] - 2026-11-21

### 🎉 新增
- 新增内置模板「中文讲义」：多文件课程讲义 / 笔记骨架，带封面、前言、目录与彩色定理盒子，章节独立成文件，新建项目时即可选用
- 新增「根据本项目制作模板」三步向导（菜单「模板 → 根据本项目制作模板…」）：勾选要带走的文件 → 自动把标题、作者、日期提取成可填变量 → 一键导出 zip 并可选装进模板库，做好的模板可直接用来新建项目

### 🔧 优化
- 模板交换统一为 zip：导入模板现在只认 zip 包（zip 里多套一层文件夹也能识别），含非法变量（重名、数字开头、保留字）或 manifest 缺失的坏包在导入时就会被拦下并明确报错，不会再导入到一半才失败
- 制作模板时会保留原项目的换行格式与文件结尾，编译配置（引擎、主文件、输出目录）也会一并带进新项目

### ⚠️ 重要变更 / 不兼容更新
- 菜单「另存当前项目为模板」已移除，改用「根据本项目制作模板…」向导；之前用旧入口保存的模板仍可正常使用
- 「导入文件夹…」入口已移除，模板导入只支持 zip 包；旧版导出的模板目录请先打包成 zip 再导入
