# 更新日志

## [0.4.1] - 2026-11-18

### 🎉 新增

- macOS 菜单栏改为系统原生菜单（文件 / 编辑 / 插入 / 构建 / 查看等全中文菜单），退出、关窗仍会先确认未保存的内容
- Zotero：项目里还没有 `.bib` 时，插入引用会自动新建 `references.bib` 并写入，随后弹窗帮你补好引用环境（`\bibliography` / `\addbibresource`），从零开始也能直接用
- Zotero：引用侧栏新增条目格式切换（跟随项目 / BibTeX / biblatex），切换时可一并转换已有条目与导言区声明

### 🔧 优化

- 「插入代码片段」改为双栏浮层：左侧分类与搜索、右侧代码预览，选中即插入
- 其他编辑器改动了已打开的文件时，Zetla 会静默自动重载，不用再关掉标签页重新打开

### 🐛 修复

- 修复参考文献末尾打印出「Zotero itemKey: …」的问题，旧写法会在保存时自动迁移
- 修复非 LaTeX 文档下点击代码片段没有反应的问题
- 修复 0.4.0 自更新下载地址 404 的问题（本次推送的即是修复后的链接）

### ⚠️ 重要变更 / 不兼容更新

- macOS 改用系统原生菜单后，`Ctrl+B` 再按数字键切换侧栏面板的连招快捷键暂不可用，请改用菜单或点击侧栏图标
- Zotero 联动仍为只读：不会写回 Zotero，在 Zotero 里删除条目也不会联动删除 `.bib` 中的条目
