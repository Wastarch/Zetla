## 绘图模块（TikZ）
- 侧栏新增「绘图」视图：在 Zetla 里直接画图，TikZ 源码就是唯一真源
- 拖控制点、改样式、调尺寸、排公式都以最小补丁写回源码，与键盘编辑共用一条撤销栈
- 节点内 `$...$` 由 MathJax 渲染，双击节点可就地改文字或公式
- 导出 PNG / SVG / PDF，一键插入 figure 环境；也可把 PNG / JPG / PDF 暂存进项目后在画布上放置

## 跨平台
- TeX Live 自动安装支持 Linux / macOS：安装器按平台分流，下载并发测速择优、卡住或低速自动换源，并补上中文集合
- 更新器支持 Linux AppImage 原地换包、deb / rpm 下载后交系统安装器，以及 macOS .app 换包后自动重启
- 关于页重做：更新说明按标题与列表结构化展示，主操作常驻顶部
