## Zotero 联动（全新，本期只读）

- 设置页新增「Zotero 联动」：连接自检、端口配置与状态栏连接灯；本地 API 不可写时给出开启引导，离线只降级不阻断编译
- 题录自动同步：Zotero 里改题录或增删条目，项目 `.bib` 与引用补全 / 悬浮卡 / 引用校验自动更新，不用再手动导出、导入、点刷新
- `Ctrl+Alt+K` 引用浮层：模糊搜索作者 / 年份 / 标题 / DOI / citekey，多选条目、6 种引用命令（含星号变体）、页码与前后缀编辑，插入后焦点留在编辑器
- 浮层分类下拉默认定位到 Zotero 当前打开的分类，也能切到「全部文献」全库搜索；本地 `.bib` 条目始终保留在候选里
- 插入即写入：插入还没进 `.bib` 的 Zotero 条目时自动补写一条 BibTeX，不需要预先配置绑定；写入失败只提示、不阻断插入
- 受管 `.bib` 字段级同步：Zotero 非空字段覆盖同名项，手写 note、独有字段与 citekey 一律不动；定时同步可选开启（默认关）
- BibTeX / biblatex 自动检测与原地切换：按项目实际使用的引擎输出字段名（`journal` ↔ `journaltitle`、`year` ↔ `date`），切换时一并改导言区并原地转换已有条目，先预览再落笔
- 引用侧栏新增「Zotero 文献库」：按分类浏览、按文本筛选、逐页加载，可直接插入引用或跳回 Zotero；支持引用条目反向跳转、全文 / 条目 / 网页分流打开，以及 CSL 引文预览与复制（内置 GB/T 7714、APA、Chicago、IEEE、MLA、Vancouver、Nature）
- 样式映射一键切换：CSL 样式与 `\bibliographystyle` / biblatex `style=` 互转，只改导言区一处，不自动重编译

## 偏好设置

- 偏好设置可作为编辑区标签页常驻，与弹窗形态一键互切，边改边看不必反复开关
- 左侧导航按「工作区 / 偏好 / 系统」三组重整，加分组标题与选中态色条；小节标题、设置行 hover 与间距按亮暗双主题重新配平
- 标签页形态可记住停留页签，不响应 Esc 与遮罩；保存推进快照并提示，取消回滚但保留面板
