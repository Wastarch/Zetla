# 更新日志
## [0.4.4] - 2026-11-22

### 🎉 新增
- 项目树支持多选：`Ctrl` 加减选、`Shift` 范围选、`Ctrl+A` 全选、`Esc` 清空，复制 / 剪切 / 删除可对整组文件一次完成，多选拖拽时影像上会显示数量徽标
- 标签页新增右键菜单：关闭其他 / 关闭右侧 / 关闭已保存 / 全部关闭、复制路径与相对路径、在系统文件管理器中显示（macOS 为「在访达中显示」）、侧栏树定位
- `\input` 类命令一键跳转与创建：`\input` / `\include` / `\subfile` / `\lstinputlisting` / `\verbatiminput` / `\bibliography` / `\addbibresource` 的目标路径 `Ctrl+点击` 直接打开；文件不存在时确认后一键创建（缺失的父目录自动补齐）
- `\input{}` 花括号内路径补全：目录逐级下钻（空目录也会列出）、文件名按命令类型自动匹配后缀；键入 `{` 或光标点进空括号都会自动拉起候选

### 🔧 优化
- 大纲更准：注释里的章节命令不再收录；`\part` 与 `\input` 子文件的章节按文档真实位置交错排序，不再整体前置
- 链接提示更清爽：按住 `Ctrl` 时只有鼠标悬停的那一条命令显示下划线，不再全篇标线
- 引用补全支持 biblatex 的 `\footcite` / `\smartcite` / `\fullcite` 等命令
- 项目树空白处点击取消选中；新建文件 / 文件夹的目标目录跟随当前选中项
- 新建文件与删除的确认改为应用内弹窗，风格与全局一致

### 🐛 修复
- 修复按住 `Ctrl` 时链接下划线不显示的问题
- 修复项目树多选时 `Ctrl` / `Shift` 点击被拖拽改选抵消的问题
- 修复大纲中 `\part` 被整体排到子文件章节之前的问题
