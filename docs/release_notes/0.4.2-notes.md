# 更新日志

## [0.4.2] - 2026-11-21

### 🎉 新增

- 编译产物可以输出到单独目录了：项目设置里填「输出目录」，PDF、日志、同步文件都会落进去，主目录保持干净；多个项目各自打开的标签页，重启后也会原样恢复
- 大纲上方新增「构建文件」面板：`.aux`、`.log`、`.pdf` 等编译产物集中列出，点一下就在标签里打开，不用再去文件夹里翻
- 绘图：打开绘图模块会自动扫描并导入项目里已有的 TikZ 源码，源码中的 `tikzpicture` 环境旁多了一个 ✎ 按钮，点它可直接跳到绘图工作台继续画
- 项目树、编辑器标签页现在都可以拖动排序：标签页拖一拖换顺序，项目树里的文件可以拖到别的位置（按住 `Ctrl` 为复制）；拖动时有跟随鼠标的影子
- 引用浮层与引用侧栏可以自定义列：右键表头勾选显示哪些列（作者 / 年份 / 刊物 / citekey 等），拖列边界调宽度；默认引用命令也能在 ⋯ 菜单里直接选
- 项目树根目录新增「小眼睛」开关，可显示以点开头的隐藏文件；根目录的操作图标改为一直显示

### 🔧 优化

- 大纲移到资源管理器底部，可折叠、可调高度，和项目树共用一块区域
- 引用浮层工具行改成单排，整体更矮；引用侧栏的 Bib 格式与引用命令统一收进 ⋯ 菜单的「标签 + 下拉框」，界面更清爽
- 全站折叠与下拉箭头统一成同一种样式，代码折叠箭头也紧贴近代码；括号匹配与代码折叠开关现在真正生效
- 编译输出目录参数做了兼容处理，中文路径的项目也能正常用 XeLaTeX / biber 编译

### 🐛 修复

- 修复设了输出目录后编译失效、产物仍落回项目根目录的问题
- 修复中文路径下 biber 报错、XeLaTeX 因输出目录非 ASCII 而编译失败的问题
- 修复「清理构建产物」可能误删用户导入 PDF 的问题：现在只删与主文件同名的产物，其他 PDF 与源码一律保留
- 修复「查看」菜单中模块视图项排列顺序不对、滑块样式异常的问题

### ⚠️ 重要变更 / 不兼容更新

- 「清理构建产物」的行为有变化：改为清除**全部**同名编译产物（含主 PDF）并先弹清单确认，不再保留旧版的 `main.pdf`；只想清中间文件时请继续用「编译后自动清理」。用户导入的 PDF、图片与源码不受影响
