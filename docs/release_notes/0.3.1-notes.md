## 拼图支持粘贴 / 拖入图片
- 拼图侧栏与中心「拼图预览」标签页都能直接 Ctrl+V 粘贴截图，或把图片文件拖进来；再次粘贴 / 拖入会累积进同一张拼图
- 修复桌面端粘贴、拖入没反应：改用 Tauri v2 的 tauri://drag-drop 事件、按 devicePixelRatio 换算落点坐标、让面板可聚焦，并给命中区域加虚线高亮
- 补齐 macOS / Linux 适配：兼容 WKWebView / WebKitGTK 只给 items、空文件名与 UTI 类型（如 public.png）的情况，双通道去重后一次拖放只导入一次

## 图片路径与目录
- 图片默认目录由 figure 统一改为 figures，Windows / Linux / macOS 都落在项目根；存量项目沿用原有配置，不会静默迁移
- 修复 macOS 上粘贴图片生成的相对路径多出 ..，以及拼图第二张图片误报「请在活动的 .tex 文档中插入图片」
