# 常见问题

> 本文档从 README 抽离。返回 [README](../README.md)。

**安装时被 SmartScreen 拦截？**
安装包尚未做代码签名，属正常现象。点「更多信息 → 仍要运行」。若企业策略禁止，可自行从源码构建。

**启动后提示未检测到 TeX？**
两种方式：在引导面板里自动安装 TeX Live；或先手动安装，再用「指定/接管已有安装…」选择 TeX Live 根目录 / `bin` / `bin\windows`，最后重新检测。

**编译报错找不到 `xelatex` 或 `latexmk`？**
说明当前引擎不在检测路径中。打开「偏好设置 → 编译设置 → 检测 / 引导…」重新检测或接管安装目录；确认安装包含 XeLaTeX 与 `latexmk`（TeX Live 完整安装自带）。自定义流程里写错命令时，日志会提示「未找到命令：xxx」，把 `command` 改成 `PATH` 能找到的名字或 exe 完整路径即可。

**怎么切换编译流程？切换后会一直生效吗？**
点标签栏右上角 **▾**，或右键 / 长按状态栏编译按钮，选一个流程即可：会立即编译一次，并把它记为**当前流程**。之后 ▶、`Ctrl+B`、保存时自动编译与实时预览都跟随它，直到你换一个或选菜单首项「按默认流程编译」。当前流程存在本地 `localStorage`，不写入配置文件。

**「默认流程」和「当前流程」有什么区别？**
「默认流程」是设置页 `Ctrl+,` → 编译设置里设定的 `defaultRecipe`，写进全局配置；「当前流程」是菜单里切换的选择，优先级更高但只存本地、不写配置文件。菜单选「按默认流程编译」会清掉当前流程，回到默认流程。完整优先级见[自定义编译流程指南](自定义编译流程指南.md) §3。

**想加一步 `makeglossaries`、改用 `bibtex`、或让某个流程固定用 pdfLaTeX 怎么办？**
在「偏好设置 → 编译设置 → 编译流程（Tool / Recipe）」里新建流程并编辑步骤：步骤下拉直接选 XeLaTeX / pdfLaTeX / LuaLaTeX / latexmk / biber / bibtex，选具体引擎即固定该引擎；自定义命令、参数与 `when` 条件在点开的「高级：JSON 编辑（完整字段）」里写。指南里有可直接粘贴的配方。

**自定义流程是项目级的吗？换项目会丢吗？**
不是项目级。工具、流程与默认流程只保存在全局 `%APPDATA%\Zetla\config.json`，对所有项目生效；项目 `.ltex/config.json` 仍只管主文件与引擎。换项目不会丢，需要按项目区分时可用 ▾ 菜单临时切换当前流程。

**为什么编译报错后没有走我配的「失败回退」？**
`fallback` 只处理**工具无法启动**（命令找不到、`latexmk` 缺可用 Perl、子进程启动失败），源码编译错误（命令返回非 0）会直接标记本次编译失败。想让某一步的失败不阻断流程，可给那个 Tool 设 `ignoreErrors: true`。

**老版本配置里的固定步骤（`build.steps`）还能用吗？**
能。后端会把它静默合成一个兼容流程，编译行为不变；但设置页已移除旧编辑器。想改用新流程，按[指南](自定义编译流程指南.md)新建一个 Recipe 并设为默认，或直接删掉 `config.json` 里的 `steps`。

**自动安装 TeX Live 很慢 / 占空间？**
基础方案约 1.5 GB，完整方案约 5 GB，耗时取决于网络。安装器会自动尝试国内镜像；中途取消会清理本次新建目录。后续补包可用 TeX Live 自带的 `tlmgr`。

**打开 GBK 老文档会乱码吗？**
不会。读取时自动识别 UTF-8 / GBK，保存时保持原编码与原换行符。

**输入 `\cite{` 没有补全候选？**
请确认项目已打开且项目内存在 `.bib` 文件；`.bib` 保存或外部修改后索引会自动刷新。Zotero 用户可先导出 BibTeX 文件，再从「引用」视图的「导入参考文献…」加入项目。

**切换项目后，之前的标签页去哪了？**
项目切换器会在本次运行内按项目缓存标签页与活动标签，切回时恢复；重启 Zetla 后只恢复上次打开的项目及其标签页，其他项目从欢迎页进入。

**拖入图片没有反应？**
请确认已打开项目、当前是 `.tex` 标签，且文件为常见图片格式（PNG / JPG / WebP 等）。项目未打开或当前是图片 / PDF 等只读标签时会给出提示，不会插入源码。

**拖入多张图片后为什么没有直接插入源码？**
多图会进入拼图工作流：侧栏切到「拼图」并打开中心「拼图预览」Tab。确认布局后，`subfigure` 模式点「生成 subfigure 代码」、合成模式点「合成单图并插入」，才会写入目标 `.tex`；单图仍会直接插入完整的 `figure` 环境。

**选完图后 `figure/` 里为什么没有文件？**
拼图采用延迟落盘：选图只记录来源。`subfigure` 模式点「生成 subfigure 代码」时才把真正进入代码的图片复制到图片目录；合成模式点「合成单图并插入」时才写出合成后的 PNG。这样实验性选图不会污染项目；已生成的代码与图片会正常保留。

**合成图的文件名怎么定？会覆盖已有文件吗？**
优先用侧栏「图片标题」：非空时保存为 `<标题>.png`（自动清洗 `/ \ : * ? " < > |` 等非法字符，保留中文）。标题为空时保存为 `fig-<首个图片 slug>-composite.png`。同名文件会**直接覆盖**，不弹冲突框，覆盖前请确认旧图不再被其他文档引用。

**合成图的子标题能编辑吗？支持公式吗？**
子编号 `(a)` 与子标题会烘焙进 PNG，合成后不能在 LaTeX 里单独编辑或重排；需要可编辑的子标题请改用 `subfigure` 模式。子标题里的 `$...$` / `$$...$$` 会经 MathJax 渲染为自包含 SVG 后画入图片，导出 PNG 同样带公式。首次合成前会轻确认，可勾选「不再提示」记住选择。

**生成的代码提示缺少 `subcaption`？**
`subfigure` 环境需要 `subcaption` 宏包。侧栏检测到缺失时会显示横幅，点「加入导言区」即可在 `\begin{document}` 前插入 `\usepackage{subcaption}`；也可以手动添加。

**编辑器里的 `✎` 是什么？**
这是环境反向编辑标记，位于公式 / 表格环境的开头定界符右侧。点击会把该环境载入对应面板，改完点「更新」原地替换；若源码在载入后被手改过，会因指纹不一致而拒绝覆盖，此时重新点 `✎` 载入即可。

**表格能直接导入 Excel（`.xlsx`）吗？**
不能直读 `.xlsx`。请先在 Excel 中另存为 CSV，再用表格面板「导入 CSV」；也可以直接从 Excel 复制区域，在网格中 `Ctrl+V` 粘贴。

**外部编辑器改了文件，Zetla 里怎么同步？**
编辑器顶部会出现「重新加载 / 忽略」提示条；点「重新加载」读取磁盘内容，点「忽略」保留当前编辑内容。

**清理辅助文件会删掉 PDF 或源码吗？**
不会。只删除白名单内的辅助文件，`.tex/.bib/.cls/.sty` 与 PDF 等受保护后缀始终保留；自定义清单误填受保护后缀也会被后端拦截。

**编译后自动清理怎么开？会清理哪些文件？**
到「偏好设置 → 编译设置」打开「编译完成后清理辅助文件」。默认按 14 项辅助后缀清理，也可用 chip 增删自定义后缀；手动「清理辅助文件」与编译后清理共用这份清单。只有编译成功才会执行。

**新建文件只能建 `.tex` 吗？**
不是。新建文件对话框提供 `.tex` / `.bib` / `.cls` / `.sty` / `.md` / `.txt` / 无后缀快选，也可以直接在文件名里输入任意后缀；文本文件创建后自动打开，图片 / PDF 只创建不打开。

**打开 `.md`、`.json` 或没有后缀的文件为什么没有语法高亮？**
这些扩展名未收录，会按纯文本渲染。可点击状态栏「文档语言」chip 手动指定档位，或选择「恢复自动识别」；手动指定仅在本次运行内有效。

**右侧小地图怎么关掉？**
「偏好设置 → 编辑器 → 显示小地图」关闭即可。小地图仅对文本缓冲区生效，图片 / PDF 标签不会显示。

**章节文件里全是「缺少 document 环境 / 缺少参考文献」的报错，怎么关？**
不用关，0.2.1 起这些**整篇级检查只对主文件生效**。被 `\input` 引入的章节片段不再误报缺少 `\documentclass`、`\bibliography`、引用或宏包；片段内的环境配对、括号、重复 label 与数学模式仍会检查。当前还没有逐项关闭诊断的开关，遇到误报欢迎提 Issue。

**`\input{chapter/chap01}` 能像 `\cite` 一样跳转吗？**
可以。按住 `Ctrl` 点击 `\input` / `\include` / `\subfile` 的花括号内容即可打开目标 `.tex`；路径按「当前文件目录 → 主文件目录 → 项目根」解析并自动补 `.tex`。目标不在项目树内或文件不存在时只会提示，不会创建文件。

**语法高亮颜色能自己改吗？改完重启还在吗？**
能。「偏好设置 → 外观与保存 → LaTeX 语法高亮 → 自定义配色…」可调整 12 个语义分组的亮 / 暗颜色，也能一键套用 Zetla 默认 / GitHub / Dracula / Solarized / Nord。配色写入 `%APPDATA%\Zetla\config.json`，重启后保留；也可导出 JSON 备份或分享。当前仅作用于 LaTeX 档，BibTeX / `.bst` / `.log` / 纯文本仍用内置配色。

**日志面板挡住编辑区了，能调小吗？**
拖拽日志面板顶部边缘即可调整高度（120–560px，编辑区至少保留 180px），高度会被记住；也可用「视图 → 隐藏日志面板」或状态栏按钮收起。

**编译日志里的长路径、长报错为什么不再被折成好几行了？**
0.2.3 起 Zetla 会给编译进程放宽 TeX 的日志列宽限制（`max_print_line` 等），长路径与长报错保持完整一行，换行交给日志面板宽度决定；拖宽面板即可读到更多。该设置只对 Zetla 发起的编译生效，从外部终端编译生成的 `.log` 仍按 TeX 默认列宽折行。

**终端里为什么找不到 `xelatex` / `latexmk`？**
终端会复用编译引擎的搜索目录（受管 TeX 目录 → 系统 `PATH` → 进程 `PATH`），与一键编译同源。若仍找不到，先到「帮助 → TeX 环境检测…」确认 TeX 已被识别；刚安装或刚修改过系统 `PATH` 时，需要新建终端会话或重启应用让新环境生效，也可以先用完整路径运行一次确认。

**终端会话关闭后还能恢复吗？**
不能。终端会话只存在于本次运行，关闭会话或退出应用即回收对应 PTY 进程；重要命令请自行保存输出。误关后可以点页签栏右端 **＋** 新建会话重新执行。

**实时预览为什么默认关闭？会不会很卡？**
实时预览每次停顿都会整篇编译，比手动编译更吃 CPU，因此默认关闭。开启后可按项目规模把延迟调到 800–1200 ms；连续输入时只保留最新一次任务（latest-wins），旧任务会被终止，不会堆积。

**跨文件替换能撤销吗？**
不能。全局搜索的跨文件替换会直接写盘，执行前会确认并提示受影响文件数。建议替换前先提交或备份；单文件替换仍可用 `Ctrl+Z` 撤销。

**代码片段怎么新增或导入？**
「偏好设置 → 代码片段」可新建自定义片段，填触发词与模板后保存即生效；也支持导入 JSON 片段包（覆盖或合并）。触发词不能含反斜杠或空白，自定义上限 500 条。中文输入法占用快捷键时，可用菜单「插入代码片段…」。

**编辑工具栏为什么不显示？**
快捷工具栏只对 `.tex` 文本缓冲显示；图片 / PDF 查看器与 `.bib`、`.log` 等标签不显示，切回 `.tex` 标签即可。

**矩阵怎么设置行列数？**
在「公式 → 快捷工具 → 数组矩阵」点任一矩阵图标，会就地展开设置浮层：可切换无括号 / 圆括号 / 方括号 / 行列式 / 分段函数，调整 1–10 行/列（`cases` 固定 2 列），预览确认后写入编写区；右键图标可直接插入编辑器。

**公式编写区的「源码 / 可视化」有什么区别？**
两者共用同一份 LaTeX。源码模式上方编辑源码、下方实时预览，点空槽只定位光标；可视化模式把渲染结果作为主编辑面，点击 `\Box` 或按 `Tab` 选中槽位后直接输入，首键即替换。复杂嵌套建议回源码模式调整；编写区内容为会话级草稿，不写入项目文件，重启应用后清空。

**窗口没有系统标题栏，怎么移动或最大化？**
拖动顶部中间空白区移动窗口，双击最大化 / 还原；右上角提供最小化、最大化与关闭，左右下边缘及右下角可拖拽缩放。关闭时仍会检查未保存文档。

**宁夏大学学位论文模板怎么用？**
欢迎页「从模板新建」→ 模板库选「宁夏大学学位论文」→「用此模板新建」，填写 23 项变量（中英文标题、培养单位、导师、学号、分类号、密级等）并选择出稿格式、盲审封面、书脊与数学字体后生成。模板使用 `nxuthesis.cls` + XeLaTeX，需要 TeX Live 含 `ctex` / `natbib` / `hyperref` 等宏包；联合导师留空时不会生成对应字段。

**安装时 WebView2 自动安装失败？**
自动安装需要联网。请按提示从 [微软 WebView2 页面](https://developer.microsoft.com/microsoft-edge/webview2/) 手动安装 Runtime 后重新运行安装程序；Windows 10/11 通常已内置，不会触发下载。

**正式版右键为什么没有系统菜单？**
正式版屏蔽了 WebView2 原生右键菜单，避免与应用自绘菜单冲突并避免暴露调试入口。项目树、引用面板等自绘菜单不受影响；文本框内复制 / 粘贴请用 `Ctrl+C` / `Ctrl+V`。

**为什么项目设置里的「输出目录」是灰的？**
当前版本编译产物固定落在主文件同目录，输出目录支持留待后续版本；该字段会保留原值，不会清除。

**卸载后配置和 TeX 还在吗？**
应用内安装的 TeX Live 位于系统本地数据目录：Windows 为 `%LOCALAPPDATA%\Zetla\tex\`，macOS 为 `~/Library/Application Support/Zetla/tex/`，卸载时可选择是否保留。应用配置的准确位置可在「偏好设置」底部查看。

**还有哪些功能在规划中？**
绘图组件（M2）、拼图 PDF 导出与 PDF 子图选页、条件模板、代码格式化 / 拼写检查、多项目并排工作区（同时打开多个项目）、输出目录支持、表格 `.xlsx` 直读等仍在规划中，相关入口会置灰并标注计划。以下能力已在 `0.2.8` 提供：项目管理与模板库、模板库新建衔接、宁夏大学学位论文模板、表格编辑器、图片插入与图片 / PDF 标签页、拼图（subfigure / 合成单图）、可编排编译流程（Tool / Recipe、流程菜单、编译步骤进度）、内置终端（多会话、终端设置、复用编译环境 PATH）、语言档位与纯文本兜底、小地图、可自定义 LaTeX 语法高亮（主题方案 / 导入导出）、单文件查找替换与全项目搜索、编辑器快捷工具栏、自定义标题栏、实时预览、代码片段（补全 / Tab 直展 / 选中包裹 / 管理 / 导入导出）、编译日志完整换行、日志面板停靠与高度记忆、章节片段诊断去噪、`\input` 跨文件跳转、新建任意后缀文件、外部改动重载、清理辅助文件与自定义清单、编译后自动清理、保存时自动编译、自动更新、多编译引擎（XeLaTeX / pdfLaTeX / LuaLaTeX）、SyncTeX 双向跳转、亮暗主题、公式与符号面板（KaTeX 渲染、矩阵自定义行列、源码 / 可视化编写、136 条公式模板、环境反向编辑）、BibTeX 参考文献（补全 / 预览 / 跳转 / 校验 / 管理 / 手动刷新）。
