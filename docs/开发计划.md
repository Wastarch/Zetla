## 0. 总体节奏

```
M0 MVP 完整闭环（≈2–3 周） → M1 创作增强（≈2–3 周） → M2 绘图组件（≈1–2 周） → M3/M4 按需
```

**M0 = MVP**：完成「打开项目 → 新建 TeX 文档 → 编写代码 → 一键 XeLaTeX 编译 → 查看 PDF 预览」完整闭环；**只保留核心链路**，砍掉所有非必要功能（✅必做 / ❌后置清单见 `docs/MVP.md` 与开发文档 §0.1）。

原则（沿用开发文档 §11）：

1. **切片提交**：每个任务是一次可独立运行验证的小切片，跑通再下一个，不攒大 diff。
2. **只做核心链路**：M0 只交付 MVP 必做项（项目树、多标签编辑器、一键编译+报错跳转、PDF 预览、三栏布局、基础 IPC），R5/R6/R7/绘图/完整环境引导等一律进 M1/M2。
3. **类型即协议**：`src/types/` 与 Rust struct 一一对应，改一边必同步另一边。
4. **每轮 Linux/WSL 过一眼**：WebKitGTK 是渲染差异集中区，提前拦截。
5. **真实数据自测**：M0 收尾按开发文档 §12.1 MVP 验收清单跑全流程，错误定位用真报错文档，不绕过验收。

### 编译链公共约定（M0-9/10/11 共用，M0-3 已定死，不改）

**数据结构**（与 `src/types/compile.ts` 对齐，Rust 侧 `#[serde(rename_all = "camelCase")]`）：

```
TexDistInfo  { found, distribution?, version?, engines[], recommended? }
CompileProgress { stage, pct, current }
TexError     { file, line, col?, raw, readable, fix?, hint? }
CompileResult { status, pdfPath?, errors[], passes, durationMs }
```

**事件名**（Rust 字符串必须与前端 `src/ipc/events.ts` 的 `RustEvents` 完全一致）：

- `compile_progress` — stage: prepare / running / parsing / done，current: 实时日志行
- `compile_finished` — CompileResult 负载，经 `AppHandle.emit(...)` 推送

**Rust 依赖引入计划**：

| crate | 引入切片 | 用途 |
|---|---|---|
| `which` | M0-3 ✅ | 跨平台 PATH 查找可执行文件 |
| `tokio`（process/macros/time） | M0-9 | 异步 spawn 子进程、流式读 stdout/stderr |
| `regex` | M0-10 | 日志解析 |

**前置条件**：

- M0-11 错误定位原计划做"最小只读预览"，因编辑壳（M0-4~6）提前完成，届时直接用正式编辑器的 `gotoLine`，**只读预览方案作废**
- M0-9 的编译按钮/编译状态栏在 M0-6 已放好占位，M0-9 直接接通

**P0 简化取舍**：

- **不做进度百分比**：LaTeX 无可靠进度，仅推 stage + 当前行
- **单并发编译**：全局锁排队，多项目并发放 M1+
- **synctex 只产出不跳转**：`-synctex=1` 生成产物，双向跳转在 M3
- log 错误行号在多文件场景可能指向内部文件，P0 以规则表命中的主源文件为准，精细映射后置

### M0-9 多遍编译（1–2 天）

### M0-10 日志解析（1 天）

- `parse_tex_log(log_path)` → `Vec<TexError>`（独立命令，便于单测）
  - 定位模式：`l.N`、`./file.tex:N`、`!<name>.tex=N`
  - log 编码用 `String::from_utf8_lossy`（xelatex 的 log 对 UTF-8/latin1 混杂，可读即可）
- **规则表 15–20 条**，每条映射 `readable`（大白话）+ `fix`（修复建议）+ `hint`：
  - `Missing $ inserted` → 缺数学模式
  - `Undefined control sequence` → 命令不存在/拼写
  - `Environment ... undefined` → 环境未定义
  - `LaTeX Error: File 'xxx.sty' not found` → 宏包缺失
  - `Runaway argument?` / `File ended while scanning` → 缺 `\end`/缺大括号
  - `There were undefined references` → 缺编译遍数
  - 中文字体/CJK 相关报错 → 字体缺失
  - ……
- 单测：**3 份真实 .log 样本**（缺 `$`、缺 `\end`、缺宏包），断言 file/line/规则命中
- 编译管线接入：`compile_finished` 带上解析后的 `errors`
- ✅ 验收：单测全绿；编译真实报错文档 errors 非空
- commit：`feat(m0): M0-10 日志解析（定位模式+规则表+编译接入）`
