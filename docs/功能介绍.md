# 功能介绍

> 本文档从 README 抽离，集中列出 Zetla 的全部功能。返回 [README](../README.md)。

- **项目管理**：无项目时显示欢迎页与最近项目列表（置顶 / 归档 / 重命名 / 导出 zip / 删除）；`Ctrl+R` 项目切换器（切换时保留各自标签页）；项目设置可改名称、描述、类型、主文件、引擎、图片目录与资源树排除规则
- **项目与编辑**：打开 / 新建项目、新建任意后缀文件（类型快选）、项目树右键操作、多标签编辑（撤销栈独立）、自动保存、外部改动重载提示、GBK 文档不乱码
- **编辑器体验**：LaTeX / BibTeX / BibTeX 样式 / TeX 日志 / 纯文本五档高亮，未收录扩展名按纯文本渲染；状态栏语言 chip 可手动切换或恢复自动识别；右侧小地图可点击滚动、跟随主题，可在设置中关闭；LaTeX 语法高亮支持 12 个语义分组自定义、亮暗双色、主题方案与导入导出；`Ctrl+F` 查找替换（大小写 / 整词 / 正则 / 替换全部）与 `Ctrl+Shift+F` 全项目搜索
- **编辑工具栏**：标签栏下方提供格式组（加粗 / 斜体 / 下划线 / 删除线）、插入组（链接 / 图片 / 列表 / 公式 / 表格）与章节层级下拉，仅 `.tex` 文本缓冲显示
- **模板库**：6 套内置模板（英文文章 / 中文文章 / 多文件毕业论文 / 多文件幻灯片 / 简历 / 宁夏大学学位论文），支持多文件生成与动态变量表单；可另存当前项目为模板、导入目录或 zip、删除用户模板
- **代码片段**：22 条内置片段覆盖结构 / 章节 / 浮动体 / 数学 / 文本；触发词补全 + `Tab` 直展，`$SELECTION` 包裹选中文本，占位符 `Tab` 跳转；设置页可增删改、导入导出 JSON，模块可整体停用
- **一键编译 / 可编排流程**：内置两个不可删的编译流程——`latexmk`（缺 Perl 或找不到 latexmk 时自动回退）与 `engine-direct`（引擎多遍 + 条件 biber）；流程由 **Tool / Recipe** 数据驱动，可自定义工具命令与参数、占位符、按文件/日志/环境变量触发的 `when` 条件步骤、按 `.log` Rerun 提示收敛重跑（`repeat.untilStable`）、失败回退链（`fallback`），步骤直接写 XeLaTeX / pdfLaTeX / LuaLaTeX 等真实引擎名即可固定引擎；标签栏 ▶|▾ 与状态栏右键/长按可随时切换当前流程。实时日志面板停靠在编辑区下方、高度可拖拽并记忆，结构化报错可点击跳转行列；日志不再被 TeX 按 79 列硬折行，长路径与长报错可完整阅读；引擎可选（XeLaTeX / pdfLaTeX / LuaLaTeX），支持保存时自动编译、**实时预览**、编译后按自定义清单清理辅助文件；编译期间状态栏进度条旁实时显示当前流程步骤（如 `XeLaTeX（1/4）`）
- **内置终端**：日志面板新增「终端」页签，基于 xterm.js + portable-pty，Windows 默认 PowerShell（`-NoLogo`）、Linux / Unix 跟随 `$SHELL`；支持多会话，每个会话拥有独立缓冲与 PTY，切换页签或会话不销毁进程；终端 PATH 复用编译引擎搜索目录，`latexmk` / `xelatex` 与一键编译同源；主题跟随亮暗模式，自适应面板尺寸，输出按帧合并防卡顿。页签栏右端提供新建 / 操作菜单 / 清屏 / 关闭，终端区右侧可切换会话；`Ctrl+滚轮` 缩放当前会话字号，支持选中自动复制与右键粘贴
- **终端设置**：设置 → 编辑器 → 终端可配置字体（留空跟随编辑器）、字号 8–24px、光标样式与闪烁、回滚行数（1000 / 5000 / 10000 / 50000）、选中自动复制、右键粘贴、默认工作目录（当前项目根 / 用户主目录）
- **图片与附件**：拖拽 / 粘贴 / 菜单插入图片并自动生成 `figure` 环境；图片与 PDF 可在代码标签页只读查看，图片支持缩放与平移
- **拼图**：多图选择 / 拖入 / 粘贴自动进入拼图工作流。`subfigure` 模式生成可编辑的子图网格代码；「合成单张图片」模式在 Canvas 中实时合成，把子编号与子标题（含 LaTeX 公式）烘焙进白底 PNG 后以单图直插。侧栏统一控制行列、间距、标题、缩放、裁剪与对齐
- **绘图（TikZ）**：活动栏「绘图」视图打开 `diagram://editor` 工作台，**TikZ 源码是唯一真源**——画布上的每次拖拽、改样式、调尺寸都以最小补丁写回源码，与键盘编辑共用同一条撤销栈——
  - **布局与通道**：Tab 内三布局（仅画布 / 仅源码 / 左右分屏，比例可拖拽并记忆）；双预览通道——**本地即时**（内置 tikz-editor 引擎，160ms 防抖 + LRU 缓存，可拖拽写回）与 **XeLaTeX 精确**（秒级，与导出一致，只读）。引擎覆盖不到的构造有常驻「预览不完整」提示与可点诊断，可一键切精确通道
  - **基础图元**：选择 / 直线 / 箭头线 / 矩形 / 圆 / 椭圆 / 多边形 / 折线 / 圆弧 / 圆点 / 文本共 11 个工具，按选择 · 几何 · 线 · 节点分组；多点工具（多边形 / 折线 / 圆弧）逐点单击、双击或 `Enter` 收尾、`Esc` 取消
  - **编辑操作**：拖控制点写回坐标、选中框 8 点柄缩放（矩形按角 / 边语义锚对侧）、旋转柄旋转；`Delete` 删除、方向键微调（`Shift` 大步）、`Ctrl+C` / `Ctrl+V` / `Ctrl+D`；空白处框选、`Shift` 加减选；多选一次撤销
  - **属性与尺寸**：颜色 / 线宽 / 箭头 / 线型 / 填充五类属性下拉 + 自定义值，只改选项 span；节点 W / H 数值面板（cm / pt）与 8 点柄按轴改写 `text width` / `minimum height`，可批量套用到同类节点；能力矩阵判定不可写的图元显示挂锁与理由，不静默改语义
  - **公式与就地编辑**：节点内 `$...$` / `$$...$$` 由 MathJax 渲染为公式字形，混排按实测字形宽度排版；双击节点弹出输入框，只替换 `{...}` 内容 span，可写中文、公式与换行
  - **组织与对齐**：图层面板（选中 / 编组 / 显隐 / 锁定 / z-order 置顶置底）为唯一图元清单；虚拟分组支持命名 / 嵌套 / 折叠（只存本机，不写进源码）；对齐 / 等距分布、拖动时智能参考线吸附、1cm 网格与标尺、吸附网格、数值旋转缩放
  - **画布与视角**：固定画布 A4 / A5 / Letter / B5 或自定义（宽度取正文宽，高度不超过纸张正文高），滚轮锚点缩放 0.25×–16×、抓手平移、适应画布 / 适应内容；缩放只改视角，不动 `viewBox` 真源
  - **导出与插入**：PNG / SVG / PDF 导出到项目图片目录或「另存为」；可开「按画布尺寸导出」保留固定留白（只在派生片段加 bounding box，绘图源码一字不改）；一键插入 `figure` 环境并按画布宽度设 `width`；「仅保存文件」只落盘不改主文档
  - **图片素材**：选 PNG / JPG / PDF 暂存到项目图片目录（默认 `figure/`）→ 画布单击放置 → 写回 `\includegraphics` 并自动补 `graphicx`；本地画布显示真图，8 点柄缩放改写 `width` / `height`；同名文件可选重命名或覆盖（覆盖既有文件二次确认），未插入主文档的暂存图在关闭绘图 Tab 后清理
  - **安全与只读**：XeLaTeX 通道下所有写源码入口统一置灰并给出理由；SVG 走元素 / 属性白名单消毒；精确预览与导出固定 `-no-shell-escape`，危险构造直接拒绝
- **表格编辑**：侧栏「表格」视图网格编辑，支持合并 / 拆分、对齐、三线表 / 全框线 / 无线、CSV / TSV 导入、Excel 粘贴与光标处表格反向回填
- **双向跳转**：编辑器 Ctrl+点击跳转 PDF 对应位置并高亮，PDF Ctrl+点击回跳源码行列（SyncTeX）；`\input` / `\include` / `\subfile` 也支持 Ctrl+点击直接打开目标 `.tex`
- **大纲导航**：侧栏自动梳理 `\input`/`\include` 链中的章节结构，层级展示、点击直达
- **参考文献（BibTeX）**：自动扫描项目内所有 `.bib` 文件并建立索引；`\cite{` 自动补全、悬浮预览、Ctrl+点击跳转条目、`.bib` 专属高亮、重复 key / 缺失引用校验；侧栏「引用」视图支持按文件分组、搜索、手动刷新、导入 `.bib`、条目预览与反向引用
- **公式与符号**：侧栏「公式」视图整合符号库、矩阵入口、公式模板、编写区与 KaTeX 预览——
  - **快捷工具**：10 个分类、354 个符号，按中英双语二级子类分区；符号以 KaTeX 渲染并视口懒加载，长名称图标单独设定宽度
  - **矩阵**：数组矩阵提供无括号 / 圆括号 / 方括号 / 行列式 / 分段函数 5 种入口，点击图标就地设置 1–10 行/列（`cases` 固定 2 列），带实时预览
  - **公式模板**：136 条内置公式、10 个分类；条目两行式展示，支持逐条高度参数，长公式不会挤压
  - 单击写入编写区，右键可直接插入编辑器 / 写入编写区 / 复制 LaTeX；顶部齿轮切换行内或编号；编写区底部提供「插入编辑器 / 复制 LaTeX」，`Ctrl+Enter` 快速提交
  - 编写区支持**源码 / 可视化**：源码模式上源码、下预览；可视化模式点击 `\Box` 或按 `Tab` 切换槽位直接输入；拖拽分割线调整高度，字号 10–50px，`Ctrl+滚轮` 缩放
  - **环境反向编辑**：公式 / 表格环境开头常驻 `✎` 徽标，点击载入对应面板；「更新」前校验源码指纹，原地替换
- **PDF 预览**：基于 PDF.js，支持缩放、翻页、页内查找、缩略图与目录侧栏，可与编辑区拖拽分栏；图片 / PDF 也可在代码标签页以只读方式打开，右侧预览仍随编译刷新
- **自动更新（三平台）**：启动自动检测新版本（Gitee / GitHub 双源回退，Rust 侧请求避免 WebView CORS），清单为 `latest.json` 协议 v2——`platforms` 按平台键给条目，顶层 `installers` 保留给只读这一项的老客户端；发现新版本时帮助菜单显示红点并在「关于 Zetla」提供更新——
  - Windows：下载后拉起 Inno 安装向导（安装包未签名，被拦截点「仍要运行」）
  - Linux AppImage：同目录 copy → 备份 → `rename` 原子覆盖 → 拉起新进程，失败自动回滚
  - Linux deb / rpm 安装版：只给「下载安装包」，下载后交系统安装器（`xdg-open` → GDebi / GNOME Software / Discover），不自行提权、不覆盖 `/usr`
  - macOS：解压 `app.tar.gz` → 退出后由脚本 `ditto` 换包 → 清 `com.apple.quarantine` → `open -n` 自动重开，失败自动回滚
  - 关于页结构化展示更新说明（标题 / 列表 / 粗体 / 代码，超 6 行折叠为「展开全部」），版本迁移行显示 `v0.2.8 → v0.3.0`；状态细化为检查中 / 已是最新 / 下载中（百分比 + 已下 / 总量 + 当前源）/ 待安装 / 失败（原因 + 重试 + 去发布页）
- **安装体验**：Windows 安装包自动检测 WebView2 Runtime，缺失时联网下载并静默安装（不增加安装包体积），正式版屏蔽 WebView2 原生右键菜单；Linux 提供 AppImage / deb / rpm 三种产物，macOS 提供 universal `.dmg`（首次安装）与 `.app.tar.gz`（自更新，ad-hoc 签名，首次打开需在系统设置放行）
- **环境引导**：启动自动检测 TeX；未安装可自动下载安装 TeX Live（基础 / 完整方案），也支持接管已有安装。安装器按平台分流——Windows 用 `install-tl.zip`（自带 Perl），Linux / macOS 用 `install-tl-unx.tar.gz` + 系统 Perl（缺失时给出 `apt` / `brew` 提示）；下载并发测速择优、15 秒无数据或低速自动换源、仅同镜像内 `Range` 续传，基础方案补 `collection-langchinese` 修中文空白
- **桌面体验**：自定义标题栏（logo + 菜单 / 拖拽区 / 最小化·最大化·关闭，双击最大化、边缘拖拽缩放；macOS 使用系统红绿灯按钮）、亮 / 暗双主题（可跟随系统）、窗口大小与位置记忆、主窗口最小尺寸 1024×640、布局记忆（含日志面板高度）、启动恢复上次项目（连同上次打开的标签页）、菜单栏与状态栏；应用外壳禁选文字，编辑器和 PDF 正文仍可选中复制
