## Zetla 0.1.2 —— 侧栏更顺手，安装包换代

日常使用体验打磨版：PDF 侧栏合并为一个入口并支持拖拽调宽，修掉编辑器换行与版面的几处问题，正式安装包也从 NSIS 换成 Inno Setup。

### 亮点

- **PDF 侧栏一键开合**：头部原来「缩略图」「目录」两个按钮合并为工具条最左侧的单一开合键（三横线图标），展开时高亮；收起再展开会回到上次停留的缩略图 / 目录页签
- **侧栏宽度可拖拽**：侧栏右侧新增拖拽条，左键拖动即可调宽（110–380px，并始终给右侧 PDF 区留出至少 160px）；宽度随布局一起记住，重启后保持
- **安装包改用 Inno Setup**：安装包与卸载程序换成 Inno Setup，发布者统一为 Max，覆盖升级沿用同一 AppId，配置与偏好不会丢

### 改进

- 设置页固定统一高度（`min(560px, 86vh)`）：切换页签时外框不再跳动，短页留白、长页只在右侧内容区滚动
- 编辑区铺满宽度：滚动条与代码背景贴到最右侧，不再留出多余空白
- 卸载时可选择是否一并删除应用内安装的 TeX Live（默认保留；静默卸载一律保留）

### 修复

- 修复软换行未生效的问题，并让字号 / 字体 / 换行变化后按新字宽重新折行
- 修复 `tauri build` 时仍会尝试下载 NSIS 的问题（安装包改由 `npm run package:inno` 产出）

### 安装 / 升级

1. 下载 `Zetla_0.1.2_x64-setup.exe` 并运行
2. 安装包未签名，SmartScreen 提示时选「更多信息 → 仍要运行」
3. 需要 Windows 10/11 + WebView2 Runtime（Win10/11 通常已内置）
4. 从 0.1.1 升级可直接覆盖安装：安装标识不变，配置、偏好与上次项目都会保留；已安装的 TeX Live 不受影响
5. TeX 可选：不装也可以，首次启动的引导页可直接安装 TeX Live

SHA256：`b5a887d9d851441fe41ee35b9d57451d00db81168b236b85fc7f0bb5990b2291`
### 已知限制

- 仅支持 Windows；界面目前只有亮色主题
- 安装包未签名
- 暂无自动更新，新版本需手动下载覆盖安装（配置与偏好会保留）
- 当前版本暂不含：绘图组件、SyncTeX 正反向搜索、外部文件变更监听、多套内置模板
- 许可证：PolyForm Noncommercial License 1.0.0（源码可见，非 OSI 开源；商业使用需另行授权）

## Zetla 0.1.1 —— 首个可用版本

桌面 LaTeX 工作台，把项目管理、编辑、编译、日志和 PDF 预览放进同一个应用。

### 亮点

- **完整闭环**：打开项目 → 新建 / 编辑 `.tex` → 一键 XeLaTeX 编译 → 右侧直接看 PDF
- **零环境也能跑**：启动时检测 TeX 发行版；未安装可在应用内直接下载安装 TeX Live（basic / full 可选、国内镜像、自定义目录、取消后自动清理），也支持接管已有的 TeX Live 安装
- **中文友好**：内置 `article` / `ctex-cn` 两套模板；GBK 老文档打开不乱码，保存不改变编码与换行
- **编译诊断**：优先 `latexmk -xelatex`；实时日志 + 结构化报错，点击错误跳转到对应行列
- **日常好用**：多标签独立撤销栈、自动保存、项目树右键新建 / 重命名 / 删除 / 复制粘贴、窗口与布局记忆、记住上次项目、编辑器 Ctrl+滚轮缩放

### 安装

1. 下载 `Zetla_0.1.1_x64-setup.exe` 并运行
2. 安装包未签名，SmartScreen 提示时选「更多信息 → 仍要运行」
3. 需要 Windows 10/11 + WebView2 Runtime（Win10/11 通常已内置）
4. TeX 可选：不装也可以，首次启动的引导页可直接安装 TeX Live

SHA256：`1EBB534E165B4CCAB31A43B69A1AB539101C71F698C2F506ADDC04F44C09447F`
