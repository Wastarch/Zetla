## Zetla 0.1.4 —— 公式工作台 · 自动更新 · 会话恢复

把「符号面板」和「公式库」合成了一个可写、可预览、可直接插入的公式侧栏；新增应用内自动更新，并让重启后的标签页原样回来。

### 亮点

- **公式侧栏（符号 + 公式 + 编写 + 预览一体）**：活动栏第三项改为「公式」（`Ctrl+B 3`），原来的符号面板与公式库合并为单一模块，设置页只需一个开关
  - **快捷工具**：10 个分类、共 191 个常用符号，另含 24 个结构模板（分数、根式、上下标、矩阵、cases、积分等）
  - **公式模板**：81 条内置公式、9 个分类，支持搜索、最近使用与自定义增删改
  - **单击写入编写区，右键直接插入**：右键菜单可选择插入到编辑器、写入侧栏编写区或复制 LaTeX；行内 / 编号由顶部齿轮统一控制
  - **KaTeX 实时预览 + 可视化模式**：预览随编写区实时更新；切到可视化后可点击公式里的占位槽回到源码定位
  - **结构模板带占位槽**：模板里的 `\Box` 空槽插入编辑器后可按 `Tab` 逐槽跳转，也可用鼠标点击选中
  - **二级工具栏**：颜色、字体、字号、环境下拉，清空、源码 / 可视化切换与字号缩放
  - **Ctrl+滚轮缩放**：编写区字号（11–20）与预览缩放（50%–400%）各自独立调节
  - 「最近使用」在符号、结构模板与公式之间共享；自定义公式保存后重启仍在
- **自动更新**：启动时自动检查新版本，帮助菜单同步显示红点
  - **双源检测**：优先 Gitee、失败回退 GitHub，读取 `latest.json` 比对版本
  - **关于 Zetla** 页显示「检查中 / 已是最新 / 发现新版本 / 下载进度 / 已下载 / 失败」状态，可手动「检查更新」或「重试」
  - **一键下载安装**：安装包多源回退下载、下载后校验 SHA256、显示下载进度；完成后关闭 Zetla 并拉起 Inno Setup 安装向导，覆盖安装保留配置与偏好
  - 会识别 `latest.json` 中的强制更新标记（`minVersion` / `mandatory`）并在关于页标注「必须更新」；某源不可用不影响其余源
  - 更新检测与下载只在本机比对、下载安装包，不上传项目或文档内容
- **会话恢复**：重启后不仅重新打开上次的项目，还会按原顺序重开上次打开的标签页并回到活动标签（最多 50 个；已删除的文件自动跳过）
- **关于页重设计**：去掉技术栈信息，只保留简介、版本号与「软件更新」区，界面更清爽

### 改进

- **主题跟随系统**：外观新增「跟随系统」，随系统亮 / 暗实时切换；菜单「主题跟随系统」与设置页选项同步
- **编译日志页签更贴心**：编译开始时自动切到「全部」；编译失败自动切到「错误」便于直接排错；编译成功则留在「全部」
- **全新应用图标**：换用 Zetla 徽章图标，任务栏、窗口、安装包与 favicon 统一（系统图标缓存较旧时可能需重启或清理缓存后生效）

### 安装 / 升级

1. 下载 `Zetla_0.1.4_x64-setup.exe` 并运行
2. 安装包未签名，SmartScreen 提示时选「更多信息 → 仍要运行」
3. 需要 Windows 10/11 + WebView2 Runtime（Win10/11 通常已内置）
4. 从 0.1.3 / 0.1.2 / 0.1.1 升级可直接覆盖安装：安装标识不变，配置、偏好与上次项目都会保留；已安装的 TeX Live 不受影响
5. **从 0.1.4 起可在应用内更新**：之后的新版本会由「关于 Zetla」检测并下载；从 0.1.3 及更早版本升级到 0.1.4 仍需手动下载安装一次
6. TeX 可选：不装也可以，首次启动的引导页可直接安装 TeX Live

SHA256：待打包后补填（以 GitHub Releases 页面为准）

### 已知限制

- 仅支持 Windows
- 安装包未签名；应用内更新拉起安装向导时，若被 SmartScreen 拦截需点「仍要运行」
- 自动更新自 0.1.4 起生效，0.1.3 及更早版本需手动升级一次
- 当前版本暂不含：绘图组件、引用自动补全、外部文件变更监听、多套内置模板（仍为 `article` / `ctex-cn` 两套）；拖拽图片、表格编辑器、外围补齐仍待后续
- 许可证：PolyForm Noncommercial License 1.0.0（源码可见，非 OSI 开源；商业使用需另行授权）

## Zetla 0.1.3 —— 双向跳转 · 暗色主题 · 符号面板

M1 批次的第一个正式版：编辑器与 PDF 预览经 SyncTeX 双向连通，新增大纲导航、符号面板和暗色主题，编译引擎与流程也能自选。

### 亮点

- **源码 ↔ PDF 双向跳转**：编辑器里 Ctrl+点击正文，右侧 PDF 随即跳到对应位置并高亮；在 PDF 里 Ctrl+点击，左侧编辑器定位到源码行列。中文路径的项目同样可用
- **大纲导航**：侧栏新增「大纲」视图，从主文件自动梳理 `\input`/`\include` 链中的章节结构，按层级展示、点击直达对应行列，编译后自动更新
- **符号面板**：侧栏新增「符号面板」，收录 191 个常用符号、按 9 类分组（希腊字母 / 运算符 / 关系符 / 箭头 / 集合与逻辑 / 大型算子 / 定界符 / 杂项 / 常用命令），搜索或点击即在光标处插入，写公式不必再背命令
- **暗色主题**：设置页「外观与保存 → 主题」一键切换暗色，编辑器与预览区同步适配；视图菜单亦可快速切换，选择即时生效并记住
- **编译引擎自选 + 自定义编译流程**：默认编译引擎可在 XeLaTeX / pdfLaTeX / LuaLaTeX 间选择（留「自动」则跟随项目配置）；带参考文献的文档可直接选用预设四步流程，或用步骤编辑器自定义顺序（如 LaTeX → BibTeX → LaTeX → LaTeX），状态栏实时显示当前生效引擎

### 改进

- **侧栏活动栏**：左侧新增常驻图标栏，「资源管理器 / 大纲 / 符号面板」单击切换、再点收起；`Ctrl+B 0/1/2/3` 键盘直达，视图菜单同步可选
- **编辑器语法高亮**：编辑器首次获得真正的 LaTeX 配色（命令、数学环境、注释等分色），亮 / 暗主题各有一份
- **编译信息更透明**：编译日志首行标注生效引擎与流程序列；状态栏引擎芯片显示生效引擎，点击可跳转设置页
- **符号面板可启停**：经模块框架注册，可在设置页「模块」页签随时关闭 / 开启

### 安装 / 升级

1. 下载 `Zetla_0.1.3_x64-setup.exe` 并运行
2. 安装包未签名，SmartScreen 提示时选「更多信息 → 仍要运行」
3. 需要 Windows 10/11 + WebView2 Runtime（Win10/11 通常已内置）
4. 从 0.1.2 / 0.1.1 升级可直接覆盖安装：安装标识不变，配置、偏好与上次项目都会保留；已安装的 TeX Live 不受影响
5. TeX 可选：不装也可以，首次启动的引导页可直接安装 TeX Live

SHA256：待打包后补填（以 GitHub Releases 页面为准）

### 已知限制

- 仅支持 Windows
- 安装包未签名
- 暂无自动更新，新版本需手动下载覆盖安装（配置与偏好会保留）
- 当前版本暂不含：绘图组件、引用自动补全、外部文件变更监听、多套内置模板（仍为 `article` / `ctex-cn` 两套）
- 暗色主题下启动首帧可能有一次短暂的亮色闪烁（设置异步加载所致）

## Zetla 0.1.2 —— 侧栏更顺手，安装包换代

日常使用体验打磨版：PDF 侧栏合并为一个入口并支持拖拽调宽，修掉编辑器换行与版面的几处问题，正式安装包也从 NSIS 换成 Inno Setup。

### 亮点

- **PDF 侧栏一键开合**：头部原来「缩略图」「目录」两个按钮合并为工具条最左侧的单一开合键（三横线图标），展开时高亮；收起再展开会回到上次停留的缩略图 / 目录页签
- **侧栏宽度可拖拽**：侧栏右侧新增拖拽条，左键拖动即可调宽（110–380px，并始终给右侧 PDF 区留出至少 160px）；宽度随布局一起记住，重启后保持
- **安装包改用 Inno Setup**：安装包与卸载程序换成 Inno Setup，发布者统一为 Max，覆盖升级沿用同一 AppId，配置与偏好不会丢

### 改进

- 设置页固定统一高度（`min(560px, 86vh)`）：切换页签时外框不再跳动，短页留白、长页只在右侧内容区滚动
- 编辑区铺满宽度：滚动条与代码背景贴到最右侧，不再留出多余空白
- 卸载时可选择是否一并删除应用内安装的 TeX Live（默认保留；静默卸载一律保留）

### 修复

- 修复软换行未生效的问题，并让字号 / 字体 / 换行变化后按新字宽重新折行
- 修复 `tauri build` 时仍会尝试下载 NSIS 的问题（安装包改由 `npm run package:inno` 产出）

## Zetla 0.1.1 —— 首个可用版本

桌面 LaTeX 工作台，把项目管理、编辑、编译、日志和 PDF 预览放进同一个应用。

### 亮点

- **完整闭环**：打开项目 → 新建 / 编辑 `.tex` → 一键 XeLaTeX 编译 → 右侧直接看 PDF
- **零环境也能跑**：启动时检测 TeX 发行版；未安装可在应用内直接下载安装 TeX Live（basic / full 可选、国内镜像、自定义目录、取消后自动清理），也支持接管已有的 TeX Live 安装
- **中文友好**：内置 `article` / `ctex-cn` 两套模板；GBK 老文档打开不乱码，保存不改变编码与换行
- **编译诊断**：优先 `latexmk -xelatex`；实时日志 + 结构化报错，点击错误跳转到对应行列
- **日常好用**：多标签独立撤销栈、自动保存、项目树右键新建 / 重命名 / 删除 / 复制粘贴、窗口与布局记忆、记住上次项目、编辑器 Ctrl+滚轮缩放

### 安装

1. 下载 `Zetla_0.1.1_x64-setup.exe` 并运行

3. 需要 Windows 10/11 + WebView2 Runtime（Win10/11 通常已内置）
4. TeX 可选：不装也可以，首次启动的引导页可直接安装 TeX Live
