## Zetla 0.2.0 —— 语言档位 · 小地图 · 任意后缀新建 · 清理清单 · 安装体验

本版聚焦日常编辑与构建体验：编辑器补齐多语言档位与纯文本兜底、加入右侧小地图；新建文件不再局限于 `.tex`；编译完成后可按自定义清单自动清理辅助文件；引用面板支持手动重扫；安装包会自动检测并按需安装 WebView2，正式版同时屏蔽了 WebView2 原生右键菜单。

### 亮点

- **编辑器语言档位与纯文本兜底**
  - 语言高亮收敛为五档：**LaTeX**、**BibTeX**、**BibTeX 样式（.bst）**、**TeX 日志（.log）**、**纯文本**
  - LaTeX 档同时覆盖 `.tex` / `.ltx` / `.cls` / `.sty` / `.bbx` / `.cbx` / `.lbx` / `.dtx` / `.ins` / `.ctx`
  - **未收录的扩展名（含无后缀文件）按纯文本渲染**，不再误套 LaTeX 高亮；行号、括号配对、查找、`Ctrl+S`、图片拖拽等编辑能力不受影响
  - 状态栏「文档语言」chip 可点击切换档位，也可一键恢复「按扩展名自动识别」；未收录扩展名会提示「该扩展名未收录，按纯文本渲染」
  - 新增 `.bst` 与 `.log` 专属着色，编译日志中的错误、告警与行号更易读
- **编辑器右侧小地图**
  - 缩略图显示在编辑器右侧，按语法 token 着色，自动跟随亮 / 暗主题；点击小地图可按比例滚动编辑器
  - 默认开启，可在「偏好设置 → 编辑器 → 显示小地图」关闭
  - 仅文本缓冲区显示；图片 / PDF 标签使用各自查看器，不挂载小地图
- **新建文件支持任意后缀**
  - 项目树右键与根行按钮统一为「新建文件」，不再写死「新建 .tex 文件」
  - 文件名对话框新增类型快选：`.tex` / `.bib` / `.cls` / `.sty` / `.md` / `.txt` / 无后缀，默认 `.tex`，并会记住本次运行内上次选择
  - 输入名自带后缀时以输入为准，无后缀时拼接所选类型；下方实时预览最终文件名
  - 文本类文件创建后自动打开标签；图片 / PDF 只创建文件，不自动打开
- **编译完成后清理辅助文件**
  - 「偏好设置 → 编译设置」新增「编译完成后清理辅助文件」开关（默认关闭）
  - 新增**自定义清理清单**：默认 14 项（`.aux` / `.log` / `.bbl` / `.blg` / `.toc` / `.out` / `.lof` / `.lot` / `.idx` / `.ilg` / `.ind` / `.fls` / `.fdb_latexmk` / `.synctex.gz`）
    - 清单以 chip 展示，可逐项移除；输入后缀回车即可添加（自动补点、转小写、去重），也可「恢复默认」
    - 清单为空时使用内置默认清单；手动「清理辅助文件」与编译后清理共用同一份清单
  - 仅**编译成功**后执行；失败或取消不清理。删除数量大于 0 时写入编译日志、弹出 toast 并刷新资源树，删除 0 个时静默
  - 后端对 `.tex` / `.bib` / `.cls` / `.sty` / `.pdf` 等受保护后缀做兜底，即使清单误填也不会删除源码、样式或 PDF
- **引用面板手动刷新**
  - 「引用」视图搜索框与「导入参考文献…」之间新增「↻ 刷新」按钮
  - 刷新会重新扫描项目目录、清除反向引用缓存并重建引用索引（重读全部 `.bib` / `.tex`，已打开文件走内存缓冲），完成后提示当前文献条目数；刷新期间按钮禁用并显示「刷新中…」
  - 调整引用面板布局，搜索、刷新、导入操作区更紧凑
- **安装与桌面体验**
  - **安装包自动检测 WebView2**：安装时查询系统注册表，已安装则零开销；缺失时由系统 PowerShell 即时下载微软引导器并静默安装
    - WebView2 引导器不内嵌进安装包，安装包体积不增加；缺失 Runtime 的旧版 Win10 需要联网
    - 自动安装失败时提示手动下载地址，不阻断安装流程
  - **正式版禁用 WebView2 原生右键菜单**：避免「返回 / 刷新 / 另存为 / 打印 / 更多工具」等系统菜单干扰应用自绘菜单，也避免暴露调试入口；开发版仍保留原生菜单便于调试
  - **主窗口最小尺寸 1024×640**：由窗口管理器约束，恢复上次窗口几何时也会按最小尺寸兜底，避免把活动栏、侧栏、编辑区与预览挤坏

### 改进

- 状态栏语言 chip 从固定「LaTeX」改为按扩展名识别，并支持手动覆盖（仅本次会话有效）
- 新建文件对话框增加文件名实时预览与会话级类型记忆，减少重复选择后缀
- 辅助文件清理统一走同一份后缀清单，手动清理与编译后清理行为一致
- 引用面板操作区重新排布，窄侧栏下更易点到刷新与导入
- 版本号提升至 `0.2.0`

### 安装 / 升级

1. 下载 `Zetla_0.2.0_x64-setup.exe` 并运行
2. 安装包未签名，SmartScreen 提示时选「更多信息 → 仍要运行」
3. 需要 Windows 10/11；WebView2 Runtime 已内置时直接使用，缺失时安装包会尝试自动下载安装（需联网）
4. 从 0.1.6 / 0.1.5 / 0.1.4 升级可直接覆盖安装：安装标识不变，配置、偏好、最近项目与上次项目都会保留；已安装的 TeX Live 不受影响
5. TeX 可选：不装也可以，首次启动的引导页可直接安装 TeX Live

SHA256：待打包后补填（以 GitHub Releases 页面为准）

### 已知限制

- 仅支持 Windows
- 安装包未签名；应用内更新拉起安装向导时，若被 SmartScreen 拦截需点「仍要运行」
- WebView2 自动安装需要联网；离线或企业网络受限时请按提示手动安装 Runtime
- 正式版屏蔽了 WebView2 原生右键菜单；文本框内复制 / 粘贴请使用 `Ctrl+C` / `Ctrl+V`，项目树、引用面板等自绘菜单不受影响
- 语言手动覆盖仅本次运行有效，重启后恢复按扩展名自动识别；语言识别只依据扩展名
- 小地图仅文本缓冲区可用，开关为全局设置，最大宽度固定（暂未提供每文件单独开关）
- 新建文件类型快选提供常用后缀，其他后缀可直接在文件名中输入
- 编译后清理清单按后缀匹配，受保护后缀（`.tex` / `.bib` / `.cls` / `.sty` / `.pdf` 等）永不删除；清理仅作用于项目根递归目录
- 引用面板「刷新」会重扫项目并重建索引，项目很大时可能需要短暂等待
- **单活动项目**：当前一次只打开一个项目，未支持同时打开多个项目工作区；项目切换保留的标签页为本次运行内有效
- 归档仅为标记，不移动或删除项目目录；删除项目不进回收站；打开中的项目不可重命名 / 删除
- 项目设置中的「输出目录」仍为置灰占位，编译产物固定落在主文件同目录
- 表格编辑器上限 100 行 × 20 列；`.xlsx` 需先另存为 CSV；反向回填针对常见 `tabular`
- 图片 / PDF 标签为只读查看器，PDF 标签为打开时快照；图片目录只支持项目内相对路径
- 模板库仅管理本地用户模板，不含在线模板市场
- BibTeX 解析为轻量实现，Zotero 仅支持「导出 `.bib` 后导入」，不做 API 双向同步
- 许可证：PolyForm Noncommercial License 1.0.0（源码可见，非 OSI 开源；商业使用需另行授权）

## Zetla 0.1.6 —— 项目管理 · 表格编辑器 · 图片插入 · 多文件模板

本版把 Zetla 从「打开一个文件夹写稿」推进到「管理多个项目、日常写论文 / 报告 / 简历」：新增欢迎页与项目切换器、项目设置与生命周期管理、模板库；补齐表格编辑器、图片拖拽 / 粘贴插入、图片与 PDF 标签页查看；并加入外部改动重载、辅助文件清理与保存时自动编译。

### 亮点

- **项目管理套件**
  - **欢迎页**：没有打开项目时显示，提供「从模板新建 / 打开项目文件夹 / 模板库」入口与**最近项目列表**（名称、位置、最近打开时间、操作）
    - 支持**置顶**（★）与**归档**；归档项目折叠在「已归档」分组，可随时取消归档
    - 「⋯」菜单提供**重命名项目 / 导出为 zip / 归档 / 删除项目**
  - **项目切换器**：`Ctrl+R` 或「文件 → 切换项目…」唤起命令面板，可输入过滤、`↑↓` 选择、`Enter` 打开、`Esc` 关闭，末项为「打开其他文件夹…」
    - **切换保留标签页**：离开项目时记住已打开的标签与当前活动标签，切回时按新项目树过滤后恢复（本次运行内有效）
  - **项目设置**：菜单「设置 → 项目设置…」，左侧分「常规 / 构建 / 显示」三页
    - 常规：项目名、描述、类型（article / thesis / beamer / resume / custom）
    - 构建：主文件（项目内 `.tex` 下拉）、编译引擎；输出目录按既定口径置灰并标注后续接通
    - 显示：图片目录（相对项目根，默认 `figure`）、排除规则（每行一个 glob，仅过滤资源管理器树）
    - 保存后写入 `.ltex/config.json`，资源树立即刷新（引擎标签、主文件标记、排除项隐藏），欢迎页项目名同步更新
  - **生命周期管理**
    - 重命名项目（重命名项目文件夹并更新最近项目）
    - 删除项目（删除整个项目文件夹，**不可撤销、不进回收站**）
    - 导出为 zip（排除辅助文件与 `node_modules` / `target` / `dist` / `.git`，保留 `.ltex`、源码与 PDF）
    - 打开中的项目由后端保护，不允许重命名 / 删除；活动项目仍可安全导出
- **模板库与多文件模板**
  - 内置模板从 2 套扩展到 **5 套**：`article`（英文文章）、`ctex-cn`（中文文章）、`thesis-cn`（多文件中文毕业论文，含章节拆分与参考文献骨架）、`beamer-cn`（多文件中文幻灯片）、`resume-cn`（中文简历）
  - **模板库**（菜单「模板 → 模板库」或欢迎页入口）：三栏布局，左分类、右搜索 + 列表 / 详情；详情展示引擎、主文件、变量、文件数、版本与标签
  - **动态变量表单**：按 `manifest.variables` 渲染 `string / text / number / select / bool / date / multiselect`，支持分组、必填、占位提示与说明；多文件模板按 `structure` 生成目录与文件
  - **用户模板**：可把当前项目「另存为模板」、导入本地模板目录或 zip（zip 防路径穿越、校验 manifest、拒绝覆盖内置模板），也可删除用户模板（内置模板受保护）
  - 从模板库可直接「用此模板新建」，向导会预选对应模板
- **表格编辑器**（侧栏「表格」视图，`Ctrl+B 5`，可在「偏好设置 → 模块」停用）
  - 类 Excel 网格编辑：回车 / 失焦提交，`Tab` / `Shift+Tab` 左右移，`Enter` / `Shift+Enter` 上下移，`Ctrl+方向键` 跨格，`Esc` 退出
  - 拖拽或 `Shift+点击` 矩形选区；`Ctrl+C` 复制为 TSV，`Ctrl+V` 以当前格为左上角铺入，**可直接从 Excel 粘贴**
  - 右键行号 / 列号插行、插列、删除行 / 列；选中矩形可**合并 / 拆分**，列级 `l / c / r` 对齐
  - 样式三选：**三线表**（booktabs，默认）、**全框线**（grid）、**无线**（plain）；可切自然宽 / 撑满页宽（tabularx）
  - 表题、标签自动生成；单元格转义支持智能 / 全转义 / 不转义；生成代码可展开预览
  - **导入 CSV / TSV**；**载入光标处表格**反向回填网格，更新时以指纹校验，源码被手改则拒绝覆盖
  - 缺少 `booktabs` / `multirow` / `tabularx` 等宏包时给出提示，可一键「加入导言区」
- **图片插入与附件查看**
  - 三种插入方式：把图片**拖进编辑器**、**粘贴截图**、菜单「插入 → 图片…」
  - 图片默认保存到 `项目根/figure/`（可在项目设置改 `imageDir`），同名自动去重为 `base-1.ext`；按当前 `.tex` 目录计算相对路径，自动生成完整 `figure` 环境（`\centering` → `\includegraphics` → `\caption` → `\label`），光标落在空 `\caption{}` 内
  - 拖拽悬停时编辑器显示高亮边框；未打开项目或当前不是 `.tex` 标签时给出提示，不写入半成品源码
  - **图片 / PDF 标签页**：项目树双击或「文件 → 打开图片 / PDF…」在代码区以只读标签打开
    - 图片查看器支持 `Ctrl+滚轮` 指针锚定缩放（0.1–8）、拖拽平移，底部显示文件名、尺寸与缩放比例
    - PDF 标签页复用 PDF 渲染页（打开时快照，不随重编译刷新）；右侧预览仍随编译更新
    - 非文本标签下撤销 / 重做 / 注释 / 保存 / 插入图片等编辑动作置灰，「关闭标签」仍可用；会话恢复会按类型重建标签
- **编辑与构建增强**
  - **外部改动重载**：已打开文件被其他编辑器修改时，编辑器顶部出现「重新加载 / 忽略」提示条；自身保存的回显不会误报
  - **清理辅助文件**：菜单「构建 → 清理辅助文件」，递归删除 `.aux/.log/.bbl/.blg/.toc/.out/.synctex.gz/.lof/.lot/.idx/.ilg/.ind/.fls/.fdb_latexmk` 等，源文件与 PDF 不动，完成后提示删除数量并刷新资源树
  - **保存时自动编译**：偏好设置「编译设置」新增开关；手动保存 `.tex` 后触发编译（多次保存 400ms 内合并），定时自动保存不触发，避免频繁编译
  - **文件菜单调整**：移除「文件 → 打开 PDF…」，统一为「打开图片 / PDF…」；编译产物 `main.pdf` 仍会在打开项目时自动加载到右侧预览
  - **软件 logo 更新**：欢迎页与应用图标换用新版 Zetla 徽章

## Zetla 0.1.5 —— 参考文献全流程 · 补全 · 预览 · 跳转 · 校验 · 管理

面向科研写作补齐 BibTeX 引用能力：从输入 `\cite{` 的补全、悬浮预览，到 Ctrl+点击跳转、重复/缺失校验，再到项目级引用管理面板与反向引用，形成完整闭环。

### 亮点

- **新增「引用」视图（文献管理面板）**：活动栏第四项「引用」（`Ctrl+B 4`，视图菜单同步），自动扫描项目内所有 `.bib` 文件
  - 条目按 `.bib` 文件分组、可折叠，显示 key、作者（年份）与 `@type`；顶部可按 key / 作者 / 标题搜索
