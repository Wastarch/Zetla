## Zetla 0.2.2 —— 自定义标题栏 · 查找替换 · 实时预览 · 代码片段

本版把编辑体验往前推了一步：用自绘标题栏替换系统边框；新增编辑器快捷工具栏、单文件查找替换与全项目搜索；编译侧加入可配置的实时预览与「最新任务优先」的顶替式编译；并新增代码片段系统，支持触发词补全、Tab 直展与设置页管理。

### 亮点

- **自定义标题栏**
  - 去掉系统标题栏，顶部改为自绘三栏：左侧 logo 与菜单、中间窗口拖拽区、右侧最小化 / 最大化·还原 / 关闭
  - 拖动中间空白区移动窗口，**双击最大化 / 还原**；系统边框关闭后由 Tauri 原生拖拽补足左右下边缘与边角缩放
  - 关闭按钮复用原有退出流程，未保存文档仍会弹出确认；窗口大小与位置记忆保持不变
  - 当前仅适配 Windows，macOS 标题栏适配暂缓
- **编辑器快捷工具栏**
  - 位于标签栏下方、代码区上方，按活动标签自动跟随
  - **格式组**：加粗 / 斜体 / 下划线 / 删除线（包裹选中文本，无选区时插入占位）
  - **插入组**：链接 / 图片 / 无序列表 / 公式 / 表格；图片按钮复用现有插入流程（保存到图片目录并生成 `figure` 环境）
  - **章节结构组**：`chapter` / `section` / `subsection` / `subsubsection` / `paragraph` / `subparagraph` 下拉，插入命令后光标落在标题花括号内
  - 仅对 `.tex` 文本缓冲显示；图片 / PDF 查看器与 `.bib` / `.log` 等不显示
- **查找替换与全局搜索**
  - **单文件查找**：`Ctrl+F`（替换用 `Ctrl+H`）打开编辑器右上角浮动面板
    - 全部命中高亮、`n/N` 计数、`↑↓` 与 `F3` / `Shift+F3` 导航、`Esc` 关闭
    - 支持 `Aa` 大小写、整词、`.*` 正则；展开替换后可「替换」当前项或「全部替换」，并可保留大小写
  - **全局搜索**：`Ctrl+Shift+F` 或活动栏「搜索」打开侧栏
    - 并发扫描项目内文本文件，边扫边出结果，按文件分组展示命中行
    - 点击命中跳转到对应文件与行，并唤起单文件高亮；跨文件替换执行前弹确认并提示受影响文件数
    - 范围覆盖 `.tex` / `.bib` / `.log` / `.md` / `.txt` 等文本扩展名，排除 `build` / `out` / `.ltex` / `.aux` / `.git` / `node_modules` / `target` 与二进制文件
- **实时预览**
  - 「偏好设置 → 编译设置 → 实时预览」开关（**默认关闭**），延迟可选 500 / 600 / 800 / 1200 ms（默认 600 ms）
  - 停止输入后防抖自动编译，**静默执行**：不展开日志面板、不弹 toast、编译前静默保存，不打断继续输入
  - **latest-wins 顶替式编译**：新的触发会终止旧任务的进程树并顶替它，旧任务静默收尾——不写错误、不触发完成提示，也不会误杀新任务
  - 编译成功后按**编译前光标所在行**在 PDF 中静默锚定并滚动到视口；手动编译会清除锚定
  - 与「编译后清理辅助文件」互斥：实时预览期间自动保留 `.fdb_latexmk` / `.fls`（增量缓存）与 `.synctex.gz`（跳转与锚定）
- **代码片段**
  - 内置 **22 条**片段，覆盖结构（`beg` / `itemize` / `enumerate` / `center`）、章节（`sec` / `ssec` / `sssec` / `para`）、浮动体（`fig` / `tab` / `eq` / `algn` / `cases` / `pmat`）、数学（`frac` / `sqrt` / `sum` / `int`）与文本（`fn` / `text` / `bf` / `it`）
  - 输入触发词时出现在补全弹窗；**精确命中后按 `Tab` 直接展开**，未命中仍按原行为缩进，不抢补全与公式槽位的 `Tab`
  - 支持 `$SELECTION`：选中文本后展开即包裹（如 `bf` → `\textbf{选中内容}`）；无选区时插入占位符
  - 模板支持 `${1:占位}` 形式的占位符，沿用 CodeMirror 原生 `Tab` / `Shift+Tab` 逐槽跳转
  - 菜单「插入代码片段…」可直接唤起片段补全，规避中文输入法占用 `Ctrl+Shift+Space` 等组合键的问题
  - 设置新增「代码片段」页，双栏管理：
    - 左侧搜索 + 「内置（只读）/ 自定义」分组；右侧编辑触发词、描述、分类与模板
    - 校验空触发词、反斜杠 / 空白、与内置冲突、重复触发词；保存后立即生效，自定义片段上限 500 条
    - 支持导入 / 导出 JSON 片段包；导入时可选择覆盖或追加合并
  - 可在「模块」页停用代码片段：停用后补全源与 `Tab` 直展短路，但不重建编辑器扩展，避免丢失占位符会话
- **细节打磨**
  - 调整行号区域宽度，长行号下不再拥挤
  - 查找替换面板的替换开关移入输入框内，面板更紧凑
  - 「全部替换」改用 SVG 图标，并清理无用 SVG 资源

### 改进

- 编译状态改为任务代号模型：重叠触发不再丢弃请求或误杀新任务，旧任务的日志、错误与跳转结果不会污染当前结果
- 图片插入、表格生成与内置片段共用同一套模板构建器：缩进统一为 Tab = 2 空格，`fig` 宽度统一为 `\linewidth`（适配分栏与 minipage）
- 内置片段全部由构建器生成，新增 `center` / `frac` / `sqrt` / `sum` / `int` 等常用片段
- 版本号提升至 `0.2.2`

### 安装 / 升级

1. 下载 `Zetla_0.2.2_x64-setup.exe` 并运行
2. 安装包未签名，SmartScreen 提示时选「更多信息 → 仍要运行」
3. 需要 Windows 10/11；WebView2 Runtime 已内置时直接使用，缺失时安装包会尝试自动下载安装（需联网）
4. 从 0.2.1 / 0.2.0 及更早版本升级可直接覆盖安装：安装标识不变，配置、偏好、最近项目与上次项目都会保留；自定义代码片段与语法高亮配色不受影响
5. TeX 可选：不装也可以，首次启动的引导页可直接安装 TeX Live

SHA256: `97A22BA261E1D8FED433005AE27B4ECBFA0A59C65DD45558E893E809E0233F04`

### 已知限制

- 仅支持 Windows
- 安装包未签名；应用内更新拉起安装向导时，若被 SmartScreen 拦截需点「仍要运行」
- WebView2 自动安装需要联网；离线或企业网络受限时请按提示手动安装 Runtime
- 自定义标题栏暂只适配 Windows；macOS 原生标题栏与窗口按钮适配未完成
- 实时预览默认关闭，且执行的是整篇编译而非增量排版；大项目或复杂文档建议加大延迟，避免频繁占用 CPU
- 实时预览重叠触发时旧任务结果会被直接丢弃（latest-wins），不会合并输出
- 实时预览开启时会保留增量缓存文件，关闭后由「编译后清理」按清单处理
- 全局搜索仅覆盖项目内文本扩展名，并排除 `build` / `out` / `.ltex` / `.aux` / `.git` / `node_modules` / `target`；不搜索二进制文件
- 跨文件替换不可撤销，执行前会二次确认并提示受影响文件数
- 代码片段仅在 `.tex` 文本缓冲生效；触发词不能包含反斜杠或空白；自定义片段上限 500 条
- 快捷工具栏仅对 `.tex` 文本缓冲显示，查看器与其他文本类型不显示
- **单活动项目**：当前一次只打开一个项目，未支持同时打开多个项目工作区；项目切换保留的标签页为本次运行内有效
- 项目设置中的「输出目录」仍为置灰占位，编译产物固定落在主文件同目录
- 模板库仅管理本地用户模板，不含在线模板市场
- BibTeX 解析为轻量实现，Zotero 仅支持「导出 `.bib` 后导入」，不做 API 双向同步

## Zetla 0.2.1 —— 日志面板停靠 · 语法高亮自定义 · 宁夏大学论文模板 · 片段诊断去噪

本版围绕编辑与写作体验：日志面板改为 VSCode 式停靠并支持拖拽调高；LaTeX 语法高亮可自定义配色、套用主题方案并导出导入；新增「宁夏大学学位论文」模板，内置模板增至 6 套；章节片段不再误报整篇级问题，`\input` 支持 Ctrl+点击跳转；模板向导与模板库的衔接也更顺。

### 亮点

- **日志面板 VSCode 式停靠**
  - 日志面板移到编辑 / 预览主列底部，**不再横跨左侧活动栏与侧栏**；侧栏保持整列高度，布局更接近主流编辑器
  - 面板顶部新增拖拽把手，可上下调整高度（120–560px，且始终为编辑区保留至少 180px；窗口变矮时自动压缩）
  - 高度写入布局记忆（`layout.logHeight`），重启或「恢复布局」后保持上次高度
  - 打开 / 关闭方式不变：「视图 → 显示 / 隐藏日志面板」、状态栏日志按钮，或编译开始时自动展开
- **LaTeX 语法高亮自定义**
  - 入口：「偏好设置 → 外观与保存 → LaTeX 语法高亮 → 自定义配色…」
  - **12 个语义分组**（正文 / 注释 / 字面参数 / 控制序列 / 章节命令 / 数学符号 / 括号 / 环境名与 label / 加粗 / 斜体 / 等宽 / 非法字符），亮色与暗色各一套颜色
  - 每组用**原生取色器**选色，也可手输 `#RRGGBB`（6 位十六进制校验）；改动即时同步编辑器预览，点设置页「取消」可整体回滚，「恢复默认」回填出厂配色
  - **主题方案**一键套用：Zetla 默认 / GitHub / Dracula / Solarized / Nord（亮暗双色，取自各主题公开标准色值）
  - **导出 / 导入 JSON**：可备份或分享配色；导入时校验颜色格式与分组 `tags`，非法文件会给出具体原因
  - 分组模型改为**可扩展**：每个分组可绑定任意数量的 lezer 标签（不再是固定 12 组枚举），未知标签安全跳过；配置写入 `config.json`，缺省或损坏时自动合并补全默认值
- **新增「宁夏大学学位论文」内置模板**
  - 内置模板由 5 套增至 **6 套**（英文文章 / 中文文章 / 多文件毕业论文 / 多文件幻灯片 / 简历 / 宁夏大学学位论文）
  - **23 项表单变量**，按「基本信息 / 外观」分组：学位层次、中英文标题、学科门类、培养单位（中英文）、学科专业、作者（中英文）、学号、导师（中英文）、联合导师、研究方向、提交日期、分类号、密级、保密年限、单位代码；外观可选出稿格式（电子 / 打印）、盲审版封面、生成书脊与数学字体
  - 联合导师为可选项，走**条件块**按需生成：不填则整段省略，不残留空行
  - 一并生成正文 4 章示例，以及摘要、致谢、附录、个人简历等文件，连同 `ref/refs.bib` 与 `nxuthesis.cls` / 三种 `.bst` 资源；示例图自带，去除对 `mwe` 宏包的依赖，**开箱即可用 XeLaTeX 编译**
  - 修复条件块在 `\nxusetup` 参数块内留下空行、导致 keyval 解析失败的问题，并补充「模板换行保留」的回归用例
- **章节片段诊断去噪 + `\input` 跳转**
  - 被 `\input` 引入的章节文件本身没有 `\documentclass` 与 `\bibliography`，此前会误报「缺少 document 环境 / `\cite` 但没有参考文献 / 缺少引用 / 缺少宏包」；现在这些**整篇级检查只对主文件生效**
  - 片段内的环境配对、括号闭合、重复 label、数学模式等文件内检查保持开启，真正的语法问题仍会提示
  - `\input` / `\include` / `\subfile` 支持 **Ctrl+点击跳转**目标 `.tex`：路径按「当前文件目录 → 主文件目录 → 项目根」依次解析，缺省自动补 `.tex`；未命中时 toast 提示，不创建文件
  - 按住 Ctrl 时目标显示链接态，悬停提示「Ctrl+点击可跳转 <文件>」，交互与 `\cite` 跳转一致
- **模板库与向导衔接**
  - 欢迎页「从模板新建」直接打开三栏模板库，移除与其重复的「模板库」按钮（菜单「模板 → 模板库」入口保留）
  - 向导顶部显示当前模板，并提供「← 返回模板库」，返回时保持原选中项；变量表单单页展示，宽屏下两列排布

### 改进

- 日志面板默认高度 212px，拖拽调整后随布局记忆持久化，不再依赖旧版 CSS 变量
- 语法高亮由编辑器内硬编码配色改为设置驱动的数据模型，亮 / 暗主题切换时即时重建
- 修正配色分组标签：「注释 / verbatim 内容」改为「verbatim 内容 / 正文」（该组实际控制正文颜色，不影响 `%` 注释）
- 模板向导不再内嵌模板卡片列表，选择模板统一在模板库完成，减少重复入口
- 版本号提升至 `0.2.1`

## Zetla 0.2.0 —— 语言档位 · 小地图 · 任意后缀新建 · 清理清单 · 安装体验

本版聚焦日常编辑与构建体验：编辑器补齐多语言档位与纯文本兜底、加入右侧小地图；新建文件不再局限于 `.tex`；编译完成后可按自定义清单自动清理辅助文件；引用面板支持手动重扫；安装包会自动检测并按需安装 WebView2，正式版同时屏蔽了 WebView2 原生右键菜单。

### 亮点

- **编辑器语言档位与纯文本兜底**
  - 语言高亮收敛为五档：**LaTeX**、**BibTeX**、**BibTeX 样式（.bst）**、**TeX 日志（.log）**、**纯文本**
  - LaTeX 档同时覆盖 `.tex` / `.ltx` / `.cls` / `.sty` / `.bbx` / `.cbx` / `.lbx` / `.dtx` / `.ins` / `.ctx`
  - **未收录的扩展名（含无后缀文件）按纯文本渲染**，不再误套 LaTeX 高亮；行号、括号配对、查找、`Ctrl+S`、图片拖拽等编辑能力不受影响
  - 状态栏「文档语言」chip 可点击切换档位，也可一键恢复「按扩展名自动识别」；未收录扩展名会提示「该扩展名未收录，按纯文本渲染」
  - 新增 `.bst` 与 `.log` 专属着色，编译日志中的错误、告警与行号更易读

## Zetla 0.1.5 —— 参考文献全流程 · 补全 · 预览 · 跳转 · 校验 · 管理

面向科研写作补齐 BibTeX 引用能力：从输入 `\cite{` 的补全、悬浮预览，到 Ctrl+点击跳转、重复/缺失校验，再到项目级引用管理面板与反向引用，形成完整闭环。

### 亮点

- **新增「引用」视图（文献管理面板）**：活动栏第四项「引用」（`Ctrl+B 4`，视图菜单同步），自动扫描项目内所有 `.bib` 文件
  - 条目按 `.bib` 文件分组、可折叠，显示 key、作者（年份）与 `@type`；顶部可按 key / 作者 / 标题搜索
  - 重复 key 的条目带黄点标记，已被引用的条目显示被引次数
  - **校验汇总条**：`⚠ 重复 key N 处` / `❌ 缺失引用 M 处`，点击直达首个问题；全部正常时显示「✓ 引用无误」
  - **导入参考文献**：可直接导入 Zotero 导出的 `.bib` 文件，拷贝到项目根目录（同名不覆盖）后自动纳入索引；不做 Zotero API 双向同步
  - **左键浮窗预览**：查看 key、类型、作者年份、标题及期刊 / 会议 / 出版社 / DOI / URL 等字段，并显示来源文件与行号
  - **右键三动作**：在光标处插入 `\cite{key}` / 跳到 `.bib` 条目 / 查看反向引用
  - **反向引用**：列出该文献在项目内所有 `.tex` / `.ltx` 中的引用位置，点击即可跳回对应源码行；被引次数随编辑实时更新
- **写作时的引用体验**
  - **`\cite{` 自动补全**：输入 `\cite{`、带可选参数或多 key 逗号后，从项目 `.bib` 索引给出候选，附带作者年份与标题；原有 LaTeX 命令补全保留
  - **悬浮预览**：光标停在 `\cite{key}` 上即可查看类型、标题、作者年份与来源文件行号；key 缺失提示「引用缺失」，重复 key 提示出现处数
  - **Ctrl+点击跳转**：在 `\cite{key}` 上 Ctrl+点击直接打开 `.bib` 并定位条目；按住 Ctrl 时引用命令显示下划线与手型，并提示「Ctrl+点击跳转到引用条目」，不影响原有 SyncTeX 正向跳转

  - **缺失引用**：`.tex` 中引用了 `.bib` 里不存在的 key 时标红；支持 `\cite` / `\citep` / `\citet` / `\citeauthor` / `\nocite` 等、可选参数与多 key 逗号分隔；`\nocite{*}` 不误报，空 `\cite{}` 也会提示
  - **性能**：引用索引集中缓存，编辑与保存后防抖 300ms 增量重扫；补全 / 悬浮 / 校验只读缓存，长文档打字不反复全量解析
