Z

Zetla

版本 1.4.2 · Tauri 2 · React 18 · WebView2

轻量本地 LaTeX 编辑器。所有文件读写与编译均在本机完成，不上传云端； 通过 MiKTeX / latexmk 调用本地编译链，支持 Synctex 双向同步、模板管理与多标签编辑。

运行环境
Windows 10 / 11 · WebView2 Runtime
编译依赖
MiKTeX · latexmk · xelatex / lualatex / pdflatex
渲染引擎
pdf.js · CodeMirror 6 (stex)
数据存储
纯本地目录，无云端同步
许可证
MIT License
设置即时生效，写入本地配置文件 %APPDATA%\Zetla\config.json
