# 使用指南

> 本文档从 README 抽离，涵盖安装、环境准备与全部使用细节（含快捷键）。返回 [README](../README.md)。

## 安装

1. 到 [Releases](https://github.com/Wastarch/Zetla/releases/latest) 下载 `Zetla_0.2.8_x64-setup.exe`。
2. 运行安装包。当前版本**未签名**，Windows SmartScreen 提示时选择「更多信息 → 仍要运行」。
3. 安装模式可以为「仅当前用户」，无需管理员权限。也可以为所有用户安装。
4. 安装包会自动检测 WebView2 Runtime：已安装则跳过；缺失时尝试联网下载并静默安装（失败会提示手动安装地址）。
5. 卸载时若检测到 **Zetla 代装的 TeX Live**，会询问是否一并删除；默认保留，TeX 可继续被其他软件使用。
6. 从 `0.2.7` 及更早版本升级可直接覆盖安装，配置、偏好、最近项目与上次项目都会保留；自定义代码片段、语法高亮配色、自定义公式与编译流程不受影响，旧配置缺少终端字段时会自动补默认值。

系统要求：

- **Windows 10/11**（当前主要开发与验收平台）
- **WebView2 Runtime**（Windows 10/11 通常已内置；缺失时安装包会尝试联网自动安装，也可手动安装）
- **TeX Live**：可选。不装也能启动，首次进入时可在应用内安装（见下一节）

> 国内网络下应用会自动尝试清华 TUNA、阿里云等镜像下载 TeX Live 安装器。

## 首次启动：准备 TeX 环境

Zetla 每次启动都会检测 TeX，顺序为：Zetla 独立目录 → 系统 `PATH` → 常见安装位置。

- **已装 TeX Live / MiKTeX**：检测到即可直接编译；环境详情可在「帮助 → TeX 环境检测…」或「偏好设置 → 编译设置」中查看。
- **未装 TeX**：自动弹出引导面板，可选：
  - **自动安装 TeX Live**：进入向导后选择方案与目录
    - *基础方案*：约 1.5 GB，含 XeLaTeX 与中文支持（ctex / fandol），适合大多数文档，后续可用 `tlmgr` 补包
    - *完整方案*：约 5 GB，包含全部宏包与文档
    - 默认安装到系统本地数据目录（Windows：`%LOCALAPPDATA%\Zetla\tex\texlive`；macOS：`~/Library/Application Support/Zetla/tex/texlive`；Linux：`~/.local/share/Zetla/tex/texlive`），也可另选目录；**只写入 Zetla 独立目录，不修改系统 PATH**
    - 按平台选用官方安装器：Windows 用 `install-tl.zip`（内含 Perl），macOS/Linux 用 `install-tl-unx.tar.gz`（需系统已安装 Perl）
    - 安装中可随时取消，取消后会清理本次新建的目录
  - **接管已有安装**：点「指定/接管已有安装…」，选择 TeX Live 根目录、`bin` 或 `bin\windows` 均可
  - **手动安装**：按面板内的官网指引自行安装后，回到应用重新检测
- 之后随时可通过菜单「帮助 → TeX 环境检测…」或「偏好设置 → 编译设置 → 检测 / 引导…」重新打开该面板。

## 新建或打开项目

- 启动后如果没有打开项目，编辑区会显示**欢迎页**：可「从模板新建」「打开项目文件夹…」，或直接从最近项目列表打开。
- **新建项目**：`Ctrl+Shift+N`（或菜单「文件 → 新建项目…」/ 欢迎页「从模板新建」）
  1. 「从模板新建」直接进入**模板库**：左侧分类、中间列表、右侧详情；选中模板后点「用此模板新建」
  2. 内置模板共 6 套：`article`（英文文章）、`ctex-cn`（中文文章）、`thesis-cn`（多文件毕业论文）、`beamer-cn`（多文件幻灯片）、`resume-cn`（中文简历）、`nxuthesis`（宁夏大学学位论文）
  3. 向导顶部显示当前模板，可点「← 返回模板库」更换；按模板变量填写标题、作者等信息，变量表单支持分组、必填、下拉、日期、开关与多选（宽屏两列）
  4. 选择生成位置 → 生成 `main.tex` 并写入 `.ltex/config.json`（记录主文件与引擎）；多文件模板会同时创建章节 / 分节目录
  5. 创建完成后自动打开到编辑器
- **打开已有项目**：`Ctrl+Shift+O`，选择项目文件夹。
  - 主文件判定顺序：`.ltex/config.json` 的 `mainFile` → 根目录 `main.tex` → 含 `\documentclass` 的最浅 `.tex` → 首个 `.tex`
  - 项目树中主文件带 `main` 标记
- **切换项目**：`Ctrl+R` 打开项目切换器，输入过滤、`↑↓` 选择、`Enter` 打开；切换时各项目的标签页会保留到本次运行结束。

## 项目管理

- **欢迎页与最近项目**
  - 最近项目以列表展示名称、位置、最近打开时间与操作按钮；点「打开」或双击行即可进入项目。
  - **置顶**：点击 ★ 把常用项目固定在列表顶部；再次点击取消置顶。
  - **归档**：在「⋯」菜单选择「归档」，项目移入「已归档」分组，不移动或删除目录；可随时取消归档。
  - **「⋯」菜单**：重命名项目、导出为 zip、归档 / 取消归档、删除项目。
- **项目切换器**（`Ctrl+R`，或「文件 → 切换项目…」）
  - 列出最近项目（置顶优先），输入关键字过滤；`↑↓` 选择、`Enter` 打开、`Esc` 关闭。
  - 末项「打开其他文件夹…」可直接选择新目录。
  - 切走时记住当前项目的标签页与活动标签，切回时按项目树过滤后恢复；该缓存仅在本次运行内有效。
- **项目设置**（菜单「设置 → 项目设置…」）
  - **常规**：项目名（默认取目录名，用于欢迎页与最近项目）、描述、类型（论文 / 学位论文 / 幻灯片 / 简历 / 自定义）。
  - **构建**：主文件（项目内 `.tex` 下拉，可自动识别）、编译引擎；输出目录当前固定为主文件同目录，界面置灰。
  - **显示**：图片目录（相对项目根，默认 `figure`）、排除规则（每行一个 glob，仅影响资源管理器树的显示）。
  - 保存后写入 `.ltex/config.json`，资源树立即刷新（引擎标签、主文件标记、排除项隐藏），欢迎页项目名同步更新。
- **项目生命周期**
  - **重命名**：重命名项目文件夹，并同步最近项目名称。
  - **删除**：删除整个项目文件夹，**不可撤销、不进回收站**，操作前会二次确认。
  - **导出为 zip**：打包项目源码与 PDF，排除辅助文件、`node_modules`、`target`、`dist` 与 `.git`。
  - 打开中的项目由后端保护，不能重命名 / 删除；仍可安全导出。
- **模板库**（菜单「模板 → 模板库」，或欢迎页「从模板新建」直接进入）
  - 左侧按分类浏览内置模板与用户模板，右侧搜索与详情；详情展示引擎、主文件、变量、文件数、版本与标签。
  - 内置 6 套模板；「宁夏大学学位论文」含 23 项变量（中英文标题、培养单位、导师、学号、分类号、密级等）与出稿格式、盲审封面、书脊、数学字体等外观选项。
  - **另存当前项目为模板**：菜单「模板 → 另存当前项目为模板…」，保存到 `%APPDATA%\Zetla\templates\`。
  - **导入模板**：支持本地模板目录或 zip（会校验 manifest，拒绝覆盖内置模板）。
  - **删除模板**：仅用户模板可删除，内置模板受保护。
  - 在模板库中可直接「用此模板新建」，向导会自动预选该模板。

## 编辑文档

- **多标签**：点击项目树文件即可打开；`Ctrl+W` 关闭；未保存的标签显示脏点 `●` 而不是关闭按钮
- **保存**：`Ctrl+S` 保存当前文件，`Ctrl+Shift+S` 全部保存；打开文件用 `Ctrl+O`
- **自动保存**：默认开启，每 30 秒写回未保存修改；编译期间默认暂停自动保存（可在设置中调整）
- **编码与换行**：自动识别 UTF-8 / GBK，状态栏只读展示编码与换行符；保存时保持原编码与 EOL，老文档不会乱码或改写换行
- **查找**：`Ctrl+F` 打开右上角浮动面板，全部命中高亮并显示 `n/N`；`↑↓` / `F3` / `Shift+F3` 导航，`Esc` 关闭；`Ctrl+H` 直接展开替换
- **替换**：支持 `Aa` 大小写、整词、`.*` 正则；「替换」当前项或「全部替换」，可勾选保留大小写
- **全局搜索**：`Ctrl+Shift+F` 或活动栏「搜索」，并发扫描项目内文本文件，按文件分组展示命中行；点击跳转并唤起单文件高亮，跨文件替换前会确认受影响文件数
- **注释**：`Ctrl+/` 切换行注释；撤销 / 重做 `Ctrl+Z` / `Ctrl+Y`
- **字号**：`Ctrl+滚轮` 缩放编辑器字体，或到「偏好设置 → 编辑器」调整字体与字号
- **快捷工具栏**：标签栏下方提供格式组（加粗 / 斜体 / 下划线 / 删除线）、插入组（链接 / 图片 / 列表 / 公式 / 表格）与章节层级下拉（`chapter` 至 `subparagraph`）；仅 `.tex` 文本缓冲显示
- **项目树**：右键可新建文件/文件夹、重命名、删除、从模板新建；`Ctrl+C` / `Ctrl+X` / `Ctrl+V` 在树内复制、剪切、粘贴（粘贴目标为选中目录、选中文件的父目录或项目根）
- **新建文件**：项目树右键或根行按钮「新建文件」支持任意后缀——
  - 类型快选提供 `.tex` / `.bib` / `.cls` / `.sty` / `.md` / `.txt` / 无后缀，默认 `.tex`，本次运行内会记住上次选择
  - 文件名自带后缀时以输入为准，否则自动拼接所选类型；对话框下方实时预览最终文件名
  - 文本类文件创建后自动打开标签；图片 / PDF 只创建文件，不自动打开
- **语言与高亮**：状态栏「文档语言」chip 默认按扩展名识别 LaTeX / BibTeX / BibTeX 样式 / TeX 日志 / 纯文本；未收录扩展名按纯文本渲染。点击 chip 可手动切换档位，或选择「恢复自动识别」；手动覆盖仅在本次运行内有效
- **小地图**：编辑器右侧显示语法着色的缩略图，点击可按比例滚动；默认开启，可在「偏好设置 → 编辑器 → 显示小地图」关闭。图片 / PDF 标签不显示小地图
- **跨文件跳转**：在 `\input{...}` / `\include{...}` / `\subfile{...}` 上 `Ctrl+点击` 打开目标 `.tex`；路径按「当前文件目录 → 主文件目录 → 项目根」依次解析，缺省自动补 `.tex`。按住 `Ctrl` 时显示链接态与「Ctrl+点击可跳转」提示，目标不存在时会提示且不会创建文件
- **诊断去噪**：被 `\input` 引入的章节片段不再误报「缺少 document 环境 / `\cite` 但没有参考文献 / 缺少引用 / 缺少宏包」；片段内的环境配对、括号闭合、重复 label 与数学模式仍会提示
- **自定义语法高亮**：「偏好设置 → 外观与保存 → LaTeX 语法高亮 → 自定义配色…」可调整 12 个语义分组的亮 / 暗颜色，套用 Zetla 默认 / GitHub / Dracula / Solarized / Nord 主题方案，并导出 / 导入配色 JSON；改动即时预览，点「取消」整体回滚
- **外部改动**：已打开文件被其他编辑器修改时，Zetla **不再弹出「重新加载 / 忽略」提示条**（2026-11-14 起）；缓冲区保持当前内容，重新打开该文件即可读到磁盘最新版本

## 代码片段

内置 22 条常用 LaTeX 片段，覆盖结构（`beg` / `itemize` / `enumerate` / `center`）、章节（`sec` / `ssec` / `sssec` / `para`）、浮动体（`fig` / `tab` / `eq` / `algn` / `cases` / `pmat`）、数学（`frac` / `sqrt` / `sum` / `int`）与文本（`fn` / `text` / `bf` / `it`）。

- **补全与展开**：在 `.tex` 中输入触发词会出现在补全弹窗；触发词精确命中时按 `Tab` 直接展开，未命中仍按原行为缩进。也可从菜单「插入代码片段…」唤起补全（`Ctrl+Shift+Space` 被中文输入法占用时的备用入口）。
- **选区包裹**：先选中文本再展开 `bf` / `it` 等包裹型片段，会生成 `\textbf{选中内容}`；无选区时插入占位符。
- **占位符跳转**：片段模板支持 `${1:占位}`，展开后用 `Tab` / `Shift+Tab` 逐槽填写。
- **管理**：设置「代码片段」页左侧可搜索并按「内置（只读）/ 自定义」分组，右侧编辑触发词、描述、分类与模板；保存后立即生效，自定义片段上限 500 条。
  - 校验空触发词、反斜杠 / 空白、与内置冲突及重复触发词。
  - 支持导入 / 导出 JSON 片段包，导入时可选择覆盖或追加合并。
  - 自定义片段保存在用户目录的 `snippets.json`，与项目无关。
- **模块开关**：可在「偏好设置 → 模块」停用代码片段；停用后补全与 `Tab` 直展短路，但不重建编辑器扩展，不会丢失当前占位符会话。

## 参考文献与引用

Zetla 会自动扫描项目内所有 `.bib` 文件，并把条目与引用信息集中到侧栏「引用」视图。

- **引用视图**：点击活动栏「引用」或按 `Ctrl+B 4`，也可从「视图」菜单切换。
  - **校验汇总条**：显示 `⚠ 重复 key N 处` / `❌ 缺失引用 M 处`，点击直达首个问题；全部正常时显示「✓ 引用无误」。
  - **条目列表**：按 `.bib` 文件分组、可折叠，展示 key、作者（年份）与 `@type`；顶部可按 key / 作者 / 标题搜索。重复 key 带标记，已引用条目显示被引次数。
  - **左键预览**：打开浮窗查看作者年份、标题、期刊 / 会议 / 出版社 / DOI / URL 等字段与来源文件行号。
  - **右键菜单**：在光标处插入 `\cite{key}`、跳到 `.bib` 条目、查看反向引用。
  - **反向引用**：列出该文献在项目 `.tex` / `.ltx` 中的引用位置，点击跳回源码行。
  - **导入参考文献…**：选择 Zotero 等工具导出的 `.bib`，复制到项目根目录（同名不覆盖）后自动纳入索引。
  - **手动刷新**：点「↻ 刷新」重新扫描项目目录并重建引用索引，可发现外部新增 / 改名的 `.bib` 与 `.tex`；刷新期间按钮显示「刷新中…」，完成后提示条目数。
- **输入引用**：在 `.tex` 中输入 `\cite{` 会自动补全文献 key（附带作者年份与标题）；悬停在已有 `\cite{key}` 上可预览条目信息。
- **Ctrl+点击跳转**：在 `\cite{key}` 上 `Ctrl+点击` 打开对应 `.bib` 条目；按住 `Ctrl` 时引用命令显示链接态并提示可点击。
- **`.bib` 高亮**：条目类型、引用 key、字段名、字段值、注释分色，亮 / 暗主题各一套。
- **校验**：跨 `.bib` 的重复 key、`.tex` 中缺失的引用会以波浪线和行号槽标记；支持 `\cite` / `\citep` / `\citet` / `\citeauthor` / `\nocite` 等，`\nocite{*}` 不误报。
- **PDF 引用跳转**：内置 `article` / `ctex-cn` 模板已启用 `hyperref`，由模板新建的项目编译后，PDF 中的 `[1]`、`\ref` 与 URL 可直接点击。

> 引用索引会在编辑、保存或外部修改 `.bib` 后自动更新（防抖 300ms）。Zotero 目前仅支持「导出 `.bib` 后导入」，未来计划会做 API 双向同步。

## 公式与符号

侧栏「公式」（`Ctrl+B 3`）把符号、模板、编写区和预览放在同一个视图中。

- **快捷工具**：10 个分类、354 个符号，按中英双语二级子类分区（二元运算符、希腊字母大小写、积分 / 双重积分 / 三重积分 / 曲线积分等）；符号以 KaTeX 渲染，滚动到视口附近才加载。
- **矩阵**：数组矩阵提供无括号 / 圆括号 / 方括号 / 行列式 / 分段函数 5 种入口；点击图标就地展开浮层，可切换环境、设置 1–10 行/列，`cases` 固定 2 列，并实时预览生成结果。
- **公式模板**：136 条内置公式、10 个分类（代数、几何、不等式、微积分、矩阵、三角公式、统计与概率、数列、物理、化学），支持最近使用与自定义增删改；条目为两行式布局，内置公式可带独立高度参数 `h`，长公式的预览字号随高度放大。
- **编写与插入**：单击符号或模板写入编写区；右键菜单可直接插入编辑器、写入编写区或复制 LaTeX。顶部齿轮切换行内 / 编号插入；编写区底部提供「插入编辑器 / 复制 LaTeX」，`Ctrl+Enter` 也可提交。
- **源码与可视化**：
  - 源码模式为上下分栏：上方 LaTeX 输入框、下方 KaTeX 实时预览；点击预览中的空槽只定位源码光标。
  - 可视化模式下渲染结果成为主编辑面：点击 `\Box` 选中槽位（首键即替换），`Tab` 在槽位间循环，活动槽高亮。
  - 两种模式共用同一份 LaTeX 源码，切换不会丢失内容。
- **布局与缩放**：符号面板与编写区之间的分割线可拖拽，编写区默认 / 最小高度 320px；源码框与预览按 1:1 平分剩余高度，二级工具栏固定 70px。编写区字号范围 10–50px（默认 20px），可用工具栏 `− / +` 或 `Ctrl+滚轮` 调整。
- **环境反向编辑**：
  - 编辑器里已有公式 / 表格环境的开头定界符右侧会显示 `✎` 徽标（如 `\begin{equation}✎`、`$✎`、`\begin{table}✎`）；点击即把该环境载入对应面板并切换到「公式」或「表格」侧栏。
  - 嵌套环境各自显示标记，内层优先；表格标记锚定在外层 `\begin{table}`，可同时编辑表格与单元格内的公式。
  - 修改后点「更新」原地写回源码。写回前会校验源码指纹：环境被手动改过则拒绝覆盖；内容未改则提示「公式未修改」。
  - 来自环境的公式会沿用原环境名重包裹，保留 `&` / `\\` 对齐；行内 `$...$` / `$$...$$` 按当前插入偏好重新包裹。更新成功后区间自动重绑，可连续微调。

## 图片与附件

- **插入图片**（三种方式）：
  - 把图片文件**拖进编辑器**
  - 在编辑器中**粘贴截图**（剪贴板含图片）
  - 菜单「插入 → 图片…」选择一个或多个文件
- 图片默认保存到 `项目根/figure/`，可在「设置 → 项目设置 → 显示 → 图片目录」改为其他相对路径；同名文件自动去重为 `base-1.ext`。
- 插入时按当前 `.tex` 所在目录计算相对路径，并自动生成完整 `figure` 环境（`\centering` → `\includegraphics` → `\caption` → `\label`），光标落在空 `\caption{}` 内，直接输入标题即可。
- 拖拽悬停时编辑器显示高亮边框；未打开项目或当前不是 `.tex` 标签时会提示，不会留下半成品源码。
- **图片 / PDF 标签页**：
  - 在项目树双击图片或 PDF，或使用「文件 → 打开图片 / PDF…」，会在代码区以只读标签打开。
  - 图片查看器支持 `Ctrl+滚轮` 缩放（0.1–8，以指针为锚点）与拖拽平移，底部显示文件名、尺寸与缩放比例。
  - PDF 标签页复用 PDF 渲染页，是打开时的快照，不随重新编译刷新；右侧 PDF 预览仍会随编译更新。
  - 非文本标签下撤销 / 重做 / 注释 / 保存 / 插入图片等编辑动作置灰；关闭标签不会提示未保存。
- 编译产物 `main.pdf` 仍会在打开项目时自动加载到右侧预览；「文件 → 打开 PDF…」已移除，统一从图片 / PDF 入口或项目树打开。

## 拼图

拼图把多张图片排成论文插图，提供两种平级模式：`subfigure`（生成可编辑的子图代码）与「合成单张图片」（合成一张 PNG 后直插）。侧栏只负责控制，排版结果在中心 Tab 预览。

- **进入方式**：
  - 活动栏「拼图」图标、`Ctrl+B 6`，或「视图」菜单。
  - 拖入 / 粘贴 / 菜单插入**多张**图片时自动进入：侧栏切到「拼图」，并打开中心「拼图预览」Tab。单图仍走原来的零步骤直插 `figure` 环境。
- **两种模式**：
  - `subfigure`：中心 Tab 显示 DOM 近似预览，生成带 `subfigure` 的网格代码，子标题保留为 LaTeX，可继续编辑与重排。
  - 合成单张图片：中心 Tab 显示 Canvas 实时合成预览，把子图合并为一张白底 PNG 并直插，子编号与子标题烘焙为像素。
  - 两种模式共用同一份布局、子图列表、单格参数与「图片标题」。
- **布局**：
  - 自动网格按图片数计算 `cols = ceil(√n)`、`rows = ceil(n / cols)`，导入 4 张即为 2×2；也可手动改行列。
  - 子图列表行优先编号 a / b / c…，显示缩略图、文件名与自动 `\label`；单击选中，再次点击取消选择（回到整图设置）。
  - 拖拽列表项可调整顺序，编号与 label 会跟着重排；每行右侧 `×` 删除子图。
  - 未选中子图时可调列间距与行间距（占列宽比例）；列间按 `\hfill` 语义均分剩余空间，行间生成 `\vspace{…\textwidth}`。
- **单格编辑**：
  - 子标题支持 `$...$`，`subfigure` 模式用 KaTeX 预览；合成模式用 MathJax 渲染后画进 PNG。留空时生成空 `\caption{}` 或只保留 `(a)` 编号。
  - 缩放 0.1–3；同一行按各格缩放比例分配宽度，并预留间距与 2% 安全余量，保证整行不超 `\textwidth`。
  - 对齐为**行级**属性（顶 / 中 / 底）：同一行混用不同对齐会让子图上下错位，因此整行取首格设置；`subfigure` 顶对齐生成 `\raisebox{-\height}` 以得到真正的顶边对齐，合成模式对齐「图片 + 子标题」单元块。
  - 裁剪为归一化四边值（左 / 下 / 右 / 上，0–1）：`subfigure` 生成 `trim=…, clip`，合成模式换算为 `drawImage` 源矩形；预览与产物使用同一套换算。
- **图片标题**：导入图片后侧栏显示「图片标题」，即外层 `figure` 的 `\caption{}`，两种模式共用；合成模式下同时作为 PNG 文件名。
- **`subfigure` 预览与生成**：
  - 中心 Tab 用 DOM 近似排版，与代码生成共用同一套宽度算法；裁剪、行级对齐、子标题与编号都会反映。PDF 子图由 pdf.js 渲染首页，图片用原始路径或内存对象 URL 直接预览。
  - 点「生成 subfigure 代码」时，才把真正进入代码的图片拷到图片目录（默认 `项目根/figure/`，可在项目设置修改），未使用的选图不会留下垃圾文件。
  - 生成前会检查图片目录中的同名文件；存在冲突时弹窗逐张选择「用 figure 中现有的」或「重命名复制新文件」，也可「全部用现有 / 全部重命名」。
  - 代码插入导入时绑定的目标 `.tex`（即使当前活动的是拼图预览 Tab），随后后台编译自检；编译失败会提示并在编辑器中选中刚插入的代码块，不阻塞继续编辑。缺少 `subcaption` 时侧栏横幅可一键加入导言区。
- **合成单张图片**：
  - 布局与 `subfigure` 共用宽度预算、行级对齐、裁剪与间距；行内剩余空间按 `\hfill` 语义均分，输出**白底 PNG**，固定 **1600px** 宽。
  - 子编号 `(a)` 与子标题会**烘焙进图片**：编号粗体、正文常规、居中于子图下方并自动换行；子标题里的 LaTeX 公式经 MathJax 渲染为自包含 SVG 后画入，导出 PNG 同样带公式。
  - 点「合成单图并插入」：合成 → PNG 落盘 → 生成单个 `figure` 环境（`\includegraphics[width=\linewidth]` + `\caption` + `\label`）直插目标 `.tex`，随后后台编译自检。
  - **命名**：图片标题非空 → `<标题>.png`（清洗 `/ \ : * ? " < > |` 等非法字符，保留中文）；为空 → `fig-<首个图片 slug>-composite.png`。同名文件**直接覆盖**，不弹冲突框。
  - **首次轻确认**：首次合成前提示子编号 / 子标题将变为像素、不再是可独立编辑的 `\subcaption`；可勾选「不再提示」，取消则不合成、不落盘。
  - 部分图片加载失败时留白继续合成；全部失败则提示且不落盘、不插入。总图题不烘焙，仍由 LaTeX `\caption` 生成；PDF 子图只取首页。

## 表格编辑

- **打开方式**：活动栏「表格」图标、`Ctrl+B 5`、或「视图」菜单；表格是模块化侧栏视图，可在「偏好设置 → 模块」停用。
- **网格编辑**：
  - 回车或失焦提交单元格；`Tab` / `Shift+Tab` 左右移，`Enter` / `Shift+Enter` 上下移，`Ctrl+方向键` 跨格，`Esc` 退出编辑。
  - 拖拽或 `Shift+点击` 选择矩形区域；`Ctrl+C` 复制为 TSV，`Ctrl+V` 以当前格为左上角铺入，可直接从 Excel 粘贴。
  - 右键行号 / 列号可插入或删除行 / 列；选中矩形可合并 / 拆分；列级对齐支持 `l` / `c` / `r`。
  - 可视化网格在亮 / 暗主题下都有清晰框线，单元格边界一目了然。
- **样式与输出**：
  - 线型三选：三线表（booktabs，默认）、全框线（grid）、无线（plain）。
  - 宽度可选自然宽或撑满页宽（tabularx + `X` 列）。
  - 可填写表题与标签；标签留空时按表题自动推导 `tab:<slug>`。
  - 单元格转义支持智能 / 全转义 / 不转义；展开「生成代码」可预览最终 LaTeX。
- **导入与反向编辑**：
  - 「导入 CSV」读取 CSV / TSV / txt（`.xlsx` 请先另存为 CSV）。
  - 「载入表格」会把光标处已有 `tabular` 回填到网格；「更新表格」仅在源码指纹未变时原地替换，手改过源码会拒绝覆盖。
  - 源码中已有表格环境的开头会显示 `✎` 徽标，点击即可把该表格载入网格；单元格内的公式也各自带 `✎`，可直接转入公式面板编辑。
  - 缺少 `booktabs` / `multirow` / `tabularx` 等宏包时给出提示，可一键「加入导言区」。
- **插入**：点「插入到编辑器」把表格代码写到当前 `.tex` 光标处，并把光标定位到 `\caption{}`；表格上限 100 行 × 20 列。

## 编译与排错

- **编译**：`Ctrl+B`，或点击标签栏右上角 **▶** / 状态栏的编译按钮；状态栏显示「编译中…」、进度条与当前流程步骤
  - 编译前会自动保存已修改文档（可在设置中关闭）
  - 编译中点击编译按钮即**终止编译**
  - **▶** 右侧的 **▾** 展开流程菜单切换当前流程；状态栏编译按钮**右键 / 长按约 0.5 秒**打开同一菜单（见[自定义编译流程](#自定义编译流程)）
  - 进度条右侧的 chip 显示当前工具与步骤位置（如 `XeLaTeX（1/4）`）；序号按流程原始步骤计，条件步骤被跳过时会跳号，悬浮可看流程名与跳过原因，`repeat` 收敛重跑标注「· 重跑」。默认 `latexmk` 流程只有一步（`latexmk（1/1）`），切到 `engine-direct` 或自定义多步流程可看到完整序列
- **保存时自动编译**：「偏好设置 → 编译设置 → 保存时自动编译」开启后，手动保存 `.tex`（`Ctrl+S` / 全部保存）会触发编译；400ms 内的多次保存合并为一次，定时自动保存不会触发
- **实时预览**：「偏好设置 → 编译设置 → 实时预览」开启后（默认关闭），停止输入即防抖自动编译；延迟可选 500 / 600 / 800 / 1200 ms（默认 600 ms）
  - 实时编译静默执行：不展开日志面板、不弹 toast、编译前静默保存，不打断继续输入
  - 重叠触发按 **latest-wins** 顶替：旧任务被终止并静默丢弃，只保留最新一次结果
  - 编译成功后 PDF 自动滚动到编译前光标所在行（静默锚定）；手动编译会清除锚定
  - 与「编译后清理」互斥：实时预览期间保留 `.fdb_latexmk` / `.fls` / `.synctex.gz`，兼顾增量编译与跳转
- **清理辅助文件**：菜单「构建 → 清理辅助文件」会递归删除 `.aux`、`.log`、`.bbl`、`.toc`、`.out`、`.synctex.gz` 等辅助文件，源文件与 PDF 不受影响，完成后提示删除数量并刷新资源树
- **编译后自动清理**：「偏好设置 → 编译设置 → 编译完成后清理辅助文件」开启后，仅在编译成功时按清单清理；失败或取消不清理，删除数量为 0 时静默
  - **自定义清理清单**：默认 14 项后缀，以 chip 展示，可逐项移除；输入后缀回车添加（自动补点、转小写、去重），也可「恢复默认」
  - 手动「清理辅助文件」与编译后清理共用同一份清单；清单为空时使用内置默认值
  - `.tex` / `.bib` / `.cls` / `.sty` / `.pdf` 等受保护后缀永不删除，即使误填进清单也会被后端拦截
- **流水线（默认）**：内置 `latexmk` 流程按生效引擎自动多轮；找不到 `latexmk` 或没有可用 Perl 时自动回退到内置 `engine-direct` 流程（引擎 → biber（存在 `.bcf` 才跑）→ 引擎 → 引擎）。流程可以替换或自定义，见[自定义编译流程](#自定义编译流程)
- **日志面板**：停靠在编辑 / 预览区下方（不横跨侧栏），开始编译时自动展开，分「全部 / 错误 / 警告 / 终端」四个页签
  - 「全部」实时输出编译器原始日志
  - 0.2.3 起编译进程关闭了 TeX 默认的 79 列硬折行，长路径与长报错保持完整一行；面板按当前宽度软换行，拖宽即可看到更多
  - 「错误 / 警告」为解析后的结构化列表，点击条目直接跳到对应文件与行列
  - 「终端」为内置终端（见下节），首次切到该页签时才创建会话，之后常驻
  - 拖拽面板顶边可调整高度（120–560px，编辑区至少保留 180px），高度随布局记忆保存
  - 需要原始 `.log` 文件时可用菜单「帮助 → 查看日志文件」；「视图 → 显示 / 隐藏日志面板」或状态栏按钮可随时开合
- **内置终端**：
  - Windows 默认启动 PowerShell（`-NoLogo`），Linux / Unix 跟随 `$SHELL`；终端 `PATH` 与编译引擎同源，可直接运行 `latexmk` / `xelatex` / `tlmgr` / git 等命令
  - **多会话**：点页签栏右端 **＋** 新建；会话数 ≥ 2 时右侧出现竖列表切换。每个会话拥有独立缓冲与 PTY，切换页签或会话不会中断后台任务
  - **操作按钮**：页签栏右端 **＋ / ▾ / 清屏 / 关闭**；▾ 菜单含新建、清屏、重开终端、关闭当前、关闭所有终端，切走页签会自动收起
  - 终端主题跟随亮 / 暗模式，面板尺寸变化自动适配；输出量大时按帧合并，界面保持流畅
  - 选中文本自动复制与右键粘贴可在设置中开关；`Ctrl+滚轮` 仅缩放当前会话字号，不回写设置
  - 会话仅存在于本次运行，关闭应用或关闭会话即回收进程；进程异常退出后可「重开终端」
- **引擎说明**：可在「偏好设置 → 编译设置」选择 XeLaTeX / pdfLaTeX / LuaLaTeX，默认跟随项目 `.ltex/config.json`；当前流程可在标签栏 ▶|▾ 或状态栏编译按钮右键 / 长按查看与切换。流程里写具体引擎名会固定使用该引擎，不受此处设置影响

## 自定义编译流程

编译流程由两层数据描述：**Tool（工具）** 是一条可执行命令（命令 + 参数 + 环境变量），**Recipe（流程）** 是有序的工具步骤（可带条件、自动重跑、失败回退）。两个内置流程 `latexmk` / `engine-direct` 不可删不可改，其余流程与工具都在「偏好设置 → 编译设置 → 编译流程（Tool / Recipe）」里增删改。

| 想做什么 | 在哪操作 |
| --- | --- |
| 临时换一个流程编译 | 标签栏 **▾**，或状态栏编译按钮右键 / 长按 → 选中即切换**当前流程**并立即编译；之后 ▶ / `Ctrl+B` / 保存即编译 / 实时预览都跟随它 |
| 恢复默认 | 同一个菜单首项「按默认流程编译」 |
| 新建 / 编辑流程 | `Ctrl+,` → 编译设置 →「+ 新建流程」→「编辑步骤」增删工具、上下移动 →「设为默认」→ **保存设置** |
| 自定义命令、条件、完整字段 | 设置页「高级：JSON 编辑（完整字段）」，支持 `%DOC%` / `%DOCFILE%` / `%DIR%` / `%OUTDIR%` 等占位符、`when` 条件、`repeat.untilStable`、`fallback` |
| 跳到编排面板 | 流程菜单末项「管理编译流程…」 |

步骤直接写**真实引擎名** `xelatex` / `pdflatex` / `lualatex` 即固定该引擎；`latexmk` / `biber` / `bibtex` 是辅助工具，`biber` / `bibtex` 未安装时会跳过该步。老配置里的 `latex` 别名仍由后端兼容为「跟随当前引擎」。最小示例（粘贴到设置页的 JSON 编辑器即可）：

```json
{
  "tools": [],
  "recipes": [
    {
      "name": "my-once",
      "tools": ["pdflatex"],
      "repeat": null,
      "fallback": "latexmk"
    }
  ],
  "defaultRecipe": "my-once"
}
```

工具、流程与默认流程只保存在**全局** `%APPDATA%\Zetla\config.json` 的 `build` 段，**不写入项目的 `.ltex/config.json`**；菜单选择的「当前流程」存在本地 `localStorage`，不进配置文件。完整字段说明、占位符表、条件写法、多份可复制配方与排错清单见 **[自定义编译流程指南](自定义编译流程指南.md)**。

## 查看 PDF

- 编译成功后自动加载项目主文件对应的 PDF；如需查看其他 PDF 或图片，可在项目树双击，或用菜单「文件 → 打开图片 / PDF…」在代码标签页打开
- **缩放**：默认「适合宽度」，可选 100% / 125% / 150%，或 `Ctrl+滚轮` 连续缩放（以指针位置为锚点）
- **翻页**：工具栏页码输入与上下翻页；连续滚动时自动同步当前页
- **页内查找**：指针在预览区内时按 `Ctrl+F`，支持命中高亮与上/下一个
- **侧栏**：缩略图与目录（大纲）切换，点击即跳页
- **分栏**：拖动编辑区与预览之间的分隔条调整比例，布局会被记住

## 偏好设置

`Ctrl+,` 打开，共八个页签：

| 面板 | 主要选项 |
| --- | --- |
| 通用 | 启动恢复上次项目、记住窗口大小与位置、恢复布局（含日志面板高度） |
| 编译设置 | TeX 发行版检测、编译前自动保存、保存时自动编译、实时预览与延迟、编译后清理辅助文件与自定义清单、默认编译引擎、**编译流程（Tool / Recipe）编排**（内置流程、新建/编辑流程与工具、默认流程、JSON 高级编辑） |
| 编辑器 | 字体、字号、自动换行、`Ctrl+滚轮` 缩放、显示小地图、括号匹配/折叠；**终端**分组：字体、字号、光标样式与闪烁、回滚行数、选中自动复制、右键粘贴、默认工作目录 |
| PDF 预览 | 默认缩放、保留滚动位置、渲染引擎（pdf.js） |
| 外观与保存 | 主题（亮色 / 暗色 / 跟随系统）、LaTeX 语法高亮自定义（12 个语义分组、主题方案、导入导出）、自动保存开关、间隔、编译期间暂停 |
| 代码片段 | 内置只读 / 自定义片段双栏管理、触发词与模板编辑、导入导出 JSON |
| 模块 | 公式、表格、拼图与代码片段模块启停（停用后对应入口与能力同步隐藏） |
| 关于 Zetla | 版本信息、软件更新（检查 / 下载 / 安装） |

项目自身的配置（名称、主文件、引擎、图片目录、排除规则等）在「设置 → 项目设置…」中管理，写入项目内的 `.ltex/config.json`。编译流程**只做全局配置**，不会写进项目文件。

配置文件位置：`%APPDATA%\Zetla\config.json`（`build.tools` / `build.recipes` / `build.defaultRecipe` 也在其中）。自定义流程的完整写法见[自定义编译流程指南](自定义编译流程指南.md)。
