# Zetla

面向 Windows 的桌面 LaTeX 工作台，把项目管理、代码编辑、编译日志和 PDF 预览放进同一个应用里。

> 当前最新版本 `0.2.1`。功能完整的桌面 LaTeX 工作台：管理项目 → 编辑 `.tex` → 一键编译 → 查看 PDF，源码与 PDF 支持双向跳转；并内置项目管理与模板库、表格编辑器、图片插入、BibTeX 参考文献、公式/符号面板、语言档位与小地图、可自定义语法高亮、自动更新与亮暗双主题。

## 功能

- **项目管理**：无项目时显示欢迎页与最近项目列表（置顶 / 归档 / 重命名 / 导出 zip / 删除）；`Ctrl+R` 项目切换器（切换时保留各自标签页）；项目设置可改名称、描述、类型、主文件、引擎、图片目录与资源树排除规则
- **项目与编辑**：打开 / 新建项目、新建任意后缀文件（类型快选）、项目树右键操作、多标签编辑（撤销栈独立）、自动保存、外部改动重载提示、GBK 文档不乱码
- **编辑器体验**：LaTeX / BibTeX / BibTeX 样式 / TeX 日志 / 纯文本五档高亮，未收录扩展名按纯文本渲染；状态栏语言 chip 可手动切换或恢复自动识别；右侧小地图可点击滚动、跟随主题，可在设置中关闭；LaTeX 语法高亮支持 12 个语义分组自定义、亮暗双色、主题方案与导入导出
- **模板库**：6 套内置模板（英文文章 / 中文文章 / 多文件毕业论文 / 多文件幻灯片 / 简历 / 宁夏大学学位论文），支持多文件生成与动态变量表单；可另存当前项目为模板、导入目录或 zip、删除用户模板
- **一键编译**：优先 `latexmk -xelatex`，缺少 Perl 时回退到多遍 `xelatex`；实时日志面板停靠在编辑区下方、高度可拖拽并记忆，结构化报错可点击跳转行列；引擎可选（XeLaTeX / pdfLaTeX / LuaLaTeX），支持自定义编译流程、保存时自动编译、编译后按自定义清单清理辅助文件
- **表格编辑**：侧栏「表格」视图网格编辑，支持合并 / 拆分、对齐、三线表 / 全框线 / 无线、CSV / TSV 导入、Excel 粘贴与光标处表格反向回填
- **图片与附件**：拖拽 / 粘贴 / 菜单插入图片并自动生成 `figure` 环境；图片与 PDF 可在代码标签页只读查看，图片支持缩放与平移
- **双向跳转**：编辑器 Ctrl+点击跳转 PDF 对应位置并高亮，PDF Ctrl+点击回跳源码行列（SyncTeX）；`\input` / `\include` / `\subfile` 也支持 Ctrl+点击直接打开目标 `.tex`
- **大纲导航**：侧栏自动梳理 `\input`/`\include` 链中的章节结构，层级展示、点击直达
- **参考文献（BibTeX）**：自动扫描项目内所有 `.bib` 文件并建立索引；`\cite{` 自动补全、悬浮预览、Ctrl+点击跳转条目、`.bib` 专属高亮、重复 key / 缺失引用校验；侧栏「引用」视图支持按文件分组、搜索、手动刷新、导入 `.bib`、条目预览与反向引用
- **公式与符号**：侧栏「公式」视图整合符号库、结构模板、公式模板、编写区与 KaTeX 预览——
  - **快捷工具**：10 个分类、191 个常用符号，另含 24 个结构模板（分数、根式、上下标、矩阵、cases、积分等）
  - **公式模板**：81 条内置公式、9 个分类，支持搜索、最近使用与自定义增删改
  - 单击写入编写区，右键可直接插入编辑器 / 写入编写区 / 复制 LaTeX；顶部齿轮切换行内或编号；结构模板的 `\Box` 空槽插入编辑器后可按 `Tab` 逐槽填写
  - KaTeX 实时预览与可视化点槽、二级工具栏（颜色 / 字体 / 字号 / 环境 / 源码·可视化）、编写区与预览区 `Ctrl+滚轮` 缩放
- **PDF 预览**：基于 PDF.js，支持缩放、翻页、页内查找、缩略图与目录侧栏，可与编辑区拖拽分栏；图片 / PDF 也可在代码标签页以只读方式打开，右侧预览仍随编译刷新
- **自动更新**：启动自动检测新版本（Gitee / GitHub 双源回退，Rust 侧请求避免 WebView CORS），发现新版本时帮助菜单显示红点并在「关于 Zetla」提供更新；可一键下载安装包并启动安装向导（安装包未做代码签名，若被拦截点「仍要运行」即可）
- **安装体验**：安装包自动检测 WebView2 Runtime，缺失时联网下载并静默安装（不增加安装包体积）；正式版屏蔽 WebView2 原生右键菜单，避免干扰自绘菜单
- **环境引导**：启动自动检测 TeX；未安装可自动下载安装 TeX Live（基础/完整方案），也支持接管已有安装
- **桌面体验**：亮 / 暗双主题（可跟随系统）、窗口大小与位置记忆、主窗口最小尺寸 1024×640、布局记忆（含日志面板高度）、启动恢复上次项目（连同上次打开的标签页）、菜单栏与状态栏

## 安装

1. 到 [Releases](https://github.com/Wastarch/Zetla/releases/latest) 下载 `Zetla_0.2.1_x64-setup.exe`。
2. 运行安装包。当前版本**未签名**，Windows SmartScreen 提示时选择「更多信息 → 仍要运行」。
3. 安装模式可以为「仅当前用户」，无需管理员权限。也可以为所有用户安装。
4. 安装包会自动检测 WebView2 Runtime：已安装则跳过；缺失时尝试联网下载并静默安装（失败会提示手动安装地址）。
5. 卸载时若检测到 **Zetla 代装的 TeX Live**，会询问是否一并删除；默认保留，TeX 可继续被其他软件使用。
6. 从 `0.2.0` 及更早版本升级可直接覆盖安装，配置、偏好、最近项目与上次项目都会保留；已保存的语法高亮配色会迁移并补全缺失分组。

系统要求：

- **Windows 10/11**（当前主要开发与验收平台）
- **WebView2 Runtime**（Windows 10/11 通常已内置；缺失时安装包会尝试联网自动安装，也可手动安装）
- **TeX Live**：可选。不装也能启动，首次进入时可在应用内安装（见下一节）

> 国内网络下应用会自动尝试清华 TUNA、阿里云等镜像下载 TeX Live 安装器。

### 首次启动：准备 TeX 环境

Zetla 每次启动都会检测 TeX，顺序为：Zetla 独立目录 → 系统 `PATH` → 常见安装位置。

- **已装 TeX Live / MiKTeX**：检测到即可直接编译，状态栏会显示引擎信息。
- **未装 TeX**：自动弹出引导面板，可选：
  - **自动安装 TeX Live**：进入向导后选择方案与目录
    - *基础方案*：约 1.5 GB，含 XeLaTeX 与中文支持（ctex / fandol），适合大多数文档，后续可用 `tlmgr` 补包
    - *完整方案*：约 5 GB，包含全部宏包与文档
    - 默认安装到 `%LOCALAPPDATA%\Zetla\tex\texlive`，也可选其他盘符；**只写入 Zetla 独立目录，不修改系统 PATH**
    - 安装中可随时取消，取消后会清理本次新建的目录
  - **接管已有安装**：点「指定/接管已有安装…」，选择 TeX Live 根目录、`bin` 或 `bin\windows` 均可
  - **手动安装**：按面板内的官网指引自行安装后，回到应用重新检测
- 之后随时可通过菜单「帮助 → TeX 环境检测…」或「偏好设置 → 编译设置 → 检测 / 引导…」重新打开该面板。

### 新建或打开项目

- 启动后如果没有打开项目，编辑区会显示**欢迎页**：可「从模板新建」「打开项目文件夹…」，或直接从最近项目列表打开。
- **新建项目**：`Ctrl+Shift+N`（或菜单「文件 → 新建项目…」/ 欢迎页「从模板新建」）
  1. 「从模板新建」直接进入**模板库**：左侧分类、中间列表、右侧详情；选中模板后点「用此模板新建」
  2. 内置模板共 6 套：`article`（英文文章）、`ctex-cn`（中文文章）、`thesis-cn`（多文件毕业论文）、`beamer-cn`（多文件幻灯片）、`resume-cn`（中文简历）、`nxuthesis`（宁夏大学学位论文）
  3. 向导顶部显示当前模板，可点「← 返回模板库」更换；按模板变量填写标题、作者等信息，变量表单支持分组、必填、下拉、日期、开关与多选（宽屏两列）
  4. 选择生成位置 → 生成 `main.tex` 并写入 `.ltex/config.json`（记录主文件与引擎）；多文件模板会同时创建章节 / 分节目录
  5. 创建完成后自动打开到编辑器
- **打开已有项目**：`Ctrl+Shift+O`，选择项目文件夹。
  - 主文件判定顺序：`.ltex/config.json` 的 `mainFile` → 根目录 `main.tex` → 含 `\documentclass` 的最浅 `.tex` → 首个 `.tex`
  - 项目树中主文件带 `main` 标记
- **切换项目**：`Ctrl+R` 打开项目切换器，输入过滤、`↑↓` 选择、`Enter` 打开；切换时各项目的标签页会保留到本次运行结束。

### 项目管理

- **欢迎页与最近项目**
  - 最近项目以列表展示名称、位置、最近打开时间与操作按钮；点「打开」或双击行即可进入项目。
  - **置顶**：点击 ★ 把常用项目固定在列表顶部；再次点击取消置顶。
  - **归档**：在「⋯」菜单选择「归档」，项目移入「已归档」分组，不移动或删除目录；可随时取消归档。
  - **「⋯」菜单**：重命名项目、导出为 zip、归档 / 取消归档、删除项目。
- **项目切换器**（`Ctrl+R`，或「文件 → 切换项目…」）
  - 列出最近项目（置顶优先），输入关键字过滤；`↑↓` 选择、`Enter` 打开、`Esc` 关闭。
  - 末项「打开其他文件夹…」可直接选择新目录。
  - 切走时记住当前项目的标签页与活动标签，切回时按项目树过滤后恢复；该缓存仅在本次运行内有效。
- **项目设置**（菜单「设置 → 项目设置…」）
  - **常规**：项目名（默认取目录名，用于欢迎页与最近项目）、描述、类型（论文 / 学位论文 / 幻灯片 / 简历 / 自定义）。
  - **构建**：主文件（项目内 `.tex` 下拉，可自动识别）、编译引擎；输出目录当前固定为主文件同目录，界面置灰。
  - **显示**：图片目录（相对项目根，默认 `figure`）、排除规则（每行一个 glob，仅影响资源管理器树的显示）。
  - 保存后写入 `.ltex/config.json`，资源树立即刷新（引擎标签、主文件标记、排除项隐藏），欢迎页项目名同步更新。
- **项目生命周期**
  - **重命名**：重命名项目文件夹，并同步最近项目名称。
  - **删除**：删除整个项目文件夹，**不可撤销、不进回收站**，操作前会二次确认。
  - **导出为 zip**：打包项目源码与 PDF，排除辅助文件、`node_modules`、`target`、`dist` 与 `.git`。
  - 打开中的项目由后端保护，不能重命名 / 删除；仍可安全导出。
- **模板库**（菜单「模板 → 模板库」，或欢迎页「从模板新建」直接进入）
  - 左侧按分类浏览内置模板与用户模板，右侧搜索与详情；详情展示引擎、主文件、变量、文件数、版本与标签。
  - 内置 6 套模板；「宁夏大学学位论文」含 23 项变量（中英文标题、培养单位、导师、学号、分类号、密级等）与出稿格式、盲审封面、书脊、数学字体等外观选项。
  - **另存当前项目为模板**：菜单「模板 → 另存当前项目为模板…」，保存到 `%APPDATA%\Zetla\templates\`。
  - **导入模板**：支持本地模板目录或 zip（会校验 manifest，拒绝覆盖内置模板）。
  - **删除模板**：仅用户模板可删除，内置模板受保护。
  - 在模板库中可直接「用此模板新建」，向导会自动预选该模板。

### 编辑文档

- **多标签**：点击项目树文件即可打开；`Ctrl+W` 关闭；未保存的标签显示脏点 `●` 而不是关闭按钮
- **保存**：`Ctrl+S` 保存当前文件，`Ctrl+Shift+S` 全部保存；打开文件用 `Ctrl+O`
- **自动保存**：默认开启，每 30 秒写回未保存修改；编译期间默认暂停自动保存（可在设置中调整）
- **编码与换行**：自动识别 UTF-8 / GBK，状态栏只读展示编码与换行符；保存时保持原编码与 EOL，老文档不会乱码或改写换行
- **查找**：编辑器内 `Ctrl+F` 打开 CodeMirror 查找面板
- **注释**：`Ctrl+/` 切换行注释；撤销 / 重做 `Ctrl+Z` / `Ctrl+Y`
- **字号**：`Ctrl+滚轮` 缩放编辑器字体，或到「偏好设置 → 编辑器」调整字体与字号
- **项目树**：右键可新建文件/文件夹、重命名、删除、从模板新建；`Ctrl+C` / `Ctrl+X` / `Ctrl+V` 在树内复制、剪切、粘贴（粘贴目标为选中目录、选中文件的父目录或项目根）
- **新建文件**：项目树右键或根行按钮「新建文件」支持任意后缀——
  - 类型快选提供 `.tex` / `.bib` / `.cls` / `.sty` / `.md` / `.txt` / 无后缀，默认 `.tex`，本次运行内会记住上次选择
  - 文件名自带后缀时以输入为准，否则自动拼接所选类型；对话框下方实时预览最终文件名
  - 文本类文件创建后自动打开标签；图片 / PDF 只创建文件，不自动打开
- **语言与高亮**：状态栏「文档语言」chip 默认按扩展名识别 LaTeX / BibTeX / BibTeX 样式 / TeX 日志 / 纯文本；未收录扩展名按纯文本渲染。点击 chip 可手动切换档位，或选择「恢复自动识别」；手动覆盖仅在本次运行内有效
- **小地图**：编辑器右侧显示语法着色的缩略图，点击可按比例滚动；默认开启，可在「偏好设置 → 编辑器 → 显示小地图」关闭。图片 / PDF 标签不显示小地图
- **跨文件跳转**：在 `\input{...}` / `\include{...}` / `\subfile{...}` 上 `Ctrl+点击` 打开目标 `.tex`；路径按「当前文件目录 → 主文件目录 → 项目根」依次解析，缺省自动补 `.tex`。按住 `Ctrl` 时显示链接态与「Ctrl+点击可跳转」提示，目标不存在时会提示且不会创建文件
- **诊断去噪**：被 `\input` 引入的章节片段不再误报「缺少 document 环境 / `\cite` 但没有参考文献 / 缺少引用 / 缺少宏包」；片段内的环境配对、括号闭合、重复 label 与数学模式仍会提示
- **自定义语法高亮**：「偏好设置 → 外观与保存 → LaTeX 语法高亮 → 自定义配色…」可调整 12 个语义分组的亮 / 暗颜色，套用 Zetla 默认 / GitHub / Dracula / Solarized / Nord 主题方案，并导出 / 导入配色 JSON；改动即时预览，点「取消」整体回滚
- **外部改动**：已打开文件被其他编辑器修改时，编辑器顶部会出现「重新加载 / 忽略」提示条；Zetla 自身保存后的回显不会误报

### 参考文献与引用

Zetla 会自动扫描项目内所有 `.bib` 文件，并把条目与引用信息集中到侧栏「引用」视图。

- **引用视图**：点击活动栏「引用」或按 `Ctrl+B 4`，也可从「视图」菜单切换。
  - **校验汇总条**：显示 `⚠ 重复 key N 处` / `❌ 缺失引用 M 处`，点击直达首个问题；全部正常时显示「✓ 引用无误」。
  - **条目列表**：按 `.bib` 文件分组、可折叠，展示 key、作者（年份）与 `@type`；顶部可按 key / 作者 / 标题搜索。重复 key 带标记，已引用条目显示被引次数。
  - **左键预览**：打开浮窗查看作者年份、标题、期刊 / 会议 / 出版社 / DOI / URL 等字段与来源文件行号。
  - **右键菜单**：在光标处插入 `\cite{key}`、跳到 `.bib` 条目、查看反向引用。
  - **反向引用**：列出该文献在项目 `.tex` / `.ltx` 中的引用位置，点击跳回源码行。
  - **导入参考文献…**：选择 Zotero 等工具导出的 `.bib`，复制到项目根目录（同名不覆盖）后自动纳入索引。
  - **手动刷新**：点「↻ 刷新」重新扫描项目目录并重建引用索引，可发现外部新增 / 改名的 `.bib` 与 `.tex`；刷新期间按钮显示「刷新中…」，完成后提示条目数。
- **输入引用**：在 `.tex` 中输入 `\cite{` 会自动补全文献 key（附带作者年份与标题）；悬停在已有 `\cite{key}` 上可预览条目信息。
- **Ctrl+点击跳转**：在 `\cite{key}` 上 `Ctrl+点击` 打开对应 `.bib` 条目；按住 `Ctrl` 时引用命令显示链接态并提示可点击。
- **`.bib` 高亮**：条目类型、引用 key、字段名、字段值、注释分色，亮 / 暗主题各一套。
- **校验**：跨 `.bib` 的重复 key、`.tex` 中缺失的引用会以波浪线和行号槽标记；支持 `\cite` / `\citep` / `\citet` / `\citeauthor` / `\nocite` 等，`\nocite{*}` 不误报。
- **PDF 引用跳转**：内置 `article` / `ctex-cn` 模板已启用 `hyperref`，由模板新建的项目编译后，PDF 中的 `[1]`、`\ref` 与 URL 可直接点击。

> 引用索引会在编辑、保存或外部修改 `.bib` 后自动更新（防抖 300ms）。Zotero 目前仅支持「导出 `.bib` 后导入」，未来计划会做 API 双向同步。

### 公式与符号

侧栏「公式」（`Ctrl+B 3`）把符号、模板、编写区和预览放在同一个视图中。

- **快捷工具**：10 个分类、191 个常用符号，另含 24 个结构模板；支持搜索与分类展开。
- **公式模板**：81 条内置公式、9 个分类，支持最近使用与自定义增删改。
- **编写与插入**：单击符号或模板写入编写区；右键菜单可直接插入编辑器、写入编写区或复制 LaTeX。顶部齿轮切换行内 / 编号插入。
- **预览**：输出区用 KaTeX 实时渲染；切到可视化后可点击占位槽回到源码定位。结构模板的 `\Box` 空槽插入编辑器后可按 `Tab` 逐槽填写。
- **工具栏与缩放**：二级工具栏提供颜色、字体、字号、环境下拉，以及清空和源码 / 可视化切换；编写区与预览区可分别用 `Ctrl+滚轮` 缩放。

### 图片与附件

- **插入图片**（三种方式）：
  - 把图片文件**拖进编辑器**
  - 在编辑器中**粘贴截图**（剪贴板含图片）
  - 菜单「插入 → 图片…」选择一个或多个文件
- 图片默认保存到 `项目根/figure/`，可在「设置 → 项目设置 → 显示 → 图片目录」改为其他相对路径；同名文件自动去重为 `base-1.ext`。
- 插入时按当前 `.tex` 所在目录计算相对路径，并自动生成完整 `figure` 环境（`\centering` → `\includegraphics` → `\caption` → `\label`），光标落在空 `\caption{}` 内，直接输入标题即可。
- 拖拽悬停时编辑器显示高亮边框；未打开项目或当前不是 `.tex` 标签时会提示，不会留下半成品源码。
- **图片 / PDF 标签页**：
  - 在项目树双击图片或 PDF，或使用「文件 → 打开图片 / PDF…」，会在代码区以只读标签打开。
  - 图片查看器支持 `Ctrl+滚轮` 缩放（0.1–8，以指针为锚点）与拖拽平移，底部显示文件名、尺寸与缩放比例。
  - PDF 标签页复用 PDF 渲染页，是打开时的快照，不随重新编译刷新；右侧 PDF 预览仍会随编译更新。
  - 非文本标签下撤销 / 重做 / 注释 / 保存 / 插入图片等编辑动作置灰；关闭标签不会提示未保存。
- 编译产物 `main.pdf` 仍会在打开项目时自动加载到右侧预览；「文件 → 打开 PDF…」已移除，统一从图片 / PDF 入口或项目树打开。

### 表格编辑

- **打开方式**：活动栏「表格」图标、`Ctrl+B 5`、或「视图」菜单；表格是模块化侧栏视图，可在「偏好设置 → 模块」停用。
- **网格编辑**：
  - 回车或失焦提交单元格；`Tab` / `Shift+Tab` 左右移，`Enter` / `Shift+Enter` 上下移，`Ctrl+方向键` 跨格，`Esc` 退出编辑。
  - 拖拽或 `Shift+点击` 选择矩形区域；`Ctrl+C` 复制为 TSV，`Ctrl+V` 以当前格为左上角铺入，可直接从 Excel 粘贴。
  - 右键行号 / 列号可插入或删除行 / 列；选中矩形可合并 / 拆分；列级对齐支持 `l` / `c` / `r`。
- **样式与输出**：
  - 线型三选：三线表（booktabs，默认）、全框线（grid）、无线（plain）。
  - 宽度可选自然宽或撑满页宽（tabularx + `X` 列）。
  - 可填写表题与标签；标签留空时按表题自动推导 `tab:<slug>`。
  - 单元格转义支持智能 / 全转义 / 不转义；展开「生成代码」可预览最终 LaTeX。
- **导入与反向编辑**：
  - 「导入 CSV」读取 CSV / TSV / txt（`.xlsx` 请先另存为 CSV）。
  - 「载入表格」会把光标处已有 `tabular` 回填到网格；「更新表格」仅在源码指纹未变时原地替换，手改过源码会拒绝覆盖。
  - 缺少 `booktabs` / `multirow` / `tabularx` 等宏包时给出提示，可一键「加入导言区」。
- **插入**：点「插入到编辑器」把表格代码写到当前 `.tex` 光标处，并把光标定位到 `\caption{}`；表格上限 100 行 × 20 列。

### 编译与排错

- **编译**：`Ctrl+B`，或点击工具栏 / 状态栏的编译按钮；状态栏显示「编译中…」与进度条
  - 编译前会自动保存已修改文档（可在设置中关闭）
  - 状态栏文案按钮在编译中点击即**终止编译**
- **保存时自动编译**：「偏好设置 → 编译设置 → 保存时自动编译」开启后，手动保存 `.tex`（`Ctrl+S` / 全部保存）会触发编译；400ms 内的多次保存合并为一次，定时自动保存不会触发
- **清理辅助文件**：菜单「构建 → 清理辅助文件」会递归删除 `.aux`、`.log`、`.bbl`、`.toc`、`.out`、`.synctex.gz` 等辅助文件，源文件与 PDF 不受影响，完成后提示删除数量并刷新资源树
- **编译后自动清理**：「偏好设置 → 编译设置 → 编译完成后清理辅助文件」开启后，仅在编译成功时按清单清理；失败或取消不清理，删除数量为 0 时静默
  - **自定义清理清单**：默认 14 项后缀，以 chip 展示，可逐项移除；输入后缀回车添加（自动补点、转小写、去重），也可「恢复默认」
  - 手动「清理辅助文件」与编译后清理共用同一份清单；清单为空时使用内置默认值
  - `.tex` / `.bib` / `.cls` / `.sty` / `.pdf` 等受保护后缀永不删除，即使误填进清单也会被后端拦截
- **流水线**：优先 `latexmk -xelatex` 自动多轮；系统中没有 Perl 时回退为多遍 `xelatex`
- **日志面板**：停靠在编辑 / 预览区下方（不横跨侧栏），开始编译时自动展开，分「全部 / 错误 / 警告」三个页签
  - 「全部」实时输出编译器原始日志
  - 「错误 / 警告」为解析后的结构化列表，点击条目直接跳到对应文件与行列
  - 拖拽面板顶边可调整高度（120–560px，编辑区至少保留 180px），高度随布局记忆保存
  - 需要原始 `.log` 文件时可用菜单「帮助 → 查看日志文件」；「视图 → 显示 / 隐藏日志面板」或状态栏按钮可随时开合
- **引擎说明**：可在「偏好设置 → 编译设置」选择 XeLaTeX / pdfLaTeX / LuaLaTeX，默认跟随项目 `.ltex/config.json`；状态栏引擎标签为只读展示

### 查看 PDF

- 编译成功后自动加载项目主文件对应的 PDF；如需查看其他 PDF 或图片，可在项目树双击，或用菜单「文件 → 打开图片 / PDF…」在代码标签页打开
- **缩放**：默认「适合宽度」，可选 100% / 125% / 150%，或 `Ctrl+滚轮` 连续缩放（以指针位置为锚点）

- **分栏**：拖动编辑区与预览之间的分隔条调整比例，布局会被记住

## 常见问题

**安装时被 SmartScreen 拦截？**
安装包尚未做代码签名，属正常现象。点「更多信息 → 仍要运行」。若企业策略禁止，可自行从源码构建。

**启动后提示未检测到 TeX？**
两种方式：在引导面板里自动安装 TeX Live；或先手动安装，再用「指定/接管已有安装…」选择 TeX Live 根目录 / `bin` / `bin\windows`，最后重新检测。

**编译报错找不到 `xelatex` 或 `latexmk`？**
说明当前引擎不在检测路径中。打开「偏好设置 → 编译设置 → 检测 / 引导…」重新检测或接管安装目录；确认安装包含 XeLaTeX 与 `latexmk`（TeX Live 完整安装自带）。

**自动安装 TeX Live 很慢 / 占空间？**
基础方案约 1.5 GB，完整方案约 5 GB，耗时取决于网络。安装器会自动尝试国内镜像；中途取消会清理本次新建目录。后续补包可用 TeX Live 自带的 `tlmgr`。

**打开 GBK 老文档会乱码吗？**
不会。读取时自动识别 UTF-8 / GBK，保存时保持原编码与原换行符。

**输入 `\cite{` 没有补全候选？**
请确认项目已打开且项目内存在 `.bib` 文件；`.bib` 保存或外部修改后索引会自动刷新。Zotero 用户可先导出 BibTeX 文件，再从「引用」视图的「导入参考文献…」加入项目。

**切换项目后，之前的标签页去哪了？**
项目切换器会在本次运行内按项目缓存标签页与活动标签，切回时恢复；重启 Zetla 后只恢复上次打开的项目及其标签页，其他项目从欢迎页进入。

**拖入图片没有反应？**
请确认已打开项目、当前是 `.tex` 标签，且文件为常见图片格式（PNG / JPG / WebP 等）。项目未打开或当前是图片 / PDF 等只读标签时会给出提示，不会插入源码。

**表格能直接导入 Excel（`.xlsx`）吗？**
不能直读 `.xlsx`。请先在 Excel 中另存为 CSV，再用表格面板「导入 CSV」；也可以直接从 Excel 复制区域，在网格中 `Ctrl+V` 粘贴。

**外部编辑器改了文件，Zetla 里怎么同步？**
编辑器顶部会出现「重新加载 / 忽略」提示条；点「重新加载」读取磁盘内容，点「忽略」保留当前编辑内容。

**清理辅助文件会删掉 PDF 或源码吗？**
不会。只删除白名单内的辅助文件，`.tex/.bib/.cls/.sty` 与 PDF 等受保护后缀始终保留；自定义清单误填受保护后缀也会被后端拦截。

**编译后自动清理怎么开？会清理哪些文件？**
到「偏好设置 → 编译设置」打开「编译完成后清理辅助文件」。默认按 14 项辅助后缀清理，也可用 chip 增删自定义后缀；手动「清理辅助文件」与编译后清理共用这份清单。只有编译成功才会执行。

**新建文件只能建 `.tex` 吗？**
不是。新建文件对话框提供 `.tex` / `.bib` / `.cls` / `.sty` / `.md` / `.txt` / 无后缀快选，也可以直接在文件名里输入任意后缀；文本文件创建后自动打开，图片 / PDF 只创建不打开。

**打开 `.md`、`.json` 或没有后缀的文件为什么没有语法高亮？**
这些扩展名未收录，会按纯文本渲染。可点击状态栏「文档语言」chip 手动指定档位，或选择「恢复自动识别」；手动指定仅在本次运行内有效。

**右侧小地图怎么关掉？**
「偏好设置 → 编辑器 → 显示小地图」关闭即可。小地图仅对文本缓冲区生效，图片 / PDF 标签不会显示。

**章节文件里全是「缺少 document 环境 / 缺少参考文献」的报错，怎么关？**
不用关，0.2.1 起这些**整篇级检查只对主文件生效**。被 `\input` 引入的章节片段不再误报缺少 `\documentclass`、`\bibliography`、引用或宏包；片段内的环境配对、括号、重复 label 与数学模式仍会检查。当前还没有逐项关闭诊断的开关，遇到误报欢迎提 Issue。

**`\input{chapter/chap01}` 能像 `\cite` 一样跳转吗？**
可以。按住 `Ctrl` 点击 `\input` / `\include` / `\subfile` 的花括号内容即可打开目标 `.tex`；路径按「当前文件目录 → 主文件目录 → 项目根」解析并自动补 `.tex`。目标不在项目树内或文件不存在时只会提示，不会创建文件。

**语法高亮颜色能自己改吗？改完重启还在吗？**
能。「偏好设置 → 外观与保存 → LaTeX 语法高亮 → 自定义配色…」可调整 12 个语义分组的亮 / 暗颜色，也能一键套用 Zetla 默认 / GitHub / Dracula / Solarized / Nord。配色写入 `%APPDATA%\Zetla\config.json`，重启后保留；也可导出 JSON 备份或分享。当前仅作用于 LaTeX 档，BibTeX / `.bst` / `.log` / 纯文本仍用内置配色。

**日志面板挡住编辑区了，能调小吗？**
拖拽日志面板顶部边缘即可调整高度（120–560px，编辑区至少保留 180px），高度会被记住；也可用「视图 → 隐藏日志面板」或状态栏按钮收起。

**宁夏大学学位论文模板怎么用？**
欢迎页「从模板新建」→ 模板库选「宁夏大学学位论文」→「用此模板新建」，填写 23 项变量（中英文标题、培养单位、导师、学号、分类号、密级等）并选择出稿格式、盲审封面、书脊与数学字体后生成。模板使用 `nxuthesis.cls` + XeLaTeX，需要 TeX Live 含 `ctex` / `natbib` / `hyperref` 等宏包；联合导师留空时不会生成对应字段。

**安装时 WebView2 自动安装失败？**
自动安装需要联网。请按提示从 [微软 WebView2 页面](https://developer.microsoft.com/microsoft-edge/webview2/) 手动安装 Runtime 后重新运行安装程序；Windows 10/11 通常已内置，不会触发下载。

**正式版右键为什么没有系统菜单？**
正式版屏蔽了 WebView2 原生右键菜单，避免与应用自绘菜单冲突并避免暴露调试入口。项目树、引用面板等自绘菜单不受影响；文本框内复制 / 粘贴请用 `Ctrl+C` / `Ctrl+V`。

**为什么项目设置里的「输出目录」是灰的？**
当前版本编译产物固定落在主文件同目录，输出目录支持留待后续版本；该字段会保留原值，不会清除。

**卸载后配置和 TeX 还在吗？**
应用配置在 `%APPDATA%\Zetla\config.json`；应用内安装的 TeX Live 在 `%LOCALAPPDATA%\Zetla\tex\`，卸载时可选择是否保留。

**还有哪些功能在规划中？**
绘图组件（M2）、条件模板、代码格式化 / 拼写检查、多项目并排工作区（同时打开多个项目）、输出目录支持、表格 `.xlsx` 直读等仍在规划中，相关入口会置灰并标注计划。以下能力已在 `0.2.1` 提供：项目管理与模板库、模板库新建衔接、宁夏大学学位论文模板、表格编辑器、图片插入与图片 / PDF 标签页、语言档位与纯文本兜底、小地图、可自定义 LaTeX 语法高亮（主题方案 / 导入导出）、日志面板停靠与高度记忆、章节片段诊断去噪、`\input` 跨文件跳转、新建任意后缀文件、外部改动重载、清理辅助文件与自定义清单、编译后自动清理、保存时自动编译、自动更新、多编译引擎（XeLaTeX / pdfLaTeX / LuaLaTeX）、SyncTeX 双向跳转、亮暗主题、公式与符号面板、BibTeX 参考文献（补全 / 预览 / 跳转 / 校验 / 管理 / 手动刷新）。

## 从源码运行

环境要求：

- **Node.js 20+**（Vite 8 要求）
- **Rust stable** 与 Cargo
- **Visual Studio 2022 Build Tools**，包含 MSVC 和 Windows SDK

```powershell
git clone https://github.com/Wastarch/Zetla.git
cd Zetla
npm install
npm run tauri dev
```

首次启动需要编译 Rust 后端，耗时会比后续启动长。

> 如果 `cargo` 找不到 `link.exe`，请在 “Developer PowerShell for VS 2022” 中运行构建命令。

### 构建安装包

正式包使用 **Inno Setup 6**（需本机安装 Inno Setup；编译器 `ISCC.exe` 会自动从注册表/常见目录查找，也可用 `INNO_SETUP_ISCC` 指定）：

```powershell
# 1) 只编 release exe（不触发 NSIS 下载）
npm run tauri build -- --no-bundle

# 2) 调 ISCC 生成安装包
npm run package:inno
```

也可以一步完成：

```powershell
npm run package:win
```

安装包输出到：

```text
build/installer/Zetla_<version>_x64-setup.exe
```

版本号唯一源是 `package.json` 的 `version` 字段：`scripts/sync-version.mjs` 会在每次 `dev`/`build`/`tauri` 前自动把它同步到 `tauri.conf.json`、`Cargo.toml` 与前端 `src/version.ts`，安装包名随之切换（详见[版本号管理](#版本号管理)）。安装脚本在 `src-tauri/windows/inno/zetla.iss`。卸载时会读取 `%LOCALAPPDATA%\Zetla\tex-install.txt` 与 `<texdir>\.zetla-tex`，询问是否同时删除 Zetla 代装的 TeX Live（默认保留，静默卸载一律保留）。

> NSIS 配置仍保留在 `tauri.conf.json` / `windows/nsis-hooks.nsh` 作为备用，但正式发布不再使用。

### 版本号管理

版本号只需维护一处：**`package.json` 的 `version` 字段**。

```powershell
# 方式一：一条命令改版本并全量同步（推荐）
node scripts/sync-version.mjs 0.2.1

# 方式二：先手改 package.json 的 version，再同步
npm run version:sync
```

`npm run dev` / `build` / `tauri` 每次都会自动前置同步，日常开发无感知。同步落点如下，**请勿手改**：

| 落点 | 用途 |
| --- | --- |
| `src-tauri/tauri.conf.json` | Tauri 应用版本：关于页显示、安装包文件名 |
| `src-tauri/Cargo.toml`、`src-tauri/Cargo.lock` | Rust crate 版本 |
| `package-lock.json` | npm 锁文件根版本 |
| `src/version.ts` | 前端常量 `APP_VERSION`（生成文件） |

## 目录结构

```text
Zetla/
├─ src/                 # React 前端：项目管理、编辑器、预览、引用、公式、表格、模板等
├─ src-tauri/           # Rust/Tauri 后端：编译、文件、配置、更新、安装器等
│  ├─ src/commands/     # Tauri commands
│  ├─ templates/        # 内置 6 套 LaTeX 模板（含宁夏大学学位论文）
│  └─ windows/inno/     # Inno Setup 正式包脚本
├─ scripts/             # 打包、版本同步与 Node 单元测试
├─ patches/             # 第三方依赖补丁（小地图宽度等）
├─ docs/                # 开发文档、开发计划、更新日志与界面稿
├─ public/              # 静态资源（含 logo）
└─ build/               # 打包脚本与打包文档
```
