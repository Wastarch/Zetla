# Zetla

面向 Windows 的桌面 LaTeX 工作台，把项目管理、代码编辑、编译日志和 PDF 预览放进同一个应用里。

> 当前最新版本 `0.2.6`。功能完整的桌面 LaTeX 工作台：管理项目 → 编辑 `.tex` → 一键编译 → 查看 PDF，源码与 PDF 支持双向跳转；并内置项目管理与模板库、表格编辑器、图片插入与拼图（subfigure / 合成单图）、BibTeX 参考文献、公式/符号面板（KaTeX 渲染与可视化编写、环境反向编辑）、语言档位与小地图、可自定义语法高亮、查找替换与全局搜索、实时预览、代码片段、编译日志完整换行、自动更新与亮暗双主题。编译流程由 **Tool / Recipe** 数据驱动：内置 `latexmk` 与 `engine-direct`，也可自定义工具、条件步骤、收敛重跑与失败回退，详见 [自定义编译流程指南](docs/自定义编译流程指南.md)。

## 功能

- **项目管理**：无项目时显示欢迎页与最近项目列表（置顶 / 归档 / 重命名 / 导出 zip / 删除）；`Ctrl+R` 项目切换器（切换时保留各自标签页）；项目设置可改名称、描述、类型、主文件、引擎、图片目录与资源树排除规则
- **项目与编辑**：打开 / 新建项目、新建任意后缀文件（类型快选）、项目树右键操作、多标签编辑（撤销栈独立）、自动保存、外部改动重载提示、GBK 文档不乱码
- **编辑器体验**：LaTeX / BibTeX / BibTeX 样式 / TeX 日志 / 纯文本五档高亮，未收录扩展名按纯文本渲染；状态栏语言 chip 可手动切换或恢复自动识别；右侧小地图可点击滚动、跟随主题，可在设置中关闭；LaTeX 语法高亮支持 12 个语义分组自定义、亮暗双色、主题方案与导入导出；`Ctrl+F` 查找替换（大小写 / 整词 / 正则 / 替换全部）与 `Ctrl+Shift+F` 全项目搜索
- **编辑工具栏**：标签栏下方提供格式组（加粗 / 斜体 / 下划线 / 删除线）、插入组（链接 / 图片 / 列表 / 公式 / 表格）与章节层级下拉，仅 `.tex` 文本缓冲显示
- **模板库**：6 套内置模板（英文文章 / 中文文章 / 多文件毕业论文 / 多文件幻灯片 / 简历 / 宁夏大学学位论文），支持多文件生成与动态变量表单；可另存当前项目为模板、导入目录或 zip、删除用户模板
- **代码片段**：22 条内置片段覆盖结构 / 章节 / 浮动体 / 数学 / 文本；触发词补全 + `Tab` 直展，`$SELECTION` 包裹选中文本，占位符 `Tab` 跳转；设置页可增删改、导入导出 JSON，模块可整体停用
- **一键编译 / 可编排流程**：内置两个不可删的编译流程——`latexmk`（缺 Perl 或找不到 latexmk 时自动回退）与 `engine-direct`（引擎多遍 + 条件 biber）；流程由 **Tool / Recipe** 数据驱动，可自定义工具命令与参数、占位符、按文件/日志/环境变量触发的 `when` 条件步骤、按 `.log` Rerun 提示收敛重跑（`repeat.untilStable`）、失败回退链（`fallback`），步骤直接写 XeLaTeX / pdfLaTeX / LuaLaTeX 等真实引擎名即可固定引擎；标签栏 ▶|▾ 与状态栏右键/长按可随时切换当前流程。实时日志面板停靠在编辑区下方、高度可拖拽并记忆，结构化报错可点击跳转行列；日志不再被 TeX 按 79 列硬折行，长路径与长报错可完整阅读；引擎可选（XeLaTeX / pdfLaTeX / LuaLaTeX），支持保存时自动编译、**实时预览**、编译后按自定义清单清理辅助文件
- **图片与附件**：拖拽 / 粘贴 / 菜单插入图片并自动生成 `figure` 环境；图片与 PDF 可在代码标签页只读查看，图片支持缩放与平移
- **拼图**：多图选择 / 拖入 / 粘贴自动进入拼图工作流。`subfigure` 模式生成可编辑的子图网格代码；「合成单张图片」模式在 Canvas 中实时合成，把子编号与子标题（含 LaTeX 公式）烘焙进白底 PNG 后以单图直插。侧栏统一控制行列、间距、标题、缩放、裁剪与对齐
- **表格编辑**：侧栏「表格」视图网格编辑，支持合并 / 拆分、对齐、三线表 / 全框线 / 无线、CSV / TSV 导入、Excel 粘贴与光标处表格反向回填
- **双向跳转**：编辑器 Ctrl+点击跳转 PDF 对应位置并高亮，PDF Ctrl+点击回跳源码行列（SyncTeX）；`\input` / `\include` / `\subfile` 也支持 Ctrl+点击直接打开目标 `.tex`
- **大纲导航**：侧栏自动梳理 `\input`/`\include` 链中的章节结构，层级展示、点击直达
- **参考文献（BibTeX）**：自动扫描项目内所有 `.bib` 文件并建立索引；`\cite{` 自动补全、悬浮预览、Ctrl+点击跳转条目、`.bib` 专属高亮、重复 key / 缺失引用校验；侧栏「引用」视图支持按文件分组、搜索、手动刷新、导入 `.bib`、条目预览与反向引用
- **公式与符号**：侧栏「公式」视图整合符号库、矩阵入口、公式模板、编写区与 KaTeX 预览——
  - **快捷工具**：10 个分类、354 个符号，按中英双语二级子类分区；符号以 KaTeX 渲染并视口懒加载，长名称图标单独设定宽度
  - **矩阵**：数组矩阵提供无括号 / 圆括号 / 方括号 / 行列式 / 分段函数 5 种入口，点击图标就地设置 1–10 行/列（`cases` 固定 2 列），带实时预览
  - **公式模板**：136 条内置公式、10 个分类；条目两行式展示，支持逐条高度参数，长公式不会挤压
  - 单击写入编写区，右键可直接插入编辑器 / 写入编写区 / 复制 LaTeX；顶部齿轮切换行内或编号；编写区底部提供「插入编辑器 / 复制 LaTeX」，`Ctrl+Enter` 快速提交
  - 编写区支持**源码 / 可视化**：源码模式上源码、下预览；可视化模式点击 `\Box` 或按 `Tab` 切换槽位直接输入；拖拽分割线调整高度，字号 10–50px，`Ctrl+滚轮` 缩放
  - **环境反向编辑**：公式 / 表格环境开头常驻 `✎` 徽标，点击载入对应面板；「更新」前校验源码指纹，原地替换
- **PDF 预览**：基于 PDF.js，支持缩放、翻页、页内查找、缩略图与目录侧栏，可与编辑区拖拽分栏；图片 / PDF 也可在代码标签页以只读方式打开，右侧预览仍随编译刷新
- **自动更新**：启动自动检测新版本（Gitee / GitHub 双源回退，Rust 侧请求避免 WebView CORS），发现新版本时帮助菜单显示红点并在「关于 Zetla」提供更新；可一键下载安装包并启动安装向导（安装包未做代码签名，若被拦截点「仍要运行」即可）
- **安装体验**：安装包自动检测 WebView2 Runtime，缺失时联网下载并静默安装（不增加安装包体积）；正式版屏蔽 WebView2 原生右键菜单，避免干扰自绘菜单
- **环境引导**：启动自动检测 TeX；未安装可自动下载安装 TeX Live（基础/完整方案），也支持接管已有安装
- **桌面体验**：自定义标题栏（logo + 菜单 / 拖拽区 / 最小化·最大化·关闭，双击最大化、边缘拖拽缩放）、亮 / 暗双主题（可跟随系统）、窗口大小与位置记忆、主窗口最小尺寸 1024×640、布局记忆（含日志面板高度）、启动恢复上次项目（连同上次打开的标签页）、菜单栏与状态栏；应用外壳禁选文字，编辑器和 PDF 正文仍可选中复制

## 安装

1. 到 [Releases](https://github.com/Wastarch/Zetla/releases/latest) 下载 `Zetla_0.2.6_x64-setup.exe`。
2. 运行安装包。当前版本**未签名**，Windows SmartScreen 提示时选择「更多信息 → 仍要运行」。
3. 安装模式可以为「仅当前用户」，无需管理员权限。也可以为所有用户安装。
4. 安装包会自动检测 WebView2 Runtime：已安装则跳过；缺失时尝试联网下载并静默安装（失败会提示手动安装地址）。
5. 卸载时若检测到 **Zetla 代装的 TeX Live**，会询问是否一并删除；默认保留，TeX 可继续被其他软件使用。
6. 从 `0.2.5` 及更早版本升级可直接覆盖安装，配置、偏好、最近项目与上次项目都会保留；自定义代码片段、语法高亮配色与自定义公式不受影响。

系统要求：

- **Windows 10/11**（当前主要开发与验收平台）
- **WebView2 Runtime**（Windows 10/11 通常已内置；缺失时安装包会尝试联网自动安装，也可手动安装）
- **TeX Live**：可选。不装也能启动，首次进入时可在应用内安装（见下一节）

> 国内网络下应用会自动尝试清华 TUNA、阿里云等镜像下载 TeX Live 安装器。

### 首次启动：准备 TeX 环境

Zetla 每次启动都会检测 TeX，顺序为：Zetla 独立目录 → 系统 `PATH` → 常见安装位置。

- **已装 TeX Live / MiKTeX**：检测到即可直接编译，状态栏会显示引擎信息。
- **未装 TeX**：自动弹出引导面板，可选：
  - **自动安装 TeX Live**：进入向导后选择方案与目录
    - *基础方案*：约 1.5 GB，含 XeLaTeX 与中文支持（ctex / fandol），适合大多数文档，后续可用 `tlmgr` 补包
    - *完整方案*：约 5 GB，包含全部宏包与文档
    - 默认安装到 `%LOCALAPPDATA%\Zetla\tex\texlive`，也可选其他盘符；**只写入 Zetla 独立目录，不修改系统 PATH**
    - 安装中可随时取消，取消后会清理本次新建的目录
  - **接管已有安装**：点「指定/接管已有安装…」，选择 TeX Live 根目录、`bin` 或 `bin\windows` 均可
  - **手动安装**：按面板内的官网指引自行安装后，回到应用重新检测
- 之后随时可通过菜单「帮助 → TeX 环境检测…」或「偏好设置 → 编译设置 → 检测 / 引导…」重新打开该面板。

### 新建或打开项目

- 启动后如果没有打开项目，编辑区会显示**欢迎页**：可「从模板新建」「打开项目文件夹…」，或直接从最近项目列表打开。
- **新建项目**：`Ctrl+Shift+N`（或菜单「文件 → 新建项目…」/ 欢迎页「从模板新建」）
  1. 「从模板新建」直接进入**模板库**：左侧分类、中间列表、右侧详情；选中模板后点「用此模板新建」
  2. 内置模板共 6 套：`article`（英文文章）、`ctex-cn`（中文文章）、`thesis-cn`（多文件毕业论文）、`beamer-cn`（多文件幻灯片）、`resume-cn`（中文简历）、`nxuthesis`（宁夏大学学位论文）
  3. 向导顶部显示当前模板，可点「← 返回模板库」更换；按模板变量填写标题、作者等信息，变量表单支持分组、必填、下拉、日期、开关与多选（宽屏两列）
  4. 选择生成位置 → 生成 `main.tex` 并写入 `.ltex/config.json`（记录主文件与引擎）；多文件模板会同时创建章节 / 分节目录
  5. 创建完成后自动打开到编辑器
- **打开已有项目**：`Ctrl+Shift+O`，选择项目文件夹。
  - 主文件判定顺序：`.ltex/config.json` 的 `mainFile` → 根目录 `main.tex` → 含 `\documentclass` 的最浅 `.tex` → 首个 `.tex`
  - 项目树中主文件带 `main` 标记
- **切换项目**：`Ctrl+R` 打开项目切换器，输入过滤、`↑↓` 选择、`Enter` 打开；切换时各项目的标签页会保留到本次运行结束。

### 项目管理

- **欢迎页与最近项目**
  - 最近项目以列表展示名称、位置、最近打开时间与操作按钮；点「打开」或双击行即可进入项目。
  - **置顶**：点击 ★ 把常用项目固定在列表顶部；再次点击取消置顶。
  - **归档**：在「⋯」菜单选择「归档」，项目移入「已归档」分组，不移动或删除目录；可随时取消归档。
  - **「⋯」菜单**：重命名项目、导出为 zip、归档 / 取消归档、删除项目。
- **项目切换器**（`Ctrl+R`，或「文件 → 切换项目…」）
  - 列出最近项目（置顶优先），输入关键字过滤；`↑↓` 选择、`Enter` 打开、`Esc` 关闭。
  - 末项「打开其他文件夹…」可直接选择新目录。
  - 切走时记住当前项目的标签页与活动标签，切回时按项目树过滤后恢复；该缓存仅在本次运行内有效。
- **项目设置**（菜单「设置 → 项目设置…」）
  - **常规**：项目名（默认取目录名，用于欢迎页与最近项目）、描述、类型（论文 / 学位论文 / 幻灯片 / 简历 / 自定义）。
  - **构建**：主文件（项目内 `.tex` 下拉，可自动识别）、编译引擎；输出目录当前固定为主文件同目录，界面置灰。
  - **显示**：图片目录（相对项目根，默认 `figure`）、排除规则（每行一个 glob，仅影响资源管理器树的显示）。
  - 保存后写入 `.ltex/config.json`，资源树立即刷新（引擎标签、主文件标记、排除项隐藏），欢迎页项目名同步更新。
- **项目生命周期**
  - **重命名**：重命名项目文件夹，并同步最近项目名称。
  - **删除**：删除整个项目文件夹，**不可撤销、不进回收站**，操作前会二次确认。
  - **导出为 zip**：打包项目源码与 PDF，排除辅助文件、`node_modules`、`target`、`dist` 与 `.git`。
  - 打开中的项目由后端保护，不能重命名 / 删除；仍可安全导出。
- **模板库**（菜单「模板 → 模板库」，或欢迎页「从模板新建」直接进入）
  - 左侧按分类浏览内置模板与用户模板，右侧搜索与详情；详情展示引擎、主文件、变量、文件数、版本与标签。
  - 内置 6 套模板；「宁夏大学学位论文」含 23 项变量（中英文标题、培养单位、导师、学号、分类号、密级等）与出稿格式、盲审封面、书脊、数学字体等外观选项。
  - **另存当前项目为模板**：菜单「模板 → 另存当前项目为模板…」，保存到 `%APPDATA%\Zetla\templates\`。
  - **导入模板**：支持本地模板目录或 zip（会校验 manifest，拒绝覆盖内置模板）。
  - **删除模板**：仅用户模板可删除，内置模板受保护。
  - 在模板库中可直接「用此模板新建」，向导会自动预选该模板。

### 编辑文档

- **多标签**：点击项目树文件即可打开；`Ctrl+W` 关闭；未保存的标签显示脏点 `●` 而不是关闭按钮
- **保存**：`Ctrl+S` 保存当前文件，`Ctrl+Shift+S` 全部保存；打开文件用 `Ctrl+O`
- **自动保存**：默认开启，每 30 秒写回未保存修改；编译期间默认暂停自动保存（可在设置中调整）
- **编码与换行**：自动识别 UTF-8 / GBK，状态栏只读展示编码与换行符；保存时保持原编码与 EOL，老文档不会乱码或改写换行
- **查找**：`Ctrl+F` 打开右上角浮动面板，全部命中高亮并显示 `n/N`；`↑↓` / `F3` / `Shift+F3` 导航，`Esc` 关闭；`Ctrl+H` 直接展开替换
- **替换**：支持 `Aa` 大小写、整词、`.*` 正则；「替换」当前项或「全部替换」，可勾选保留大小写
- **全局搜索**：`Ctrl+Shift+F` 或活动栏「搜索」，并发扫描项目内文本文件，按文件分组展示命中行；点击跳转并唤起单文件高亮，跨文件替换前会确认受影响文件数
- **注释**：`Ctrl+/` 切换行注释；撤销 / 重做 `Ctrl+Z` / `Ctrl+Y`
- **字号**：`Ctrl+滚轮` 缩放编辑器字体，或到「偏好设置 → 编辑器」调整字体与字号
- **快捷工具栏**：标签栏下方提供格式组（加粗 / 斜体 / 下划线 / 删除线）、插入组（链接 / 图片 / 列表 / 公式 / 表格）与章节层级下拉（`chapter` 至 `subparagraph`）；仅 `.tex` 文本缓冲显示
- **项目树**：右键可新建文件/文件夹、重命名、删除、从模板新建；`Ctrl+C` / `Ctrl+X` / `Ctrl+V` 在树内复制、剪切、粘贴（粘贴目标为选中目录、选中文件的父目录或项目根）
- **新建文件**：项目树右键或根行按钮「新建文件」支持任意后缀——
  - 类型快选提供 `.tex` / `.bib` / `.cls` / `.sty` / `.md` / `.txt` / 无后缀，默认 `.tex`，本次运行内会记住上次选择
  - 文件名自带后缀时以输入为准，否则自动拼接所选类型；对话框下方实时预览最终文件名
  - 文本类文件创建后自动打开标签；图片 / PDF 只创建文件，不自动打开
- **语言与高亮**：状态栏「文档语言」chip 默认按扩展名识别 LaTeX / BibTeX / BibTeX 样式 / TeX 日志 / 纯文本；未收录扩展名按纯文本渲染。点击 chip 可手动切换档位，或选择「恢复自动识别」；手动覆盖仅在本次运行内有效
- **小地图**：编辑器右侧显示语法着色的缩略图，点击可按比例滚动；默认开启，可在「偏好设置 → 编辑器 → 显示小地图」关闭。图片 / PDF 标签不显示小地图
- **跨文件跳转**：在 `\input{...}` / `\include{...}` / `\subfile{...}` 上 `Ctrl+点击` 打开目标 `.tex`；路径按「当前文件目录 → 主文件目录 → 项目根」依次解析，缺省自动补 `.tex`。按住 `Ctrl` 时显示链接态与「Ctrl+点击可跳转」提示，目标不存在时会提示且不会创建文件
- **诊断去噪**：被 `\input` 引入的章节片段不再误报「缺少 document 环境 / `\cite` 但没有参考文献 / 缺少引用 / 缺少宏包」；片段内的环境配对、括号闭合、重复 label 与数学模式仍会提示
- **自定义语法高亮**：「偏好设置 → 外观与保存 → LaTeX 语法高亮 → 自定义配色…」可调整 12 个语义分组的亮 / 暗颜色，套用 Zetla 默认 / GitHub / Dracula / Solarized / Nord 主题方案，并导出 / 导入配色 JSON；改动即时预览，点「取消」整体回滚
- **外部改动**：已打开文件被其他编辑器修改时，编辑器顶部会出现「重新加载 / 忽略」提示条；Zetla 自身保存后的回显不会误报

### 代码片段

内置 22 条常用 LaTeX 片段，覆盖结构（`beg` / `itemize` / `enumerate` / `center`）、章节（`sec` / `ssec` / `sssec` / `para`）、浮动体（`fig` / `tab` / `eq` / `algn` / `cases` / `pmat`）、数学（`frac` / `sqrt` / `sum` / `int`）与文本（`fn` / `text` / `bf` / `it`）。

- **补全与展开**：在 `.tex` 中输入触发词会出现在补全弹窗；触发词精确命中时按 `Tab` 直接展开，未命中仍按原行为缩进。也可从菜单「插入代码片段…」唤起补全（`Ctrl+Shift+Space` 被中文输入法占用时的备用入口）。
- **选区包裹**：先选中文本再展开 `bf` / `it` 等包裹型片段，会生成 `\textbf{选中内容}`；无选区时插入占位符。
- **占位符跳转**：片段模板支持 `${1:占位}`，展开后用 `Tab` / `Shift+Tab` 逐槽填写。
- **管理**：设置「代码片段」页左侧可搜索并按「内置（只读）/ 自定义」分组，右侧编辑触发词、描述、分类与模板；保存后立即生效，自定义片段上限 500 条。
  - 校验空触发词、反斜杠 / 空白、与内置冲突及重复触发词。
  - 支持导入 / 导出 JSON 片段包，导入时可选择覆盖或追加合并。
  - 自定义片段保存在用户目录的 `snippets.json`，与项目无关。
- **模块开关**：可在「偏好设置 → 模块」停用代码片段；停用后补全与 `Tab` 直展短路，但不重建编辑器扩展，不会丢失当前占位符会话。

### 参考文献与引用

Zetla 会自动扫描项目内所有 `.bib` 文件，并把条目与引用信息集中到侧栏「引用」视图。

- **引用视图**：点击活动栏「引用」或按 `Ctrl+B 4`，也可从「视图」菜单切换。
  - **校验汇总条**：显示 `⚠ 重复 key N 处` / `❌ 缺失引用 M 处`，点击直达首个问题；全部正常时显示「✓ 引用无误」。
  - **条目列表**：按 `.bib` 文件分组、可折叠，展示 key、作者（年份）与 `@type`；顶部可按 key / 作者 / 标题搜索。重复 key 带标记，已引用条目显示被引次数。
  - **左键预览**：打开浮窗查看作者年份、标题、期刊 / 会议 / 出版社 / DOI / URL 等字段与来源文件行号。
  - **右键菜单**：在光标处插入 `\cite{key}`、跳到 `.bib` 条目、查看反向引用。
  - **反向引用**：列出该文献在项目 `.tex` / `.ltx` 中的引用位置，点击跳回源码行。
  - **导入参考文献…**：选择 Zotero 等工具导出的 `.bib`，复制到项目根目录（同名不覆盖）后自动纳入索引。
  - **手动刷新**：点「↻ 刷新」重新扫描项目目录并重建引用索引，可发现外部新增 / 改名的 `.bib` 与 `.tex`；刷新期间按钮显示「刷新中…」，完成后提示条目数。
- **输入引用**：在 `.tex` 中输入 `\cite{` 会自动补全文献 key（附带作者年份与标题）；悬停在已有 `\cite{key}` 上可预览条目信息。
- **Ctrl+点击跳转**：在 `\cite{key}` 上 `Ctrl+点击` 打开对应 `.bib` 条目；按住 `Ctrl` 时引用命令显示链接态并提示可点击。
- **`.bib` 高亮**：条目类型、引用 key、字段名、字段值、注释分色，亮 / 暗主题各一套。
- **校验**：跨 `.bib` 的重复 key、`.tex` 中缺失的引用会以波浪线和行号槽标记；支持 `\cite` / `\citep` / `\citet` / `\citeauthor` / `\nocite` 等，`\nocite{*}` 不误报。
- **PDF 引用跳转**：内置 `article` / `ctex-cn` 模板已启用 `hyperref`，由模板新建的项目编译后，PDF 中的 `[1]`、`\ref` 与 URL 可直接点击。

> 引用索引会在编辑、保存或外部修改 `.bib` 后自动更新（防抖 300ms）。Zotero 目前仅支持「导出 `.bib` 后导入」，未来计划会做 API 双向同步。

### 公式与符号

侧栏「公式」（`Ctrl+B 3`）把符号、模板、编写区和预览放在同一个视图中。

- **快捷工具**：10 个分类、354 个符号，按中英双语二级子类分区（二元运算符、希腊字母大小写、积分 / 双重积分 / 三重积分 / 曲线积分等）；符号以 KaTeX 渲染，滚动到视口附近才加载。
- **矩阵**：数组矩阵提供无括号 / 圆括号 / 方括号 / 行列式 / 分段函数 5 种入口；点击图标就地展开浮层，可切换环境、设置 1–10 行/列，`cases` 固定 2 列，并实时预览生成结果。
- **公式模板**：136 条内置公式、10 个分类（代数、几何、不等式、微积分、矩阵、三角公式、统计与概率、数列、物理、化学），支持最近使用与自定义增删改；条目为两行式布局，内置公式可带独立高度参数 `h`，长公式的预览字号随高度放大。
- **编写与插入**：单击符号或模板写入编写区；右键菜单可直接插入编辑器、写入编写区或复制 LaTeX。顶部齿轮切换行内 / 编号插入；编写区底部提供「插入编辑器 / 复制 LaTeX」，`Ctrl+Enter` 也可提交。
- **源码与可视化**：
  - 源码模式为上下分栏：上方 LaTeX 输入框、下方 KaTeX 实时预览；点击预览中的空槽只定位源码光标。
  - 可视化模式下渲染结果成为主编辑面：点击 `\Box` 选中槽位（首键即替换），`Tab` 在槽位间循环，活动槽高亮。
  - 两种模式共用同一份 LaTeX 源码，切换不会丢失内容。
- **布局与缩放**：符号面板与编写区之间的分割线可拖拽，编写区默认 / 最小高度 320px；源码框与预览按 1:1 平分剩余高度，二级工具栏固定 70px。编写区字号范围 10–50px（默认 20px），可用工具栏 `− / +` 或 `Ctrl+滚轮` 调整。
- **环境反向编辑**：
  - 编辑器里已有公式 / 表格环境的开头定界符右侧会显示 `✎` 徽标（如 `\begin{equation}✎`、`$✎`、`\begin{table}✎`）；点击即把该环境载入对应面板并切换到「公式」或「表格」侧栏。
  - 嵌套环境各自显示标记，内层优先；表格标记锚定在外层 `\begin{table}`，可同时编辑表格与单元格内的公式。
  - 修改后点「更新」原地写回源码。写回前会校验源码指纹：环境被手动改过则拒绝覆盖；内容未改则提示「公式未修改」。
  - 来自环境的公式会沿用原环境名重包裹，保留 `&` / `\\` 对齐；行内 `$...$` / `$$...$$` 按当前插入偏好重新包裹。更新成功后区间自动重绑，可连续微调。

### 图片与附件

- **插入图片**（三种方式）：
  - 把图片文件**拖进编辑器**
  - 在编辑器中**粘贴截图**（剪贴板含图片）
  - 菜单「插入 → 图片…」选择一个或多个文件
- 图片默认保存到 `项目根/figure/`，可在「设置 → 项目设置 → 显示 → 图片目录」改为其他相对路径；同名文件自动去重为 `base-1.ext`。
- 插入时按当前 `.tex` 所在目录计算相对路径，并自动生成完整 `figure` 环境（`\centering` → `\includegraphics` → `\caption` → `\label`），光标落在空 `\caption{}` 内，直接输入标题即可。
- 拖拽悬停时编辑器显示高亮边框；未打开项目或当前不是 `.tex` 标签时会提示，不会留下半成品源码。
- **图片 / PDF 标签页**：
  - 在项目树双击图片或 PDF，或使用「文件 → 打开图片 / PDF…」，会在代码区以只读标签打开。
  - 图片查看器支持 `Ctrl+滚轮` 缩放（0.1–8，以指针为锚点）与拖拽平移，底部显示文件名、尺寸与缩放比例。
  - PDF 标签页复用 PDF 渲染页，是打开时的快照，不随重新编译刷新；右侧 PDF 预览仍会随编译更新。
  - 非文本标签下撤销 / 重做 / 注释 / 保存 / 插入图片等编辑动作置灰；关闭标签不会提示未保存。
- 编译产物 `main.pdf` 仍会在打开项目时自动加载到右侧预览；「文件 → 打开 PDF…」已移除，统一从图片 / PDF 入口或项目树打开。

### 拼图

拼图把多张图片排成论文插图，提供两种平级模式：`subfigure`（生成可编辑的子图代码）与「合成单张图片」（合成一张 PNG 后直插）。侧栏只负责控制，排版结果在中心 Tab 预览。

- **进入方式**：
  - 活动栏「拼图」图标、`Ctrl+B 6`，或「视图」菜单。
  - 拖入 / 粘贴 / 菜单插入**多张**图片时自动进入：侧栏切到「拼图」，并打开中心「拼图预览」Tab。单图仍走原来的零步骤直插 `figure` 环境。
- **两种模式**：
  - `subfigure`：中心 Tab 显示 DOM 近似预览，生成带 `subfigure` 的网格代码，子标题保留为 LaTeX，可继续编辑与重排。
  - 合成单张图片：中心 Tab 显示 Canvas 实时合成预览，把子图合并为一张白底 PNG 并直插，子编号与子标题烘焙为像素。
  - 两种模式共用同一份布局、子图列表、单格参数与「图片标题」。
- **布局**：
  - 自动网格按图片数计算 `cols = ceil(√n)`、`rows = ceil(n / cols)`，导入 4 张即为 2×2；也可手动改行列。
  - 子图列表行优先编号 a / b / c…，显示缩略图、文件名与自动 `\label`；单击选中，再次点击取消选择（回到整图设置）。
  - 拖拽列表项可调整顺序，编号与 label 会跟着重排；每行右侧 `×` 删除子图。
  - 未选中子图时可调列间距与行间距（占列宽比例）；列间按 `\hfill` 语义均分剩余空间，行间生成 `\vspace{…\textwidth}`。
- **单格编辑**：
  - 子标题支持 `$...$`，`subfigure` 模式用 KaTeX 预览；合成模式用 MathJax 渲染后画进 PNG。留空时生成空 `\caption{}` 或只保留 `(a)` 编号。
  - 缩放 0.1–3；同一行按各格缩放比例分配宽度，并预留间距与 2% 安全余量，保证整行不超 `\textwidth`。
  - 对齐为**行级**属性（顶 / 中 / 底）：同一行混用不同对齐会让子图上下错位，因此整行取首格设置；`subfigure` 顶对齐生成 `\raisebox{-\height}` 以得到真正的顶边对齐，合成模式对齐「图片 + 子标题」单元块。
  - 裁剪为归一化四边值（左 / 下 / 右 / 上，0–1）：`subfigure` 生成 `trim=…, clip`，合成模式换算为 `drawImage` 源矩形；预览与产物使用同一套换算。
- **图片标题**：导入图片后侧栏显示「图片标题」，即外层 `figure` 的 `\caption{}`，两种模式共用；合成模式下同时作为 PNG 文件名。
- **`subfigure` 预览与生成**：
  - 中心 Tab 用 DOM 近似排版，与代码生成共用同一套宽度算法；裁剪、行级对齐、子标题与编号都会反映。PDF 子图由 pdf.js 渲染首页，图片用原始路径或内存对象 URL 直接预览。
  - 点「生成 subfigure 代码」时，才把真正进入代码的图片拷到图片目录（默认 `项目根/figure/`，可在项目设置修改），未使用的选图不会留下垃圾文件。
  - 生成前会检查图片目录中的同名文件；存在冲突时弹窗逐张选择「用 figure 中现有的」或「重命名复制新文件」，也可「全部用现有 / 全部重命名」。
  - 代码插入导入时绑定的目标 `.tex`（即使当前活动的是拼图预览 Tab），随后后台编译自检；编译失败会提示并在编辑器中选中刚插入的代码块，不阻塞继续编辑。缺少 `subcaption` 时侧栏横幅可一键加入导言区。
- **合成单张图片**：
  - 布局与 `subfigure` 共用宽度预算、行级对齐、裁剪与间距；行内剩余空间按 `\hfill` 语义均分，输出**白底 PNG**，固定 **1600px** 宽。
  - 子编号 `(a)` 与子标题会**烘焙进图片**：编号粗体、正文常规、居中于子图下方并自动换行；子标题里的 LaTeX 公式经 MathJax 渲染为自包含 SVG 后画入，导出 PNG 同样带公式。
  - 点「合成单图并插入」：合成 → PNG 落盘 → 生成单个 `figure` 环境（`\includegraphics[width=\linewidth]` + `\caption` + `\label`）直插目标 `.tex`，随后后台编译自检。
  - **命名**：图片标题非空 → `<标题>.png`（清洗 `/ \ : * ? " < > |` 等非法字符，保留中文）；为空 → `fig-<首个图片 slug>-composite.png`。同名文件**直接覆盖**，不弹冲突框。
  - **首次轻确认**：首次合成前提示子编号 / 子标题将变为像素、不再是可独立编辑的 `\subcaption`；可勾选「不再提示」，取消则不合成、不落盘。
  - 部分图片加载失败时留白继续合成；全部失败则提示且不落盘、不插入。总图题不烘焙，仍由 LaTeX `\caption` 生成；PDF 子图只取首页。

### 表格编辑

- **打开方式**：活动栏「表格」图标、`Ctrl+B 5`、或「视图」菜单；表格是模块化侧栏视图，可在「偏好设置 → 模块」停用。
- **网格编辑**：
  - 回车或失焦提交单元格；`Tab` / `Shift+Tab` 左右移，`Enter` / `Shift+Enter` 上下移，`Ctrl+方向键` 跨格，`Esc` 退出编辑。
  - 拖拽或 `Shift+点击` 选择矩形区域；`Ctrl+C` 复制为 TSV，`Ctrl+V` 以当前格为左上角铺入，可直接从 Excel 粘贴。
  - 右键行号 / 列号可插入或删除行 / 列；选中矩形可合并 / 拆分；列级对齐支持 `l` / `c` / `r`。
  - 可视化网格在亮 / 暗主题下都有清晰框线，单元格边界一目了然。
- **样式与输出**：
  - 线型三选：三线表（booktabs，默认）、全框线（grid）、无线（plain）。
  - 宽度可选自然宽或撑满页宽（tabularx + `X` 列）。
  - 可填写表题与标签；标签留空时按表题自动推导 `tab:<slug>`。
  - 单元格转义支持智能 / 全转义 / 不转义；展开「生成代码」可预览最终 LaTeX。
- **导入与反向编辑**：
  - 「导入 CSV」读取 CSV / TSV / txt（`.xlsx` 请先另存为 CSV）。
  - 「载入表格」会把光标处已有 `tabular` 回填到网格；「更新表格」仅在源码指纹未变时原地替换，手改过源码会拒绝覆盖。
  - 源码中已有表格环境的开头会显示 `✎` 徽标，点击即可把该表格载入网格；单元格内的公式也各自带 `✎`，可直接转入公式面板编辑。
  - 缺少 `booktabs` / `multirow` / `tabularx` 等宏包时给出提示，可一键「加入导言区」。
- **插入**：点「插入到编辑器」把表格代码写到当前 `.tex` 光标处，并把光标定位到 `\caption{}`；表格上限 100 行 × 20 列。

### 编译与排错

- **编译**：`Ctrl+B`，或点击标签栏右上角 **▶** / 状态栏的编译按钮；状态栏显示「编译中…」与进度条
  - 编译前会自动保存已修改文档（可在设置中关闭）
  - 编译中点击编译按钮即**终止编译**
  - **▶** 右侧的 **▾** 展开流程菜单切换当前流程；状态栏编译按钮**右键 / 长按约 0.5 秒**打开同一菜单（见[自定义编译流程](#自定义编译流程)）
- **保存时自动编译**：「偏好设置 → 编译设置 → 保存时自动编译」开启后，手动保存 `.tex`（`Ctrl+S` / 全部保存）会触发编译；400ms 内的多次保存合并为一次，定时自动保存不会触发
- **实时预览**：「偏好设置 → 编译设置 → 实时预览」开启后（默认关闭），停止输入即防抖自动编译；延迟可选 500 / 600 / 800 / 1200 ms（默认 600 ms）
  - 实时编译静默执行：不展开日志面板、不弹 toast、编译前静默保存，不打断继续输入
  - 重叠触发按 **latest-wins** 顶替：旧任务被终止并静默丢弃，只保留最新一次结果
  - 编译成功后 PDF 自动滚动到编译前光标所在行（静默锚定）；手动编译会清除锚定
  - 与「编译后清理」互斥：实时预览期间保留 `.fdb_latexmk` / `.fls` / `.synctex.gz`，兼顾增量编译与跳转
- **清理辅助文件**：菜单「构建 → 清理辅助文件」会递归删除 `.aux`、`.log`、`.bbl`、`.toc`、`.out`、`.synctex.gz` 等辅助文件，源文件与 PDF 不受影响，完成后提示删除数量并刷新资源树
- **编译后自动清理**：「偏好设置 → 编译设置 → 编译完成后清理辅助文件」开启后，仅在编译成功时按清单清理；失败或取消不清理，删除数量为 0 时静默
  - **自定义清理清单**：默认 14 项后缀，以 chip 展示，可逐项移除；输入后缀回车添加（自动补点、转小写、去重），也可「恢复默认」
  - 手动「清理辅助文件」与编译后清理共用同一份清单；清单为空时使用内置默认值
  - `.tex` / `.bib` / `.cls` / `.sty` / `.pdf` 等受保护后缀永不删除，即使误填进清单也会被后端拦截
- **流水线（默认）**：内置 `latexmk` 流程按生效引擎自动多轮；找不到 `latexmk` 或没有可用 Perl 时自动回退到内置 `engine-direct` 流程（引擎 → biber（存在 `.bcf` 才跑）→ 引擎 → 引擎）。流程可以替换或自定义，见[自定义编译流程](#自定义编译流程)
- **日志面板**：停靠在编辑 / 预览区下方（不横跨侧栏），开始编译时自动展开，分「全部 / 错误 / 警告」三个页签
  - 「全部」实时输出编译器原始日志
  - 0.2.3 起编译进程关闭了 TeX 默认的 79 列硬折行，长路径与长报错保持完整一行；面板按当前宽度软换行，拖宽即可看到更多
  - 「错误 / 警告」为解析后的结构化列表，点击条目直接跳到对应文件与行列
  - 拖拽面板顶边可调整高度（120–560px，编辑区至少保留 180px），高度随布局记忆保存
  - 需要原始 `.log` 文件时可用菜单「帮助 → 查看日志文件」；「视图 → 显示 / 隐藏日志面板」或状态栏按钮可随时开合
- **引擎说明**：可在「偏好设置 → 编译设置」选择 XeLaTeX / pdfLaTeX / LuaLaTeX，默认跟随项目 `.ltex/config.json`；状态栏引擎标签为只读展示。流程里写具体引擎名会固定使用该引擎，不受此处设置影响

### 自定义编译流程

编译流程由两层数据描述：**Tool（工具）** 是一条可执行命令（命令 + 参数 + 环境变量），**Recipe（流程）** 是有序的工具步骤（可带条件、自动重跑、失败回退）。两个内置流程 `latexmk` / `engine-direct` 不可删不可改，其余流程与工具都在「偏好设置 → 编译设置 → 编译流程（Tool / Recipe）」里增删改。

| 想做什么 | 在哪操作 |
| --- | --- |
| 临时换一个流程编译 | 标签栏 **▾**，或状态栏编译按钮右键 / 长按 → 选中即切换**当前流程**并立即编译；之后 ▶ / `Ctrl+B` / 保存即编译 / 实时预览都跟随它 |
| 恢复默认 | 同一个菜单首项「按默认流程编译」 |
| 新建 / 编辑流程 | `Ctrl+,` → 编译设置 →「+ 新建流程」→「编辑步骤」增删工具、上下移动 →「设为默认」→ **保存设置** |
| 自定义命令、条件、完整字段 | 设置页「高级：JSON 编辑（完整字段）」，支持 `%DOC%` / `%DOCFILE%` / `%DIR%` / `%OUTDIR%` 等占位符、`when` 条件、`repeat.untilStable`、`fallback` |
| 跳到编排面板 | 流程菜单末项「管理编译流程…」 |

步骤直接写**真实引擎名** `xelatex` / `pdflatex` / `lualatex` 即固定该引擎；`latexmk` / `biber` / `bibtex` 是辅助工具，`biber` / `bibtex` 未安装时会跳过该步。老配置里的 `latex` 别名仍由后端兼容为「跟随当前引擎」。最小示例（粘贴到设置页的 JSON 编辑器即可）：

```json
{
  "tools": [],
  "recipes": [
    {
      "name": "my-once",
      "tools": ["pdflatex"],
      "repeat": null,
      "fallback": "latexmk"
    }
  ],
  "defaultRecipe": "my-once"
}
```

工具、流程与默认流程只保存在**全局** `%APPDATA%\Zetla\config.json` 的 `build` 段，**不写入项目的 `.ltex/config.json`**；菜单选择的「当前流程」存在本地 `localStorage`，不进配置文件。完整字段说明、占位符表、条件写法、多份可复制配方与排错清单见 **[自定义编译流程指南](docs/自定义编译流程指南.md)**。

### 查看 PDF

- 编译成功后自动加载项目主文件对应的 PDF；如需查看其他 PDF 或图片，可在项目树双击，或用菜单「文件 → 打开图片 / PDF…」在代码标签页打开
- **缩放**：默认「适合宽度」，可选 100% / 125% / 150%，或 `Ctrl+滚轮` 连续缩放（以指针位置为锚点）
- **翻页**：工具栏页码输入与上下翻页；连续滚动时自动同步当前页
- **页内查找**：指针在预览区内时按 `Ctrl+F`，支持命中高亮与上/下一个
- **侧栏**：缩略图与目录（大纲）切换，点击即跳页
- **分栏**：拖动编辑区与预览之间的分隔条调整比例，布局会被记住

## 常见问题

**安装时被 SmartScreen 拦截？**
安装包尚未做代码签名，属正常现象。点「更多信息 → 仍要运行」。若企业策略禁止，可自行从源码构建。

**启动后提示未检测到 TeX？**
两种方式：在引导面板里自动安装 TeX Live；或先手动安装，再用「指定/接管已有安装…」选择 TeX Live 根目录 / `bin` / `bin\windows`，最后重新检测。

**编译报错找不到 `xelatex` 或 `latexmk`？**
说明当前引擎不在检测路径中。打开「偏好设置 → 编译设置 → 检测 / 引导…」重新检测或接管安装目录；确认安装包含 XeLaTeX 与 `latexmk`（TeX Live 完整安装自带）。自定义流程里写错命令时，日志会提示「未找到命令：xxx」，把 `command` 改成 `PATH` 能找到的名字或 exe 完整路径即可。

**怎么切换编译流程？切换后会一直生效吗？**
点标签栏右上角 **▾**，或右键 / 长按状态栏编译按钮，选一个流程即可：会立即编译一次，并把它记为**当前流程**。之后 ▶、`Ctrl+B`、保存时自动编译与实时预览都跟随它，直到你换一个或选菜单首项「按默认流程编译」。当前流程存在本地 `localStorage`，不写入配置文件。

**「默认流程」和「当前流程」有什么区别？**
「默认流程」是设置页 `Ctrl+,` → 编译设置里设定的 `defaultRecipe`，写进全局配置；「当前流程」是菜单里切换的选择，优先级更高但只存本地、不写配置文件。菜单选「按默认流程编译」会清掉当前流程，回到默认流程。完整优先级见[自定义编译流程指南](docs/自定义编译流程指南.md) §3。

**想加一步 `makeglossaries`、改用 `bibtex`、或让某个流程固定用 pdfLaTeX 怎么办？**
在「偏好设置 → 编译设置 → 编译流程（Tool / Recipe）」里新建流程并编辑步骤：步骤下拉直接选 XeLaTeX / pdfLaTeX / LuaLaTeX / latexmk / biber / bibtex，选具体引擎即固定该引擎；自定义命令、参数与 `when` 条件在点开的「高级：JSON 编辑（完整字段）」里写。指南里有可直接粘贴的配方。

**自定义流程是项目级的吗？换项目会丢吗？**
不是项目级。工具、流程与默认流程只保存在全局 `%APPDATA%\Zetla\config.json`，对所有项目生效；项目 `.ltex/config.json` 仍只管主文件与引擎。换项目不会丢，需要按项目区分时可用 ▾ 菜单临时切换当前流程。

**为什么编译报错后没有走我配的「失败回退」？**
`fallback` 只处理**工具无法启动**（命令找不到、`latexmk` 缺可用 Perl、子进程启动失败），源码编译错误（命令返回非 0）会直接标记本次编译失败。想让某一步的失败不阻断流程，可给那个 Tool 设 `ignoreErrors: true`。

**老版本配置里的固定步骤（`build.steps`）还能用吗？**
能。后端会把它静默合成一个兼容流程，编译行为不变；但设置页已移除旧编辑器。想改用新流程，按[指南](docs/自定义编译流程指南.md)新建一个 Recipe 并设为默认，或直接删掉 `config.json` 里的 `steps`。

**自动安装 TeX Live 很慢 / 占空间？**
基础方案约 1.5 GB，完整方案约 5 GB，耗时取决于网络。安装器会自动尝试国内镜像；中途取消会清理本次新建目录。后续补包可用 TeX Live 自带的 `tlmgr`。

**打开 GBK 老文档会乱码吗？**
不会。读取时自动识别 UTF-8 / GBK，保存时保持原编码与原换行符。

**输入 `\cite{` 没有补全候选？**
请确认项目已打开且项目内存在 `.bib` 文件；`.bib` 保存或外部修改后索引会自动刷新。Zotero 用户可先导出 BibTeX 文件，再从「引用」视图的「导入参考文献…」加入项目。

**切换项目后，之前的标签页去哪了？**
项目切换器会在本次运行内按项目缓存标签页与活动标签，切回时恢复；重启 Zetla 后只恢复上次打开的项目及其标签页，其他项目从欢迎页进入。

**拖入图片没有反应？**
请确认已打开项目、当前是 `.tex` 标签，且文件为常见图片格式（PNG / JPG / WebP 等）。项目未打开或当前是图片 / PDF 等只读标签时会给出提示，不会插入源码。

**拖入多张图片后为什么没有直接插入源码？**
多图会进入拼图工作流：侧栏切到「拼图」并打开中心「拼图预览」Tab。确认布局后，`subfigure` 模式点「生成 subfigure 代码」、合成模式点「合成单图并插入」，才会写入目标 `.tex`；单图仍会直接插入完整的 `figure` 环境。

**选完图后 `figure/` 里为什么没有文件？**
拼图采用延迟落盘：选图只记录来源。`subfigure` 模式点「生成 subfigure 代码」时才把真正进入代码的图片复制到图片目录；合成模式点「合成单图并插入」时才写出合成后的 PNG。这样实验性选图不会污染项目；已生成的代码与图片会正常保留。

**合成图的文件名怎么定？会覆盖已有文件吗？**
优先用侧栏「图片标题」：非空时保存为 `<标题>.png`（自动清洗 `/ \ : * ? " < > |` 等非法字符，保留中文）。标题为空时保存为 `fig-<首个图片 slug>-composite.png`。同名文件会**直接覆盖**，不弹冲突框，覆盖前请确认旧图不再被其他文档引用。

**合成图的子标题能编辑吗？支持公式吗？**
子编号 `(a)` 与子标题会烘焙进 PNG，合成后不能在 LaTeX 里单独编辑或重排；需要可编辑的子标题请改用 `subfigure` 模式。子标题里的 `$...$` / `$$...$$` 会经 MathJax 渲染为自包含 SVG 后画入图片，导出 PNG 同样带公式。首次合成前会轻确认，可勾选「不再提示」记住选择。

**生成的代码提示缺少 `subcaption`？**
`subfigure` 环境需要 `subcaption` 宏包。侧栏检测到缺失时会显示横幅，点「加入导言区」即可在 `\begin{document}` 前插入 `\usepackage{subcaption}`；也可以手动添加。

**编辑器里的 `✎` 是什么？**
这是环境反向编辑标记，位于公式 / 表格环境的开头定界符右侧。点击会把该环境载入对应面板，改完点「更新」原地替换；若源码在载入后被手改过，会因指纹不一致而拒绝覆盖，此时重新点 `✎` 载入即可。

**表格能直接导入 Excel（`.xlsx`）吗？**
不能直读 `.xlsx`。请先在 Excel 中另存为 CSV，再用表格面板「导入 CSV」；也可以直接从 Excel 复制区域，在网格中 `Ctrl+V` 粘贴。

**外部编辑器改了文件，Zetla 里怎么同步？**
编辑器顶部会出现「重新加载 / 忽略」提示条；点「重新加载」读取磁盘内容，点「忽略」保留当前编辑内容。

**清理辅助文件会删掉 PDF 或源码吗？**
不会。只删除白名单内的辅助文件，`.tex/.bib/.cls/.sty` 与 PDF 等受保护后缀始终保留；自定义清单误填受保护后缀也会被后端拦截。

**编译后自动清理怎么开？会清理哪些文件？**
到「偏好设置 → 编译设置」打开「编译完成后清理辅助文件」。默认按 14 项辅助后缀清理，也可用 chip 增删自定义后缀；手动「清理辅助文件」与编译后清理共用这份清单。只有编译成功才会执行。

**新建文件只能建 `.tex` 吗？**
不是。新建文件对话框提供 `.tex` / `.bib` / `.cls` / `.sty` / `.md` / `.txt` / 无后缀快选，也可以直接在文件名里输入任意后缀；文本文件创建后自动打开，图片 / PDF 只创建不打开。

**打开 `.md`、`.json` 或没有后缀的文件为什么没有语法高亮？**
这些扩展名未收录，会按纯文本渲染。可点击状态栏「文档语言」chip 手动指定档位，或选择「恢复自动识别」；手动指定仅在本次运行内有效。

**右侧小地图怎么关掉？**
「偏好设置 → 编辑器 → 显示小地图」关闭即可。小地图仅对文本缓冲区生效，图片 / PDF 标签不会显示。

**章节文件里全是「缺少 document 环境 / 缺少参考文献」的报错，怎么关？**
不用关，0.2.1 起这些**整篇级检查只对主文件生效**。被 `\input` 引入的章节片段不再误报缺少 `\documentclass`、`\bibliography`、引用或宏包；片段内的环境配对、括号、重复 label 与数学模式仍会检查。当前还没有逐项关闭诊断的开关，遇到误报欢迎提 Issue。

**`\input{chapter/chap01}` 能像 `\cite` 一样跳转吗？**
可以。按住 `Ctrl` 点击 `\input` / `\include` / `\subfile` 的花括号内容即可打开目标 `.tex`；路径按「当前文件目录 → 主文件目录 → 项目根」解析并自动补 `.tex`。目标不在项目树内或文件不存在时只会提示，不会创建文件。

**语法高亮颜色能自己改吗？改完重启还在吗？**
能。「偏好设置 → 外观与保存 → LaTeX 语法高亮 → 自定义配色…」可调整 12 个语义分组的亮 / 暗颜色，也能一键套用 Zetla 默认 / GitHub / Dracula / Solarized / Nord。配色写入 `%APPDATA%\Zetla\config.json`，重启后保留；也可导出 JSON 备份或分享。当前仅作用于 LaTeX 档，BibTeX / `.bst` / `.log` / 纯文本仍用内置配色。

**日志面板挡住编辑区了，能调小吗？**
拖拽日志面板顶部边缘即可调整高度（120–560px，编辑区至少保留 180px），高度会被记住；也可用「视图 → 隐藏日志面板」或状态栏按钮收起。

**编译日志里的长路径、长报错为什么不再被折成好几行了？**
0.2.3 起 Zetla 会给编译进程放宽 TeX 的日志列宽限制（`max_print_line` 等），长路径与长报错保持完整一行，换行交给日志面板宽度决定；拖宽面板即可读到更多。该设置只对 Zetla 发起的编译生效，从外部终端编译生成的 `.log` 仍按 TeX 默认列宽折行。

**实时预览为什么默认关闭？会不会很卡？**
实时预览每次停顿都会整篇编译，比手动编译更吃 CPU，因此默认关闭。开启后可按项目规模把延迟调到 800–1200 ms；连续输入时只保留最新一次任务（latest-wins），旧任务会被终止，不会堆积。

**跨文件替换能撤销吗？**
不能。全局搜索的跨文件替换会直接写盘，执行前会确认并提示受影响文件数。建议替换前先提交或备份；单文件替换仍可用 `Ctrl+Z` 撤销。

**代码片段怎么新增或导入？**
「偏好设置 → 代码片段」可新建自定义片段，填触发词与模板后保存即生效；也支持导入 JSON 片段包（覆盖或合并）。触发词不能含反斜杠或空白，自定义上限 500 条。中文输入法占用快捷键时，可用菜单「插入代码片段…」。

**编辑工具栏为什么不显示？**
快捷工具栏只对 `.tex` 文本缓冲显示；图片 / PDF 查看器与 `.bib`、`.log` 等标签不显示，切回 `.tex` 标签即可。

**矩阵怎么设置行列数？**
在「公式 → 快捷工具 → 数组矩阵」点任一矩阵图标，会就地展开设置浮层：可切换无括号 / 圆括号 / 方括号 / 行列式 / 分段函数，调整 1–10 行/列（`cases` 固定 2 列），预览确认后写入编写区；右键图标可直接插入编辑器。

**公式编写区的「源码 / 可视化」有什么区别？**
两者共用同一份 LaTeX。源码模式上方编辑源码、下方实时预览，点空槽只定位光标；可视化模式把渲染结果作为主编辑面，点击 `\Box` 或按 `Tab` 选中槽位后直接输入，首键即替换。复杂嵌套建议回源码模式调整；编写区内容为会话级草稿，不写入项目文件，重启应用后清空。

**窗口没有系统标题栏，怎么移动或最大化？**
拖动顶部中间空白区移动窗口，双击最大化 / 还原；右上角提供最小化、最大化与关闭，左右下边缘及右下角可拖拽缩放。关闭时仍会检查未保存文档。

**宁夏大学学位论文模板怎么用？**
欢迎页「从模板新建」→ 模板库选「宁夏大学学位论文」→「用此模板新建」，填写 23 项变量（中英文标题、培养单位、导师、学号、分类号、密级等）并选择出稿格式、盲审封面、书脊与数学字体后生成。模板使用 `nxuthesis.cls` + XeLaTeX，需要 TeX Live 含 `ctex` / `natbib` / `hyperref` 等宏包；联合导师留空时不会生成对应字段。

**安装时 WebView2 自动安装失败？**
自动安装需要联网。请按提示从 [微软 WebView2 页面](https://developer.microsoft.com/microsoft-edge/webview2/) 手动安装 Runtime 后重新运行安装程序；Windows 10/11 通常已内置，不会触发下载。

**正式版右键为什么没有系统菜单？**
正式版屏蔽了 WebView2 原生右键菜单，避免与应用自绘菜单冲突并避免暴露调试入口。项目树、引用面板等自绘菜单不受影响；文本框内复制 / 粘贴请用 `Ctrl+C` / `Ctrl+V`。

**为什么项目设置里的「输出目录」是灰的？**
当前版本编译产物固定落在主文件同目录，输出目录支持留待后续版本；该字段会保留原值，不会清除。

**卸载后配置和 TeX 还在吗？**
应用配置在 `%APPDATA%\Zetla\config.json`；应用内安装的 TeX Live 在 `%LOCALAPPDATA%\Zetla\tex\`，卸载时可选择是否保留。

**还有哪些功能在规划中？**
绘图组件（M2）、拼图 PDF 导出与 PDF 子图选页、条件模板、代码格式化 / 拼写检查、多项目并排工作区（同时打开多个项目）、输出目录支持、表格 `.xlsx` 直读等仍在规划中，相关入口会置灰并标注计划。以下能力已在 `0.2.6` 提供：项目管理与模板库、模板库新建衔接、宁夏大学学位论文模板、表格编辑器、图片插入与图片 / PDF 标签页、拼图（subfigure / 合成单图）、语言档位与纯文本兜底、小地图、可自定义 LaTeX 语法高亮（主题方案 / 导入导出）、单文件查找替换与全项目搜索、编辑器快捷工具栏、自定义标题栏、实时预览、代码片段（补全 / Tab 直展 / 选中包裹 / 管理 / 导入导出）、编译日志完整换行、日志面板停靠与高度记忆、章节片段诊断去噪、`\input` 跨文件跳转、新建任意后缀文件、外部改动重载、清理辅助文件与自定义清单、编译后自动清理、保存时自动编译、自动更新、多编译引擎（XeLaTeX / pdfLaTeX / LuaLaTeX）、SyncTeX 双向跳转、亮暗主题、公式与符号面板（KaTeX 渲染、矩阵自定义行列、源码 / 可视化编写、136 条公式模板、环境反向编辑）、BibTeX 参考文献（补全 / 预览 / 跳转 / 校验 / 管理 / 手动刷新）。

## 从源码运行

环境要求：

- **Node.js 20+**（Vite 8 要求）
- **Rust stable** 与 Cargo
- **Visual Studio 2022 Build Tools**，包含 MSVC 和 Windows SDK

```powershell
git clone https://github.com/Wastarch/Zetla.git
cd Zetla
npm install
npm run tauri dev
```

首次启动需要编译 Rust 后端，耗时会比后续启动长。

> 如果 `cargo` 找不到 `link.exe`，请在 “Developer PowerShell for VS 2022” 中运行构建命令。

### 构建安装包

正式包使用 **Inno Setup 6**（需本机安装 Inno Setup；编译器 `ISCC.exe` 会自动从注册表/常见目录查找，也可用 `INNO_SETUP_ISCC` 指定）：

```powershell
# 1) 只编 release exe（不触发 NSIS 下载）
npm run tauri build -- --no-bundle

# 2) 调 ISCC 生成安装包
npm run package:inno
```

也可以一步完成：

```powershell
npm run package:win
```

安装包输出到：

```text
build/installer/Zetla_<version>_x64-setup.exe
```

版本号唯一源是 `package.json` 的 `version` 字段：`scripts/sync-version.mjs` 会在每次 `dev`/`build`/`tauri` 前自动把它同步到 `tauri.conf.json`、`Cargo.toml` 与前端 `src/version.ts`，安装包名随之切换（详见[版本号管理](#版本号管理)）。安装脚本在 `src-tauri/windows/inno/zetla.iss`。卸载时会读取 `%LOCALAPPDATA%\Zetla\tex-install.txt` 与 `<texdir>\.zetla-tex`，询问是否同时删除 Zetla 代装的 TeX Live（默认保留，静默卸载一律保留）。

> NSIS 配置仍保留在 `tauri.conf.json` / `windows/nsis-hooks.nsh` 作为备用，但正式发布不再使用。

### 版本号管理

版本号只需维护一处：**`package.json` 的 `version` 字段**。

```powershell
# 方式一：一条命令改版本并全量同步（推荐）
node scripts/sync-version.mjs 0.2.6

# 方式二：先手改 package.json 的 version，再同步
npm run version:sync
```

`npm run dev` / `build` / `tauri` 每次都会自动前置同步，日常开发无感知。同步落点如下，**请勿手改**：

| 落点 | 用途 |
| --- | --- |
| `src-tauri/tauri.conf.json` | Tauri 应用版本：关于页显示、安装包文件名 |
| `src-tauri/Cargo.toml`、`src-tauri/Cargo.lock` | Rust crate 版本 |
| `package-lock.json` | npm 锁文件根版本 |
| `src/version.ts` | 前端常量 `APP_VERSION`（生成文件） |

### 测试与检查

```powershell
# 前端类型检查
npx tsc --noEmit

# 前端生产构建
npm run build

# Rust 单元测试
cd src-tauri
cargo test
```

引用模块另有 Node 纯逻辑断言（需 Node 22+，逐个运行 `scripts/*.test.ts`）：

```powershell
node --experimental-strip-types scripts/cite-support.test.ts
```

## 目录结构

```text
Zetla/
├─ src/                 # React 前端：项目管理、编辑器、预览、引用、公式、表格、模板等
├─ src-tauri/           # Rust/Tauri 后端：编译、文件、配置、更新、安装器等
│  ├─ src/commands/     # Tauri commands
│  ├─ templates/        # 内置 6 套 LaTeX 模板（含宁夏大学学位论文）
│  └─ windows/inno/     # Inno Setup 正式包脚本
├─ scripts/             # 打包、版本同步与 Node 单元测试
├─ patches/             # 第三方依赖补丁（小地图宽度等）
├─ docs/                # 使用指南（模板编写、自定义编译流程）、更新日志与界面稿
│  └─ dev/              # 开发文档 / 开发计划 / 设计稿（.gitignore 忽略，仅本地）
├─ public/              # 静态资源（含 logo）
└─ build/               # 打包脚本与打包文档
```
